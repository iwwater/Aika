# S4 · Memory Retrieval

> 历史阶段规格：已由 [模块 SPEC](../../modules/README.md) 和 [模块测试规则](../../modules/TESTING.md) 替代。下方旧串行顺序及全仓小阶段门禁不再执行；保留原要求与历史证据追溯。

> 2026-09-10：本阶段以 LLM 文本回复开发为主。真人麦克风、TTS、声学指标不作为准入或通过门槛；保留已有语音适配回归。文本对话质量由固定样本与审阅验证。

状态：待实现；前置 S3。目标：按问题找到相关记忆，纠正或删除后不再重复旧事实。

## 数据与行为

扩展现有 MemoryRecord，区分 episodic 事件与稳定画像引用。字段至少有 id、kind、content、sourceMessageIds、createdAt、updatedAt、eventAt（可空）、lastConfirmedAt（可空）、confidence、status、supersedesId（可空）。候选与用户确认分开；模型置信度不是用户确认。

旧记录保留内容/状态/时间，缺来源标 legacy、置信度标 unknown，不虚构时间或来源。迁移幂等；SQLite 与浏览器存储均能读写兼容数据。

`retrieveMemories(query, now, limit, budget)` 返回候选记录及分数解释；按相关性、时间、状态选取，不能只拿最后 12 条。不依赖额外实时 LLM；第一版可采用本地关键词/词法评分。候选可参与上下文，但明确未确认；无关或低可信事实不当定论。

用户更正产生替代关系；暂时情绪不直接升为稳定人格。持久化、更新和删除必须联动检索缓存与 User Soul 引用。删除默认禁止从旧来源自动重建同一记忆；保留最小抑制标记，原始聊天删除是单独功能。摘要若含该事实须失效或重建，无法溯源的旧摘要保守失效。

本阶段复用既有抽取器，但避免被取消轮写入；后台频率与候选合并在 S5 收敛。交付检索服务、迁移、纠正/删除入口以及固定测试集。

## 验收条件

测试集至少 30 条记忆/20 个问题：15 个有相关答案、5 个应无结果；覆盖偏好、计划、人物、过期事实、更正及中日英表达。逐题标注允许的来源 ID；同一测试集固化入库，不针对失败改标签。

| ID | 方法 | 通过条件 |
| --- | --- | --- |
| S4-AC01 | 自动：固定检索集 | 15 个有答案问题中 ≥13 个 Top-5 命中；5 个无答案问题均不强行注入无关事实 |
| S4-AC02 | 自动：新旧事实冲突与过期计划 | 新确认事实优先；被替代事实不再作为当前事实；过期计划标明过去时间 |
| S4-AC03 | 集成：删除→重启→检索→后台抽取 | 删除内容不出现在记忆/画像/摘要注入中，不由旧来源自动复活 |
| S4-AC04 | 自动：旧数据库迁移两次 | 数量/内容/确认状态不丢失，不生成重复记录，失败不破坏旧库 |
| S4-AC05 | 人工：跨会话 10 个场景 | 至少 8 个正确自然引用相关事实；编造来源或将未确认候选说成已确认事实为 0 |

暂不上向量数据库或知识图谱；未达到跨语言召回门槛时调整检索，不用提示词掩盖漏召回。

## PRD v0.4 增补：Schema 与检索

在上述字段之外增加 type（fact/preference/event/goal/relationship）、importance、lastAccessedAt、validFrom/validUntil（可空）；kind 表示事件/画像层次，type 表示内容类别，两者不混用。规范状态 candidate/confirmed/superseded，旧 pending→candidate、旧 confirmed 保持，category 保留兼容；缺失值使用有文档的默认或 unknown，不虚构历史确认。有效期过滤、访问时间更新不能自动提高置信度或确认状态。

桌面第一版优先 FTS5/BM25 + recency + importance，评分权重版本化、可测试。浏览器/FTS 不可用可见降级词法检索；各路径独立达到既有召回门槛。过期事件可作为过去经历检索，不能当仍有效的未来计划。

User Soul 自动晋升至少需两个不同用户轮次的相容证据；同句重试/重复抽取不算新证据。用户显式编辑或纠正可直接生效；单次模型候选不得覆写稳定画像，冲突保留溯源并等待合并规则处理。

| ID | 方法 | 通过条件 |
| --- | --- | --- |
| S4-AC06 | 自动：有效期/重要度/访问时间与旧状态迁移 | 相同相关度下重要度和时效按公开规则排序；读取不提升确认状态；pending 幂等迁移，无失效事实冒充当前事实 |
| S4-AC07 | 自动：单证据/重复来源/两份独立证据/用户纠正 | 单次推断不覆盖 User Soul；重复来源不达晋升阈值；合格多证据可沉淀；明确用户纠正生效并保留来源 |
