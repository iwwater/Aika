## 范围与接口

- 使用可合法使用的现成角色包，角色素材制作/声音训练另列任务，不迁移 Unity。
- `CharacterPresentationAdapter`：load、setExpression、playMotion、setMouthOpen、reset、dispose；输入携带 turnId，未知 ID 回退默认。映射来自角色包 manifest，不执行模型返回的脚本或文件路径。
- Live2D 接入 Canvas/WebGL，支持待机呼吸/眨眼、预设表情和基础动作。口型优先取实际播放音频能量；若 TTS 只提供开始/结束回调则使用可见标记的简化口型，不宣称精确同步。
- 打断/结束立即复位口型和当轮动作，旧轮事件无效；模型加载失败、无包、WebGL 不可用时回退现有占位角色，聊天保持可用。
- 桌宠窗口透明、置顶、可拖动，允许从主窗口关闭/恢复；关闭表现窗口不得退出正在使用的主聊天。释放纹理/动画循环和窗口监听。

交付渲染适配器、合法示例包配置、桌宠窗口控制和性能实测。真实音频无法获取时同步验收标 BLOCKED，简化口型可作为降级交付但不能替代完整同步通过。

## 验收条件

| ID | 方法 | 通过条件 |
| --- | --- | --- |
| S8-AC01 | 自动：未知表情/动作/旧轮事件 | 默认回退，无任意代码执行，旧轮不改变当前表现 |
| S8-AC02 | 实机：10 句真实音频与 5 次打断 | 口型开始/结束相对音频偏差各 ≤150ms；打断后 ≤300ms 复位，无持续张嘴 |
| S8-AC03 | 实机：缺包/坏包/WebGL 不可用 | 三种情况均回退占位，文字及语音仍可操作 |
| S8-AC04 | 实机：连续运行 30 分钟 | 固定设备/包/分辨率下帧时间 P95 ≤33.3ms；S1 语音门槛不回退，无持续增长的监听器/渲染实例 |
| S8-AC05 | 实机：开关桌宠 10 次、拖动与重启 | 无重复窗口和残留动画循环；位置可恢复且屏幕变更后可找回；主聊天不中断 |
