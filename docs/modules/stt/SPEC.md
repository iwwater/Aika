# STT 模块 SPEC

职责：Mic→Audio Buffer→VAD→Speech Segment→ASR→Transcript Buffer→Turn Ready。语音段与对话回合分开；不调用 LLM，不合成回复，不绘制字幕。LLM/前端使用事件 recorder 或 stub。

## STT-01 · 输入契约与识别适配

交付 start/stop/cancel/dispose 生命周期，Whisper 自动语言与 Web Speech 可见降级；分段 ID、时间戳和来源精度。

| AC | 模块内验收 |
| --- | --- |
| STT-01-A | 假输入设备驱动重复启动/关闭/重开：无重复监听，dispose 后不产生有效事件 |
| STT-01-B | 固定 ASR 响应覆盖成功、空文本、超时、断开与取消；错误可见，下一段恢复，不要求真实 LLM/TTS |
| STT-01-C | Whisper 使用音频结束时间，Web Speech 估算明确标记；缺本地服务时降级信息与实际后端一致 |

## STT-02 · 分段排序与回合提交

交付真实最后有声时间、pending ASR 集合、按音频顺序合并、语义尾静音阈值、用户“立即发送/清空”的 API。

| AC | 模块内验收 |
| --- | --- |
| STT-02-A | 虚拟时钟覆盖短停顿、犹豫、续说和正常收尾；完整发言只产生一次 turnReady，空缓冲不提交 |
| STT-02-B | ASR 乱序/迟到时按原顺序合并，等待在途段完成；静音已足够时不从 ASR 返回再次重等阈值 |
| STT-02-C | 旧输入会话结果失效，新会话首段不丢；立即发送与清空各自幂等，不提交被清空文本 |

## STT-03 · 设备与识别验收（DEFERRED）

恢复真实语音验收后才执行。固定中文/日语/英语/混说各 5 个样本，预先保存台词和停顿长度，不依赖 LLM/TTS。

| AC | 模块内验收 |
| --- | --- |
| STT-03-A | 20 轮因低于阈值短停顿而拆轮为 0，每个预期完整输入仅提交一次；识别错误单列 |
| STT-03-B | ASR 完成且尾静音条件满足→turnReady 调度开销 P95 ≤250ms；记录识别准确性及延迟，不能用模拟音频冒充麦克风 |
| STT-03-C | 权限拒绝/设备断开/重开均可恢复或明确不可用；各宣称支持的输入引擎单独列结果 |

不在 STT 模块测 TTFA、TTS 口型、LLM 回复或完整 Barge-in；对应集成 INT-02。
