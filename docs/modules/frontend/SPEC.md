# 前端模块 SPEC

职责：React 页面、字幕/消息、模式与设置操作、加载/错误/取消状态。通过 Runtime/STT/TTS 接口，不在组件直接拼模型 prompt、检索 Memory 或解析原始流式 JSON。

开发与测试使用 fake Runtime、fake STT/TTS 和固定数据，无真实模型凭证、麦克风、Whisper 或音频服务也能完成小阶段。

## FE-01 · Runtime 桥接与消息状态

交付文本发送、流式展示、取消/重试、complete/interrupted/cancelled 呈现；Hook 只订阅状态与派发命令，保留旧消息兼容。

| AC | 模块内验收 |
| --- | --- |
| FE-01-A | fake Runtime 流式/完成/失败/取消序列正确展示，旧 turn 事件不覆盖新消息，不重复显示片段 |
| FE-01-B | 无 TTS/mic 时文本发送和完成正常；错误后能再发，disabled/busy 状态不残留 |
| FE-01-C | 中断消息明确状态，不当完整成功回复；组件卸载/重开无重复订阅 |

## FE-02 · 模式、场景与设置

交付 companion/oral_practice/scenario_practice 选择、练习语言/纠正偏好/场景参数、退出场景与设置保存反馈；角色始终相同。

| AC | 模块内验收 |
| --- | --- |
| FE-02-A | 切换三模式向接口发送正确参数，退出场景清除 UI 临时身份，不重置角色显示 |
| FE-02-B | fake 存储成功/失败/重载：设置正确恢复，失败可见，不假装已保存 |
| FE-02-C | 键盘可完成选择/发送/取消，控件有可访问名称；窄屏和桌面无主要控件遮挡 |

## FE-03 · 语音状态与字幕显示

交付监听/转写/等待/回复/播放状态、临时字幕、立即发送/清空、逐句高亮和降级提示。只消费模拟状态，不新增音频算法。

| AC | 模块内验收 |
| --- | --- |
| FE-03-A | fake STT 临时/最终事件正确更新字幕，立即发送/清空只调用对应接口一次 |
| FE-03-B | fake TTS 句子进度高亮正确，缺少匹配范围不猜位置；取消后高亮清理 |
| FE-03-C | 无麦克风/输入降级/音频错误均可见且仍可文字聊天；关闭面板解除自身订阅 |

证据：组件测试、浏览器使用 fake 数据的操作记录和必要截图。整套真实桌面/手机链路留 INT-01/03。Live2D/桌宠/素材创作仍后置，环境采集不开启。
