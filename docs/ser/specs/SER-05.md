# SER-05 · 演示服务输入边界与响应性

状态：已执行并验收（2026-09-21，[验收报告](../reports/SER-05_ACCEPTANCE.md)）；依赖 SER-04 的共享解析与路径入口。
日期：2026-09-21。需求：[PRD](../PRD.md)；范围遵守[优化入口](../../VOICE_RESEARCH_OPTIMIZATION.md)。

## 问题

`ser_server.py` 用字符串前缀判断路径包含，可能放行同前缀兄弟目录；页面将文件名/错误字符串直接拼入 innerHTML；上传路由在 async 请求内直接解码和同步推理，可能占住服务事件循环。

## 文件与接口范围

- 仅 `research/ser/ser_server.py`、`demo/ser-demo/index.html`，以及 `research/ser/tests/test_ser_server.py` 和必要浏览器验证脚本。
- 引擎通过最小可注入 callable/实例替换，真实路由、路径校验、音频预处理、响应组装必须走生产代码；导入测试不加载真实模型。
- 保持 `/health`、`/meta`、`/predict`、`/predict/path`、`/audio`、`/` 与 `--host/--port`；成功字段 top/top_ja/top_zh/scores/elapsed_s/duration_s/model/src 及错误 detail 形状不变。
- 非法路径仍400、合法但不存在404、不可解码400、推理失败500。现有有效样本的来源、颜色、标签和结果展示保持兼容。
- 不引入认证系统、远程部署、流式推理、新情绪类别或 UI 重设计。仅修当前代码已识别的问题。

## 具体行为

1. 将允许根目录和候选路径解析为规范路径，以路径组件判断包含关系；拒绝绝对路径、越界父目录、同前缀兄弟目录及指向根外的链接。先校验再打开文件。正常目录内相对路径继续可用。
2. 文件名、src、错误文字使用 textContent 或等价安全文本节点；固定模板可保留 innerHTML，禁止把未验证动态文本插进去。历史列表和失败页面同样覆盖。
3. 音频解码与同步模型推理不在 async 路由事件循环内直接运行。沿用单模型、串行推理原则，锁与实际线程生命周期匹配；执行前核对当前框架官方文档/本地安装版本的支持方式，不为这一点另建队列框架。
4. health 在另一个推理请求被可控 fake 阻塞时仍能返回；不要求真实 GPU 延迟达到任意阈值，不增加前端“实时性能已达标”的承诺。

## 验收条件

| AC | 定向检查 |
| --- | --- |
| A | 临时目录 fixture 覆盖合法音频、缺失音频、父目录越界、绝对路径、audio_backup 同前缀目录、根外链接；违规请求不读取目标文件、不调用模型。平台不能创建链接时单列 NOT RUN |
| B | 用含 `<img ...>` 的文件名/错误/src fixture，经真实浏览器上传或注入假 HTTP 响应，页面仅显示字面文本，不产生注入元素或执行标记；历史与错误分支均验证 |
| C | 两个请求经过生产锁而推理不重叠；用事件屏障挂起 fake 推理时 health 仍能完成，测试释放屏障收尾，不靠长 sleep 推断 |
| D | 假模型驱动上传、样本识别、坏音频和推理失败；字段、状态码与既有消费者兼容；标签解析复用 SER-04 |
| E | 真实浏览器完成选择样本、显示结果、历史、上传错误恢复；不绕过页面点击直接调用 renderResult 冒充交互通过 |

## 验证与交付

本地 SER Python 运行 `test_ser_server.py` 及受影响的共享解析测试；浏览器使用当前可用浏览器/Playwright，服务和路由真实启动，模型为 fake，不使用真实凭证/GPU。截图与命令结果进 `docs/ser/reports/SER-05_ACCEPTANCE.md`，报告区分 fixture UI 与真实声学结果。

默认属于有效请求兼容的缺陷修复；拒绝此前误放行输入是有意收紧，不升级主工程协议。若实现必须改成功响应 schema，先修改本 SPEC 并登记消费者，不能暗改。
