# SER-10 验收报告 · 声学扰动、短时窗与延迟压力测试

日期：2026-09-22。规格：[SER-10](../specs/SER-10.md)。结论：**PASS**。真实麦克风测试：**BLOCKED**。

## 执行范围

在SER-06的1,248条七类计分样本上执行8个条件，共9,984次真实emotion2vec embedding推理，失败0。每条样本只由其固定外折模型预测；模型训练只使用干净训练speaker。temperature和阈值直接冻结自SER-09，没有根据压力测试结果重新调参。

受控条件包括clean、白噪声20/10/0 dB SNR、-12/+12 dB增益、中心1.0/0.5秒窗口。噪声seed由sample ID与条件哈希确定。+12 dB允许削波，因此代表过载压力条件，不是无损增益。

## 关键发现

1. **噪声是首要风险。** 20 dB已经损失约0.103 UAR；10 dB损失约0.248；0 dB接近失效。严重噪声下confidence仍可能很高：0 dB仍接受20.99%的样本，但已接受样本错误率75.57%。现有拒识不能视为可靠OOD检测器。
2. **低音量敏感。** -12 dB使UAR降至0.8185，主要错误包括neutral→sad、fearful→sad。+12 dB削波影响很小，表现出明显的非对称幅度敏感性；产品前应增加并单独验证响度归一化。
3. **短片段不可用。** 1秒和0.5秒UAR分别只有0.4144/0.3170，coverage约10%。需要VAD后最短有效语音门槛，不能在半秒级片段上强行输出情绪。
4. **错误向sad坍缩。** 噪声条件下fearful/disgusted/angry/happy大量转为sad；0 dB下angry→sad 186条、fearful→sad 180条、happy→sad 177条。这是明显的扰动偏置，而非均匀随机退化。

## 延迟

下表只测GPU embedding前向时间，不包含文件读取、重采样、扰动、分类器、IPC或UI，因此不得称为端到端产品延迟。

| 输入长度 | P50 | P95 | RTF |
| --- | ---: | ---: | ---: |
| 原始整段（clean） | 19.35 ms | 30.65 ms | 0.0058 |
| 原始整段（其余全长条件典型） | 18.55–18.89 ms | 20.98–21.11 ms | 约0.0051 |
| 1.0秒 | 8.81 ms | 9.31 ms | 0.0089 |
| 0.5秒 | 7.91 ms | 8.42 ms | 0.0159 |

短输入绝对耗时更低，但固定开销使RTF反而升高。首次模型加载、磁盘I/O和上层服务延迟没有计入。
