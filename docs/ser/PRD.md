# SER 研究工具 · 模块 PRD

需求来源：[研究立项 SER-01](SPEC_SER-01.md)、[研究计划](RESEARCH_PLAN.md)。本文件限定工程职责，不把已有研究假设升级为已证明结论。执行入口：[SPEC 索引](SPEC.md)。

## 目标

支持语音情绪实验、结果复核与本地演示，使模型输入、标签处理、统计口径和证据出处可追溯。研究脚本与本地演示共用必要的数据处理规则，独立于 Aika 主工程。

## 范围

- 负责 `research/ser/` 的样本读取、模型适配、指标、实验日志与产物；负责 `demo/ser-demo/` 的本地识别展示。
- 真实模型通过可替换边界调用。统计、解析和 HTTP/UI 编排可以离线验收，不要求真实 GPU 或其他语音模块服务。
- 不负责主工程接入、TTS 推理、Whisper 部署、LLM 回复或新数据采集；不把六种风格标签直接视为标准 SER 类别真值。
- 文档在本目录，新增规格在 `specs/`，验收报告在 `reports/`；已有 SER-01/02 保留原路径。

## 质量要求

未知预测仍计入错误分母；真实标签剔除规则与推理失败分开报告。小样本与模型对照只能支持对应证据范围的观察。环境、样本清单、模型标识、运行参数和结果版本可追溯；新结果不得静默覆盖历史证据。

## 契约与协作

遵守 [共享契约](../modules/CONTRACTS.md)。当前 SER 是独立研究服务，未注册为主工程 SpeechInput/SpeechOutput，不更改 `services/voice/contracts.ts`。局部 HTTP 与结果 schema 的兼容方案由 SER-03/05 定义并在执行报告登记；不得宣称已完成跨模块接入。
