# SER V2 路线图：把日语语音情感识别做到可研究、可解释、可落地

日期：2026-09-22。方向决策：当前阶段暂停 TTS M1 重训，把新增精力集中到 SER。执行仍遵守“一次一份 SPEC”。

## 1. 当前基线

已经具备的部分：

- emotion2vec+ large 在 RAVDESS 七类、1,248 条计分样本上达到 accuracy 0.9215、UAR 0.9234；计分、未知预测、失败记录和历史产物保护已经过 SER-03/04 复核。
- 18 条日语样本完成 zero-shot 分类与 embedding 探索，观察到柔软类声线被误判为 fearful/surprised、嘲讽与毒舌不稳定。
- 独立服务、上传边界、浏览器演示和错误隔离由 SER-05 覆盖。
- 本地环境已有 scikit-learn、PyTorch、FunASR/emotion2vec；尚未安装 openSMILE。

当前结果只证明“英文 acted 数据上模型可用、日语小样本上存在值得研究的偏差”。它还不能证明日语真实场景准确、跨说话人泛化、概率可信或实时对话可用。

## 2. “做得很不错”的验收定义

SER V2 不用一个漂亮 accuracy 代替完整质量。最终至少满足以下六个维度：

| 维度 | 最终要求 |
| --- | --- |
| 泛化 | 主结果采用 speaker-independent；同一句文本可能重复时增加 speaker + text-independent 结果 |
| 日语有效性 | 主结论来自有授权、带标签的真人日语语音；18 条 Demo 只作探索/外部压力测试 |
| 指标 | 同时报 UAR、macro-F1、accuracy、每类 recall、混淆矩阵和失败数；未知/拒识计入分母 |
| 可解释性 | eGeMAPS 基线、特征组消融和 SSL 表征对照能回答“哪些声学线索有效” |
| 可信度 | 报告概率校准和拒识曲线；低置信输入允许返回 uncertain，而非强行给情绪 |
| 产品可用性 | 在真实麦克风短句、噪声、不同音量、不同说话人下测鲁棒性与延迟；研究服务先独立，不触碰冻结中的前端 |

只有同时满足以上条件，才称为“日语 SER 做得好”。RAVDESS 高分、单一说话人听感或 Demo 演示均不能单独达标。

## 3. 数据与标签策略

### 3.1 数据分层

1. **主基准：授权真人日语情绪语料**。优先申请 JTES；并行调查 OGVC、Keio-ESD 等合法来源。未取得授权前不假设数据可用。
2. **英文 sanity check：RAVDESS**。只确认方法实现和跨语言起点，不代表日语质量。
3. **域外真实日语压力测试**。使用明确授权、与训练说话人隔离的自然/情绪化语音；样本不足时只报告方向性结果。
4. **合成受控集**。仅用于固定文本、改变韵律的词义隔离实验和模型行为诊断，不用于训练真人 SER。

### 3.2 标签分层

- 数据集原生标签是研究真值层，不为了迎合 Aika mood 随意改名。
- 建立 canonical emotion 层，保存原始标签、映射版本和无法映射项。
- Aika 的 style/mood 是产品策略层；从 SER 情绪到 mood 的映射单独评估，不反向污染训练标签。
- 后续可增加 valence/arousal 连续维度，但不得从离散标签凭空伪造连续真值。

## 4. 执行阶段

| 顺序 | SPEC | 目标 | 主要产出 |
| --- | --- | --- | --- |
| 1 | SER-06 | 冻结数据清单、标签映射、无泄漏 split 与统一评测协议 | manifest schema、split validator、evaluation contract、基线数据审计 |
| 2 | SER-07 | 建立可解释传统基线 | openSMILE eGeMAPS 88维、标准化、class-weighted SVM/LogReg、特征组消融 |
| 3 | SER-08 | 建立现代 SSL 强基线 | frozen emotion2vec embedding + linear/MLP probe，与 eGeMAPS 同 split 对照 |
| 4 | SER-09 | 日语少样本适配与校准 | nested CV、speaker-balanced sampling、temperature scaling、拒识阈值 |
| 5 | SER-10 | 真实短句与环境鲁棒性 | 麦克风、噪声、音量、短时窗、跨说话人压力测试；错误类型表 |
| 6 | SER-11 | 研究闭环与产品接入 | 独立服务契约、时序/延迟、情绪到对话策略映射；等主工程重构后再执行 |

SER-07 与 SER-08 必须使用 SER-06 冻结的同一 split。禁止各自挑最好看的随机划分。

## 5. 模型选择原则

- 第一优先不是端到端微调，而是建立可复核的 eGeMAPS 与 frozen-embedding 基线。
- 数据量不足时不训练大模型全参数；优先 linear probe、浅层分类器、参数高效适配。
- 超参数选择只能在训练/验证折内完成，测试折不得参与选择。
- 报告均值、标准差和逐折结果；不只报告最好一次。
- 对低置信、域外或无声输入提供拒识，不能把 softmax 最大值当可靠概率。
- 所有模型比较固定数据、split、标签和指标版本；模型规模与训练数据同时变化时不得声称单变量因果。

## 6. 当前明确不做

- 不启动 GPT-SoVITS M1 重训，不把促音电音问题混进本轮 SER。
- 不用 A/C 合成音频训练分类器。
- 不以 6 条真人参考音频做交叉验证或发布准确率。
- 不在获得许可前提交或分发 JTES 等受限数据。
- 不改 `aika-crossplatform/`；SER-11 等合作者重构落地后再重新对照接口。

## 7. 最近决策点

SER-06 可以在数据授权到达前完成协议、schema 和 RAVDESS 审计。授权日语数据到位后只新增 manifest 条目并生成冻结 split，不重写评测规则。JTES 申请邮件是外部发送行为，需用户确认收件人和个人信息后另行发送；草稿本身不视为已申请。
