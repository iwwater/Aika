| **显式授权管理器** | 1. 严格默认关闭，捕获必须携带有效 `CaptureGrant`；<br>2. 支持目标窗口/区域、处理目的地（`local` / `cloud`）、生命周期（`single` / `session`）与 TTL；<br>3. 单次 Grant 消费后状态原子置为 `expired`，后续重复请求拦截拒绝；<br>4. 目的地由 `local` 升格为 `cloud` 或目标变更时强制撤回并以新 revision 重新核对；<br>5. 撤回（`revokeGrant`）联动绑定 `AbortController`，在途 OCR/VLM 处理即刻终止。 | [`core/perception-grant.ts`](file:///F:/AIVoice/Aika-Next/windows/code/desktop-pet/core/perception-grant.ts) |
| **屏幕感知引擎** | 1. 适配独立 OCR 与 VLM 多模态能力，支持组合或单引擎运行；<br>2. 原始大图图像在提取后立即 Drop / 释放内存，产物 `Observation` 仅留存 `frameHash` 摘要与结构化文本/总结；<br>3. 帧哈希缓存键机制：相同图像直接复用识别结果，避免重复推理开销；<br>4. 异步处理期间如果 Grant 被撤回，严格抛出异常并拒绝产出有效 Observation。 | [`core/screen-perception.ts`](file:///F:/AIVoice/Aika-Next/windows/code/desktop-pet/core/screen-perception.ts) |
| **动态上下文注入** | 1. `ObservationContextAdapter` 仅将时效性感知内容作为 Prompt 的**动态后缀（Dynamic Suffix）**拼接；<br>2. 核心系统设定与角色记忆构建的**冻结前缀快照（Frozen Prefix）100% 保持字节一致**，确保供应商端 KV Cache 击中率；<br>3. 观察失效、超时或 Grant 撤销后，Prompt 动态后缀自动剔除屏幕感知内容，杜绝迟到污染；<br>4. 严格校验租户配对（`PairingScope`），防止跨用户或跨实例信息泄漏。 | [`core/observation-context.ts`](file:///F:/AIVoice/Aika-Next/windows/code/desktop-pet/core/observation-context.ts) |
