# 08-05 复核报告：Work / ACP / MCP

- 日期：2026-09-25
- 状态：**正式管理 API、Work 确认卡、产品数据目录与 trial-backend ACP fixture 进程链自动验收通过；真实 ACP/MCP 服务及桌面视觉验收 BLOCKED / NOT RUN**
- 复核范围：ACP/MCP 版本、JSON-RPC stdio 传输、权限失败关闭、Work 幂等回执和 `trial-backend` 装配入口。

## 本轮交付

- 新增 `core/stdio-json-rpc.ts`：通过 `spawn(..., shell:false)` 启动绝对路径命令，使用 UTF-8 换行 JSON-RPC，限制输入、输出消息大小和请求超时，处理断连、JSON-RPC 错误及优雅关闭；进程仅继承必要的 OS 运行变量，其余环境必须由配置显式提供。
- ACP 冻结为 v1 数字版本 `1`；适配器执行 `initialize → session/new → session/prompt` 并采集 `session/update` 文本，传播 `session/cancel`。没有 UI 权限桥时不开放文件系统/terminal 能力；Agent 的权限请求收到 `cancelled`。
- MCP 冻结为现代 `2026-07-28` 和兼容旧服务的 `2025-11-25`。stdio 优先 `server/discover`，旧服务回退 `initialize`；支持 `tools/list` 分页、现代 `_meta`、`tools/call`、远端错误映射和取消通知。
- 远端工具 annotation 不可信。工具只有出现在本机可信策略中并明确配置为只读时才可免 grant；其他工具默认要求授权。
- 原 Work 模块幂等、未知状态、取消竞态与工作域隔离逻辑保留。
- `WorkRequest` 增加单调 `revision`；修改请求时必须给出当前 revision，派发/取消同样要求用户确认卡携带 revision。旧卡版本会在调用 adapter 前被拒绝；SQLite journal 在事务内比较 revision，跨进程陈旧确认也失败关闭。
- `executorRevision` 将每个 prepared Work 卡绑定到当时的 ACP/MCP profile revision；profile 重配后旧卡无法静默改用新命令。凭据保存在权限受限 profile 文件，API 仅返回环境变量名称，不返回值。
- journal v1→v2 迁移将既有请求视为原 revision 1，v2→v3 增加持久遗忘 tombstone；损坏或格式不符的记录仍失败关闭。journal 文件要求私有权限，启用 SQLite `secure_delete`。
- 新增独立 SQLite `SqliteWorkProtocolJournal`：在外部派发前原子记录请求与 pairing，恢复“已尝试但未收到终态”的任务为不可重试 `uncertain`，阻止重启重复执行。
- 终态回执先持久化，再同步等待事件投影；Timeline listener 失败或没有匹配消费者时不确认 outbox，后续启动以稳定 `eventId` 重放。读取、修订、取消和重放派发均校验 pairing；派发需等待 outbox 就绪。
- 遗忘先把 journal 正文原子替换为 tombstone，再撤销 Timeline source；启动恢复会在 Work manager 创建和 outbox 重放之前补做 source revocation。已遗忘 operation 不可修订或派发，Timeline 查询和投影触发器共同防止正文复活。
- `trial-backend` 正式组合根加载 private profile/journal、认证管理路由、任务运行时和关闭生命周期；无 profile 时保持可启动，配置保存和启动不启动外部进程，只有 MCP 元数据发现或明确确认任务才启动 stdio 子进程。
- 管理端 Work 页面包含 profile 配置、MCP 工具发现、参数/权限摘要、可修订草稿、最终确认卡、回执和遗忘操作。MCP 工具注释不能授予权限；ACP 动态 permission request 在没有交互式授权桥时明确拒绝。

## 停止项与状态

本地正式组合根链路已接通并通过自动化，但真实外部服务尚未提供：目前没有经用户选定的 ACP v1 Agent、现代/旧版 MCP 服务和对应的只读/写入工具权限场景。系统也没有 ACP 动态权限请求的互动授权桥，当前按规范拒绝这些请求。真实任务副作用、取消与远端未知状态核对仍不能用 fixture 代替。Work 管理页面由模拟 DOM 测试覆盖；Electron 视觉/点击验收未运行。

继续接线前的必要项：

1. 使用实际兼容的 ACP v1 Agent 与 MCP `2026-07-28`/`2025-11-25` 服务分别跑发现、确认、权限拒绝/授权、取消、断连和重启对账；外部服务不在当前 fixture 资源内，保持 **BLOCKED / NOT RUN**；
2. 在可启动 Electron 的 Windows 环境对 Work 管理页面和真实低风险服务进行视觉/交互验收；当前 Chromium GPU/renderer 启动故障未解除，保持 **BLOCKED / NOT RUN**；
3. 如后续确需 ACP server 主动请求额外能力，先实现可展示、可撤销并可审计的交互授权；当前实现明确默认拒绝，不隐式授权。

因此 08-05 的**正式自动化接线通过**，真实服务与桌面体验仍 **BLOCKED / NOT RUN**；此状态不代表 0.8 发布许可。
