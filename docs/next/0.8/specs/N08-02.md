## 1. 目标与负责边界

落实 [0.8 RPD](../RPD.md) §8.1 与验收矩阵 08-L，完善桌面宠物轻量气泡、展开聊天抽屉（drawer）与控制台会话查看的协同交互：
1. **单一轮次权威（Single TurnScope Authority）**：
   - 气泡、展开抽屉与 Live2D 表情动作完全消费同一份 `TurnScope` 状态投影；
   - 用户展开抽屉、收起抽屉或切换窗口显示模式时，**绝不新建会话、绝不重复提交输入、绝不重复播放 TTS 音频**；
   - 气泡淡出或关闭时，历史记录安全留存于会话历史中，绝不丢失。
2. **长回复阅读与点击展开**：
   - 轻量短回复在气泡直接完整展示；长回复展示时支持点击气泡展开抽屉查看全文，不重新请求或重复播报。
3. **取消与代次防护（Stale Generation Guard）**：
   - 发生取消、超时或切换时，严格校验 `generation` 与 `turnId`；旧轮次的迟到回复与音频丢弃，禁止覆盖新界面。
4. **输入法组合键防护与焦点恢复**：
   - 严格在 `compositionstart`/`compositionend` 期间拦截回车误触发；发送后自动清空输入框并支持键盘焦点恢复。
5. **穿透区域仲裁协同**：
   - 抽屉展开时，`#drawer` 区域动态进入交互矩形列表；收起时立即释放，鼠标点击顺畅穿透至背景桌面。

## 2. 详细交互规则与状态机

### 2.1 状态转移与事件流

```
用户输入 (Text/ASR)
  ↓
TurnScope 生成 (sessionId, turnId, generation)
  ↓
[thinking] -> 气泡显示 "想一想… ✦" (40s 超时保护)
  ↓
收到 reply 事件:
  ├── 气泡呈现: showBubble(text, 'speaking')
  ├── 对话日志: chatLog.reply(scope, text)
  └── 展开抽屉: 若抽屉已开，列表同步更新
  ↓
播放结束 (playback:ended) -> view.state 归为 idle
```

### 2.2 抽屉开关不变量（Invariants）

- `panel(true)` 与 `panel(false)` 仅控制 DOM 可见性与动画；
- `setIgnoreMouseEvents` 依据 `#drawer` 是否隐藏动态刷新 `interactive_regions`；
- 开关过程不向后端发送任何 `submit_text` 或新轮次信令。

---

## 3. 验收条件 (AC)

- **AC-0802-1（单一轮次与收展不变量）**：抽屉在 thinking 或 speaking 期间展开或收起，`view.scope` 保持不变，不会产生新请求或重复播放；
- **AC-0802-2（气泡淡出不丢历史）**：气泡淡出（`dismissBubble`）后，`chatLog` 中的用户与助手消息行完整保留；
- **AC-0802-3（迟到轮次丢弃）**：来自旧 generation 的 reply 或 presentation 事件被 `DesktopViewState.accepts()` 拒绝，不改变当前界面；
- **AC-0802-4（输入法合成态防护）**：输入法在拼音组合（`composing = true`）期间按下 Enter 键，不触发消息提交；
- **AC-0802-5（穿透区域协同）**：抽屉打开时上报交互区域，关闭时清空区域，仲裁策略恢复整窗穿透。
