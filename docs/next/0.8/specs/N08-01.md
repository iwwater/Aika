## 1. 目标与负责边界

在 08-00 冻结的 `CompanionEventEnvelope` 契约基础上，实现生产就绪的多域事件传递与跨域时间线投影引擎：
1. **多域事件分发（`CompanionEventHub`）**：
   - 遵照 `HostEventChannel` 接口规范，支持按照业务领域（`canon` / `companion` / `work`）与角色配对（`PairingScope`）精准路由；
   - 严格校验 `eventId`、`schemaVersion: 1`、`occurredAt`、`pairing` 和 `sourceRef`；
   - 消除无约束的全局广播，按包标识与会话/配对隔离订阅。
2. **跨域时间线投影引擎（`UnifiedTimelineService`）**：
   - 统一收拢三域投影查询：
     - **Canon 域**：来自角色包的固定世界观与作品事实（不可变设定）；
     - **Companion 域**：来自真实对话、观察、主动邀请与关系流转（伴侣共度历史）；
     - **Work 域**：来自工程任务、ACP/MCP 工具回执（独立任务卡，不污染伴侣主观记忆）；
   - **幂等性**：依据 `eventId` 去重，防范重复投递与死循环；
   - **乱序容忍**：依 `occurredAt` 时序严格排序，延迟到达事件正确插入；
   - **重启恢复**：结合既有 `character_companion_projection_outbox`，支持进程重启后自动恢复未完成投影；
   - **撤销与遗忘传播**：当关联来源事实被撤销/遗忘时，动态剔除或脱敏受影响条目，严禁被遗忘内容在时间线复活；
   - **严格配对隔离**：禁止跨 `userId`、`characterId` 或 `characterInstanceId` 越权查看历史。

## 2. 详细接口设计

### 2.1 事件总线通道：`CompanionEventHub`

```typescript
export interface CompanionEventListener {
  readonly id: string;
  readonly domains: readonly EventDomain[];
  readonly pairing?: PairingScope;
  readonly handler: (envelope: CompanionEventEnvelope) => void | Promise<void>;
}

export class CompanionEventHub {
  publish(envelope: CompanionEventEnvelope): void;
  subscribe(listener: Omit<CompanionEventListener, 'id'>): () => void;
  drain(): Promise<void>;
}
```

### 2.2 统一时间线投影服务：`UnifiedTimelineService`

```typescript
export interface TimelineQuery {
  readonly pairing: PairingScope;
  readonly domains?: readonly EventDomain[];
  readonly limit?: number;
  readonly cursor?: string;
  readonly cutoffPoint?: string;
}

export interface TimelineQueryResult {
  readonly items: readonly TimelineItem[];
  readonly nextCursor: string | null;
  readonly totalMatching?: number;
}

export interface TimelineItem {
  readonly eventId: string;
  readonly domain: EventDomain;
  readonly type: string;
  readonly occurredAt: string;
  readonly summary: string;
  readonly sourceRef: { readonly id: string; readonly version: number };
  readonly canonDetails?: { readonly awareness?: string; readonly scene?: string };
  readonly companionDetails?: { readonly userText: string; readonly assistantText: string };
  readonly workDetails?: { readonly executorId: string; readonly status: string; readonly targetTitle: string };
}
```

## 3. 验收条件 (AC)

- **AC-0801-1（分域隔离）**：发布 `work` 域事件只进入 Work 投影，绝不混入 Companion 时间线或生成假伴侣自述；Canon 事实只读；
- **AC-0801-2（幂等与去重）**：相同 `eventId` 的事件重复发布被静默去重（`duplicate`），发生冲突时拒绝覆盖；
- **AC-0801-3（乱序自愈）**：延迟 5 秒到达的早期时间戳事件，查询时按 `occurredAt` 正确呈现于历史序列中；
- **AC-0801-4（配对安全隔离）**：Pairing A 绝对无法查询到 Pairing B 的私有伴侣或任务事件；
- **AC-0801-5（撤销与遗忘联动）**：撤销来源 ID 后，时间线投影立即将关联事件内容置空或剔除，重启后保持剔除状态；
- **AC-0801-6（重启持久化恢复）**：模拟进程崩溃并在重启后调用 `drain`，Outbox 中暂存的对话事件完整沉淀至时间线库。
