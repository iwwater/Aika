## 1. 目标与负责边界

落实 [0.8 RPD](../RPD.md) §4 及验收矩阵 08-A~D，实现受控的屏幕感知采集、OCR/VLM 结构化提取与时效性 `Observation` 注入：
1. **显式授权管理器（`CaptureGrantManager`）**：
   - 默认关闭；第一次采集明确目标（窗口/区域/全屏）、时长（单次/会话）、处理目的地（`local` / `cloud`）；
   - 授权代次 `revision` 控制：目标切换或由本地切云端时强制重新核对；
   - 锁屏、目标关闭、用户主动撤销时立即触发 `AbortController` 中止在途采集，并将状态置为 `revoked`。
2. **多模态感知适配器（`PerceptionEngine`）**：
   - 独立声明 OCR 与 VLM 能力；支持仅安装其一或组合使用；
   - OCR 输出文字坐标、阅读顺序与置信度；VLM 输出脱敏摘要与视觉元素，标明不确定性（`uncertain`）；
   - 原始图像在推理/提取完毕后立即释放（Drop/Unlink），仅在内存保留 `frameHash` 摘要与结构化结果；
   - 图像短期缓存键：`${targetId}:${frameHash}:${grantRevision}:${engine}`，支持重复画面轻量复用。
3. **时效性上下文动态注入（`ObservationContextAdapter`）**：
   - 仅作为 `DialoguePipeline` 提示词的**动态后缀（Dynamic Suffix）**拼接，**绝不改变 0.61 冻结前缀快照**，保障供应商 KV 缓存；
   - TTL 超时（默认 120 秒）或 Grant 撤销后，上下文自动剔除观察，杜绝迟到污染；
   - 模型文本输出中的指令不构成工具授权（防 Prompt 越权注入）。

## 2. 接口契约定义

```typescript
export interface CaptureRequest {
  readonly grantId: string;
  readonly imageBytes: Uint8Array;
  readonly mimeType: 'image/png' | 'image/jpeg';
}

export interface PerceptionEngineOptions {
  readonly ocrEngine?: (bytes: Uint8Array) => Promise<OcrResult>;
  readonly vlmEngine?: (bytes: Uint8Array) => Promise<VlmObservationResult>;
}

export class CaptureGrantManager {
  issueGrant(params: Omit<CaptureGrant, 'grantId' | 'revision' | 'grantedAt' | 'status'>): CaptureGrant;
  revokeGrant(grantId: string): boolean;
  getGrant(grantId: string): CaptureGrant | null;
  verifyOrReissue(grantId: string, currentTargetId: string, targetDest: ProcessingDestination): { grant: CaptureGrant; reissued: boolean };
}

export class ScreenPerceptionService {
  constructor(grantManager: CaptureGrantManager, options?: PerceptionEngineOptions);
  processCapture(request: CaptureRequest, pairing: PairingScope): Promise<Observation>;
  getObservation(observationId: string): Observation | null;
  invalidateObservation(observationId: string): void;
}
```

## 3. 验收条件 (AC)

- **AC-0803-1（授权生效与到期零采集）**：无有效 Grant 时拒绝捕获；单次 Grant 消费后状态变为 `expired`，后续请求被拦截；
- **AC-0803-2（目的地变更重验）**：当处理目的地从 `local` 切换至 `cloud` 时，原授权判定失效，必须重新签发新代次（revision 递增）；
- **AC-0803-3（处理中撤销与在途阻断）**：调用 `revokeGrant` 时，正在进行的 OCR/VLM 处理通过 AbortSignal 立即中止，不产出有效 Observation；
- **AC-0803-4（原图释放与结构化提取）**：Observation 产物中只保留 `frameHash` 与结构化 text/blocks/summary，不留存大图二进制；
- **AC-0803-5（动态后缀注入与前缀冻结保全）**：活跃的 Observation 仅作为后缀插入 Context；撤销或超时后 Context 恢复纯净，冻结前缀哈希前后严格一致。
