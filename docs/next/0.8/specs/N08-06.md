## 1. 目标与负责边界

落实 [0.8 RPD](../RPD.md) §8.2、§9 与验收矩阵 08-A ~ 08-M，完成 Aika Next 0.8 全景收口验证：
1. **最小包组合与清洁安装隔离（08-I）**：
   - 验证 Pure Core（无感知、无主动、无 Work 扩展包）平稳启动，Live2D 桌面伴侣与基础对话完备可用；
   - 缺少可选功能包时，系统保持优雅降级，未启用模块零后台资源消耗与零无故报错；
   - 验证按需加载 `+Perception`、`+Proactive`、`+Work` 扩展包组合。
2. **控制台路由、鉴权与诊断收口（08-J / 08-M）**：
   - 保证控制台 URL 包含或剥离敏感 Token 的安全路由解析（`parseConsoleRoute`）；
   - 保证历史旧深链（`#section=timeline`、`#section=diagnostics`、`#section=runtime` 等）平滑兼容映射；
   - 控制台总览数据严格绑定真实 API，拒绝硬编码虚拟在线状态或无依据的好感百分比；
   - 追溯链条（Trace）可正向关联至 Timeline 事件与来源事实。
3. **08-A ~ 08-M 全量验收矩阵收口**：
   - 逐项核实 08-A 至 08-M 的自动化测试证据、生产接口状态及人工体验边界；
   - 区分 PASS、NOT RUN、DEFERRED，杜绝未经实测标绿。
4. **前端视觉调整门槛守则**：
   - 严格遵循 RPD §8.2 逐界面顺序（气泡 -> 抽屉 -> 会话查看 -> Timeline -> 感知授权 -> 主动策略 -> 总览与诊断 -> Work 卡）；
   - 涉及前端视觉重构遵守“先明确需求 -> 索取参考图 -> 确认范围 -> 实施并请求逐项审核”的规范。
