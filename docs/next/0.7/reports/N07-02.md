## 1. 交付目标与责任范围

本次完成 Aika Next 0.7 连续性文字闭环的第二阶段核心能力：
“可替换 CharacterSourceProvider（本地文本/文件 + 显式 HTTP Wiki）与生产级 CharacterDistiller adapter”。
接入 0.65 `ResolvedBinding` 契约体系，实现剧情截止点（`cutoffPoint`）隔离、事实分类（`explicit` / `inferred` / `disputed`）与知识缺口（`gaps`）分析。

本阶段继续遵守边界：**不扩展双时间线、关系成长、激活/升级/回退与管理 UI**，相关内容依既定路线留待后续 SPEC（N07-03～N07-05）。

## 2. 源码与模块变更

- `contracts/character-pack.ts`：新增 `CharacterSourceRef`、`SourceKind`（`text` / `file` / `http_wiki`）、`FetchSourceResult`、`CharacterSourceProvider` 接口，并扩充 `CharacterPackErrorCode`（新增 `source_fetch_failed`、`unsupported_source`、`cutoff_violation`）。
- `memory/character-source-provider.ts`：实现 `TextSourceProvider`、`HttpWikiSourceProvider` 与 `CompositeCharacterSourceProvider`。
  - `TextSourceProvider`：安全读取内联文本与本地 `.txt`, `.md`, `.markdown` 文件。
  - `HttpWikiSourceProvider`：显式 HTTP(S) Wiki 抓取，内置 SSRF 私网 IP 拦截、脚本与样式剥离、Markdown 标题转换、登录墙/权限墙感知报错（不伪称已读取）。
  - `CompositeCharacterSourceProvider`：多源路由器，按 URI 协议及类型自动分发。
- `memory/character-pack-validator.ts`：扩展 `validateDraftEvidence` 与新增 `computeCutoffAllowedBlockIds`。支持针对 `cutoffPoint` 判定允许的区块范围，超出截止点的引用一律拒绝并报错；校验事实的 `explicit` / `inferred` / `disputed` 状态标记。
- `providers/character-distiller.ts`：扩展 `resolveDistillerConfig` 兼容 0.65 `ResolvedBinding`；在 prompt 中增加截止点说明与事实分类要求；新增 `distillFromSourceRefs` 提供“拉取 → 入库 → 分块 → 提炼 → 校验持久化”高层协调入口。
- `tests/memory/character-source-provider.test.ts`：覆盖文本与文件读取、SSRF 拦截、HTTP 状态码报错、HTML 清洗与标题转换、登录墙检测、复合路由等。
- `tests/providers/character-distiller-02.test.ts`：覆盖 0.65 `ResolvedBinding` 接入、`cutoffPoint` 越界拦截、事实状态分类校验、`distillFromSourceRefs` 端到端协调。
- `tools/acceptance-next07-02.mjs`：正式真实模型闭环验证脚本。
