## 2. 源码与模块变更

- `contracts/character-pack.ts`：
  - 新增 `CanonAwareness`（`experienced` / `heard` / `unknown`）。
  - 新增 `CanonTimelineEvent`、`CharacterPack`（不可变激活包）。
  - 新增 `PairingScope`（`userId` + `characterId` + `characterInstanceId`）、`CharacterInstance`。
  - 新增 `CompanionTimelineEvent`、`ContinuitySnapshot`、`ContinuityReadPort`。
- `memory/character-pack-store.ts`：
  - 新增 SQLite 表：`character_packs`（不可变包）、`character_instances`（实例指针）、`character_pack_history`（操作审计溯源）、`character_companion_timeline`（陪伴对话时间线）、`character_source_revocations`（来源撤销登记表）。
  - 实现 `previewDraft`：投影未激活草稿的完整包形态与潜在警告。
  - 实现 `activateDraft`：校验草稿状态与撤销来源，原子插入不可变包，更新实例指针并写入升级历史。
  - 实现 `rollback`：切换实例活动包指针；**铁律保障**：若目标版本引用了已被撤销的来源，直接拒绝回退。
  - 实现 `appendCompanionEvent`：将交互对话严格附加到当前配对的 Companion Timeline。
  - 实现 `ContinuityReadPort.getSnapshot`：依据配对范围检索活动包、过滤截止点与撤销事件的 Canon Timeline、以及隔离属于该实例的 Companion Timeline。
- `tests/memory/character-pack-activation.test.ts`：7 项测试用例，覆盖草稿预览、拒绝未通过草稿、激活与升级原子性、回退恢复、回退遭遇来源撤销被拒、A/B 实例隔离、双时间线读取与截止点过滤。
- `tools/acceptance-next07-03.mjs`：正式真实模型闭环验证脚本。
- `package.json`：更新 `"test:next07"` 覆盖全部 39 项连续性自动化测试。
