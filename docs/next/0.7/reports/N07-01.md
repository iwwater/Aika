## 2. 源码与模块变更

- `contracts/character-pack.ts`：定义来源快照（`SourceSnapshot`）、分块定位（`SourceBlock`、`SourceBlockLocator`）、角色草稿负载（`CharacterPackDraftPayload`、`CanonFact`）、草稿结构（`CharacterPackDraft`）、校验结果（`DraftValidationResult`）及错误类型（`CharacterPackError`）。
- `contracts/index.ts`：导出 `character-pack.ts` 契约，供系统统一调度。
- `memory/character-pack-source.ts`：实现基于 Unicode code point 的确定性段落与正文分块、章节提取（支持 Markdown `#` 及中文章节标题）、行号定位、单文件限制校验（2MB、合法扩展名、禁止路径穿越）与 SHA-256 哈希计算。
- `memory/character-pack-validator.ts`：实现证据引用与草稿合法性校验器（`validateDraftEvidence`）。严格拒绝伪造引用、越界定位、未登记证据 ID 以及无依据的原作事实。
- `memory/character-pack-store.ts`：基于现存 SQLite 数据库的草稿持久化存储器。创建 `character_pack_sources`、`character_pack_source_blocks`、`character_pack_drafts` 三张表；通过立即事务（`immediate`）实现原子写入；相同内容哈希的来源导入具备幂等性；支持进程关闭与重启后的完整数据还原。
- `providers/character-distiller.ts`：正式提炼器。接入 `ProviderTransport` 与已有配置；在 Prompt 中枚举并强制引用真实区块 ID；支持 `AbortSignal` 协作式中断；模型异常或证据校验不通过时只生成 `rejected` 状态草稿，绝不污染活动包。
- `tools/acceptance-next07-01.mjs`：正式真实模型闭环测试工具，替代临时探针脚本。
- `package.json`：新增 `"test:next07"` 确定性测试脚本，并将 `"test:next07:real"` 接入正式工具链。
