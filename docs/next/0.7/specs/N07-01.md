# N07-01 · 来源快照、证据和 Character Pack 草稿

状态：**AUTO_PASS（受控自动闭环；0.65 人工验收继续暂缓）**；前置：N07-00。

交付本地 TXT/Markdown 的受控 source snapshot、稳定 block hash/locator、Character Pack draft schema 与持久化接口。复用当前 SQLite 迁移和事务边界，不另建运行时数据库；草稿、活动版本和来源撤销修订分开存储。将已验证探针迁移为正式 `CharacterDistiller`。

## 1. 确定性门槛与通过标准

- [x] **AC-01-A（来源快照与分块）**：支持本地 TXT/Markdown 导入，Unicode code-point 级别精确定位与正文分块；支持 Markdown 及中文章节提取，单文件上限（2MB）、合法后缀与路径安全校验。
- [x] **AC-01-B（来源导入幂等）**：相同 characterId 与相同 content_hash 的资料重复导入时，返回既有快照与 duplicate 标识，无多余行落库。
- [x] **AC-01-C（证据定位与校验）**：每个 Canon 事实必须引用真实已登记的区块 ID；伪造引用、缺少引用、定位越界及非法 schema 均判定为 invalid 并拒绝作为有效草稿。
- [x] **AC-01-D（草稿原子持久化与重启恢复）**：基于现有 companion SQLite 库创建草稿与来源表，写入采用立即事务（immediate transaction）；写入失败不留半成品；关闭连接重新打开可完整读取草稿及所有关联来源。
- [x] **AC-01-E（正式 CharacterDistiller）**：接入现有 `ProviderTransport` 与 `EndpointConfig`，支持 `AbortSignal` 取消控制；模型输出异常或校验不通过时降级为 rejected 草稿，不污染活动版本。
- [x] **AC-01-F（受控真实回放）**：使用 `gemini-3.1-flash-lite-preview` 执行 2 次调用闭环（提炼 + 对话），验证持久化与重启恢复，指标记录于 [N07-01-real.md](../reports/N07-01-real.md)。
