# N07-02 · SourceProvider 与可替换 CharacterDistiller

状态：**AUTO_PASS（受控自动闭环；0.65 人工验收继续暂缓）**；前置：N07-01。

交付 `CharacterSourceProvider`（本地 TXT/Markdown 与显式 HTTP Wiki）和 `CharacterDistiller` adapter。模型调用经 0.65 resolved binding 与统一授权接入；结构化结果必须经过本地 schema/evidence/cutoff 校验。模型失败、取消、超时或输出缺证据时只产生失败草稿，不污染活动包。

## 1. 确定性门槛与通过标准

- [x] **AC-02-A（TextSourceProvider 与本地文件）**：支持 inline text 与本地 .txt/.md 文件加载；非法扩展名、不存在文件均抛出受控 `CharacterPackError`。
- [x] **AC-02-B（HttpWikiSourceProvider 与安全清理）**：支持显式 HTTP(S) Wiki 网页拉取；默认拦截私有 IP/SSRF；剔除 script/style/nav/footer/注释，转换 Markdown 标题，解析 HTML 实体；检测登录墙（login wall）与内容过短并显式报错，不伪造成功。
- [x] **AC-02-C（0.65 ResolvedBinding 接入）**：`CharacterDistiller` 支持消费 0.65 的 `ResolvedBinding` 与 `keyResolver`，完成多源模型解耦与统一调度。
- [x] **AC-02-D（剧情截止点 cutoffPoint 拦截）**：支持剧情截止点计算与校验；引用超出截止点的区块直接判定为 `invalid` 并记录 cutoff 违规错误。
- [x] **AC-02-E（事实分类与推测隔离）**：事实必须带有 `explicit`、`inferred` 或 `disputed` 状态标记；未知状态拒绝；无来源推断不能提升为 Canon 事实。
- [x] **AC-02-F（端到端 SourceRefs 提炼）**：`distillFromSourceRefs` 一键协调拉取来源、导入 SQLite 存储、切分定位、模型提炼与草稿落库。
- [x] **AC-02-G（受控真实回放）**：同一短资料经过真实模型（`gemini-3.1-flash-lite-preview`）提炼，获得非空 Soul、带真实区块引用的 Canon 条目与明确的 gaps（知识缺口）分析；回复中诚实指出未提及的经历，不编造共同历史。记录于 [N07-02-real.md](../reports/N07-02-real.md)。
