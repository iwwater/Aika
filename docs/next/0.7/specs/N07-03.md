# N07-03 · Pack 生命周期与双时间线读取

状态：**AUTO_PASS（受控自动闭环；0.65 人工验收继续暂缓）**；前置：N07-01。

交付草稿预览、显式激活、升级、回退和角色实例隔离。Canon Timeline 与 Companion Timeline 使用不同 kind/排序键和来源，按剧情截止点、角色知情状态和活动 pack 版本过滤。回退旧 pack 不能绕过来源撤销修订。

## 1. 确定性门槛与通过标准

- [x] **AC-03-A（草稿预览 previewDraft）**：支持草稿在未激活状态下的完整包投影预览，输出警告列表（未验证状态、已撤销来源等），不提前落库为正式角色包。
- [x] **AC-03-B（显式激活与不可变版本）**：草稿必须通过校验（`status: validated`）方可激活；以立即事务原子落库为不可变 `CharacterPack`，自动绑定目标实例指针；拒绝非法草稿激活；禁止同版本号覆盖。
- [x] **AC-03-C（版本升级与历史溯源）**：在同一实例上激活新版本草稿自动触发升级流，实例指针更新，并在 `character_pack_history` 中完整保留从旧包到新包的升级记录。
- [x] **AC-03-D（版本回退与撤销约束）**：支持将实例活动指针原子回退至旧版本；**严格执行撤销保护规则**：若目标旧版本引用的来源已于后续被撤销，回退请求直接拒绝并抛出 `version_conflict`（回退不可绕过来源撤销）。
- [x] **AC-03-E（A/B 角色实例隔离）**：同一角色下的不同实例（Instance A 与 Instance B）完全独立。升级 A 不影响 B；A 产生的陪伴交互记忆（Companion Timeline）绝不泄漏至 B。
- [x] **AC-03-F（双时间线读取与过滤 ContinuityReadPort）**：Canon Timeline 按原作叙事偏序（`ordinal`）升序排列，支持按剧情截止点与知情状态过滤，排除已撤销来源事件；Companion Timeline 按交互现实时间（ISO timestamp）升序排列，严格限定在当前配对内。
- [x] **AC-03-G（受控真实模型回放）**：使用 `gemini-3.1-flash-lite-preview` 完成 2 次调用闭环；验证激活后的角色包与双时间线融合输入，模型准确识记用户邻居称呼并精确陈述原作事实，记录于 [N07-03-real.md](../reports/N07-03-real.md)。

详细验收数据与测试日志参见验收报告：[reports/N07-03.md](../reports/N07-03.md)。
