# N081-02 · 有界 Collection 样本库

状态：**AUTO_PASS（存储组件层）**；G3 实机可回放 NOT_RUN（属 N081-06）。验收报告 [reports/N081-02.md](../reports/N081-02.md)。前置 [N081-00](N081-00.md)、[N081-01](N081-01.md)。接口基线 [Collection 契约](../CONTRACTS.md)。关联 RPD N081-R05～R08、81-D/E/F。

## 实施

建立唯一 Collection 来源 owner，保存聚合 keyboard 片段、图片候选的受管副本/缩略图、来源/配对/授权修订/时间、清理状态和最小 tombstone。不得复用临时 Observation 缓存充当跨日库，不把图片正文复制到 Timeline 或 Memory。资产复制和记录提交应具备崩溃可恢复的一致性；幂等 key 能区分重放通知与不同时间再次使用同图。启动时清理过期内容和孤立临时文件后开放查询。

预算采用 [配置表](../TEST_PROFILES.md)：normal 7 天/1 GiB，smoke 10 分钟/64 MiB；单图 20 MiB/40 MP 固定。容量含副本、缩略图和索引；先达到 TTL/容量上限即按确定性规则清理或拒绝新项，显示原因。用户原图绝不由 Collection 删除。单条、时段、清空、来源撤销均传播到受管资产、缩略图、索引、Timeline 投影和后续可引用派生物；旧任务/补扫/重启不得复活已删样本。存储升级须包含旧库和回滚/恢复验证。

## 接口设计与责任范围

拟由 `memory/collection-store.ts` 提供 `appendKeyboard(grant,sample,idempotencyKey)`、`appendImage(grant,candidate,idempotencyKey)`、`list(CollectionQuery)`、`readAsset(pairing,sampleId,variant)`、`feedback(...)`、`recordMissing(pairing,kind,observedAt,operationId)`、`erase(item|range|all|source,expectedRevision,operationId)`、`expire(now)`、`stats(pairing)` 和 `close()`。append 返回 `inserted|duplicate|rejected` 及 sampleId/reason，调用者不可凭文件通知自行宣布采集成功。漏采标注不创建伪样本。所有写入核对 grant 的配对/修订和 tombstone；读资产再次核对配对、有效期及失效状态。N081-06 的管理 port 与 Timeline 只消费这些公开方法，不直接查询私有表。

本步负责同一个 SQLite owner 下的 grants/samples/assets/feedback/tombstones/counters 迁移和受管资产目录。文件先写受管临时区、校验、转正，再让索引可见；崩溃恢复清孤儿且不向用户原图写入。内容 hash 只给同配对资产去重，不当事件 ID；来源 idempotency key 由 N081-03～05 按各自通知身份提供。本步不负责 native listener、模态 UI、事件语义推断或 0.8 Observation 持久化。

## 验收

- 受控存储测试覆盖写入/查询/重启、相同通知重放、不同时间同内容、乱序、提交前崩溃、孤立文件、满盘、TTL 和容量先后触顶；自动时间用 fake clock。
- 删除/撤销/清空后重启与重放仍不可见、无法读取副本；原始用户文件字节与路径保持原状。授权代次在提交前复验。
- 只用测试数据根运行自动化，不清理用户实际截图目录。报告 `reports/N081-02.md` 列表结构、迁移/恢复、预算计数算法及生产组合根待接线项；本步通过不表示 G3 已过。
