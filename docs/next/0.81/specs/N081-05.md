# N081-05 · 剪贴板图片与双通道去重

状态：**AUTO_PASS（组件层 + helper staging 通道）**；真实剪贴板与真实截图工具 NOT_RUN（属 N081-06 G5）。验收报告 [reports/N081-05.md](../reports/N081-05.md)。前置 [N081-01](N081-01.md)、[N081-02](N081-02.md)、[N081-04](N081-04.md)。接口基线 [Collection 契约](../CONTRACTS.md)。关联 RPD N081-R04/R05、81-C。

## 实施

订阅 Windows 剪贴板变化，只在图片来源授权启用后读取支持的图片格式；不读取普通文本、HTML 或文件列表正文。首次启用不摄取当时已存在的内容。收到变化后保存版本/序号，受占用时有界重试，每次读取前后复验版本；若已变更，旧通知作废。复制网页图与截图不可凭剪贴板通道区分，来源为 `clipboard/unknown`；具备可靠相邻文件证据时才关联到同一截图事件。

目录与剪贴板之间用归一化内容摘要、授权配对和时间窗口做**同一次捕获关联**；normal 5 秒、smoke 2 秒。相同内容在稍后再出现应保留新事件并共享资产引用，不无限复制；近似像素/pHash 只能提示可能重复，不能直接合并不同证据。双通道到达乱序、容器格式差异和时间错配均有明确 uncertain/repeated 状态。不得向外传剪贴板正文或触发云解析。

## 接口设计与责任范围

本步的后端 `ClipboardImagePort.start({grantId},onChange)` 只上报 Windows clipboard sequence 和观察时间。`readImageIfCurrent(sequence)` 的**服务端封装**从 helper 取得一次性 stagedAssetId、复验授权并读取受管 staging，才向 `CollectionService` 返回受支持图片 bytes/mime 或 null；helper NDJSON 只传 stagedAssetId/尺寸，不传 bytes，更不返回 text/HTML/files。读取前后 sequence 不同则返回 null 并计入 `stale_clipboard`；源幂等 key 为 grant/revision + sequence。占用最多重试 3 次、总计不超过 1 秒，每次复检 sequence；队列受 policy 的 32 项/64 MiB 或 smoke 4 项/24 MiB 限制，不能无限追赶旧版本。

本步还提供 `CollectionService.correlateImage(candidate)`：输入同配对、两来源各自授权有效的文件/剪贴板图片摘要和时间，只在精确等价、关联窗口内且一对一无竞争时**投影合并显示**；返回 `{decision:'same_capture'|'separate'|'uncertain',sampleIds}`。两条底层来源证据不合成不可拆的记录，以便撤销任一来源后重算投影。另一次复制保留新样本，受管资产可共享；近似 hash 仅用于标记。Timeline/管理页消费结果，不再自行做去重。本步不读普通剪贴板文本、不认定剪贴板图片必是截图，也不提供 OCR/VLM。

## 验收

- fixture 和真实剪贴板通知测试版本变化、占用、空/文本/HTML/文件列表、纯图片、同图重复复制、双通道先后到达、同像素不同编码、近似但不同图、授权/锁屏时竞态。
- 使用实际截图工具验证仅剪贴板和文件+剪贴板双通道；另复制普通网页图片，确认不强标 screenshot。相同一次捕获只显示一条经历，不同次使用保留分开的事件。
- 剪贴板读取/去重失败有计数且不阻断 keyboard/目录正常采集。报告 `reports/N081-05.md` 标出自动与实机结论以及误合并/漏合并样本。
