# N081-04 · 指定目录的新截图

状态：**AUTO_PASS（含真实文件 watcher）**；真实截图工具与正式组合根 NOT_RUN（属 N081-06）。验收报告 [reports/N081-04.md](../reports/N081-04.md)。前置 [N081-01](N081-01.md)、[N081-02](N081-02.md)。接口基线 [Collection 契约](../CONTRACTS.md)。关联 RPD N081-R03/R05、81-C 文件部分。

## 实施

只监听用户明确选定、规范化且实路径仍在授权边界内的目录；初次启用不导入旧文件，不扫描整盘。文件通知是“候选”，不是成功截图：校验扩展/格式、两次元数据稳定与可解码，再按单图 20 MiB/40 MP 上限复制受管资产。稳定检查最短间隔在 N081-00 后冻结，normal/smoke 相同；半写、损坏、超限、目录移动、越界重解析点或循环符号链接均拒绝并计数，不默默扩大权限。

保留文件首次观察、稳定读取和上下文采样时间；窗口可能已切换，不把读取时前台程序确定为截图来源。重复通知幂等，Watcher 丢事件时只在同一有效授权期内有界补扫；暂停期间、启用前文件永不补录。用户原文件只读，不因样本删除而移除。

## 接口设计与责任范围

本步在正式后端实现 `ScreenshotDirectoryPort.start({grantId,canonicalRoot},onCandidate): Promise<CollectionSourceLease>`，候选仅带 `opaqueFileRef` 与 `observedAt`，不通过公开事件总线传播真实路径。服务端内部另有 `resolveCandidate(opaqueFileRef,grant)`，每次读取前/后核验 realpath 仍属于 grant.directoryRoot，两次 size/mtime 至少间隔 1 秒且稳定并可解码，产出只在进程内存中流转的 `{bytes,mimeType,fileVersion,firstSeenAt,stableAt}`；源幂等 key 为 grant/revision + 文件身份/版本，不使用图片 hash 代替事件身份。目录 watcher 不依赖 keyboard helper，后者不可用时此来源仍可独立运行。

`CollectionService` 校验尺寸与当前授权后调用 N081-02 `appendImage`；N081-05 只消费其受控图片摘要/时间做跨源关联。该 port 不扫描历史图库、不删除用户原图、不把 watcher 事件直写 Timeline。N081-06 负责正式组合根和设置页目录选择。

## 验收

- 使用真实文件 watcher 的临时目录测试分块写入、完成后解码、损坏图、同名覆盖、重复通知、超限、符号链接/重解析点、目录失效及启用前旧文件；只有稳定合法的新文件可入库。
- 授权暂停/撤销后旧 watcher 和排队项不能提交；按多次重启检验去重与有限补扫。不对原图写入或删除。
- 实机至少使用一种实际截图工具把图片写到选定测试目录，记录工具、格式、时间错配和采集时延；测试脚本单独写图不算截图工具覆盖。报告 `reports/N081-04.md` 区分两者。
