# N081-03 · Windows keyboard 活动聚合

状态：**AUTO_PASS（含真实 native 实机）**；正式组合根接线与锁屏实机 NOT_RUN（属 N081-06）。验收报告 [reports/N081-03.md](../reports/N081-03.md)。前置 [N081-01](N081-01.md)、[N081-02](N081-02.md)。接口基线 [Collection 契约](../CONTRACTS.md)。关联 RPD N081-R02、81-B。

## 实施

在当前 Windows 交互会话接真正的键盘活动来源，区分 keyboard 与综合输入闲置；`GetLastInputInfo` 只能辅助 AFK，不能冒充 keyboard。具体 native 方案由本步对桌面主进程/包生命周期核实后选定，原始通知在 adapter 内只增加计数/活动时间，不向 IPC、Event Hub、日志或数据库传键码、字符、组合输入或逐键顺序。无法观察时报告 unavailable，不用鼠标运动填补键盘事件。

按 policy 生成活动桶和静默片段，锁屏/睡眠/配对变化清空 ring；前台应用仅作为采样时上下文，窗口标题默认关闭。游戏/快捷键仍标键盘活动，不推断正在写文本；IME 语言不能可靠取得则 unknown。只有聚合片段进入 N081-02 存储，采集任务不启动 Turn、模型或云请求。

## 接口设计与责任范围

本步实现 [契约](../CONTRACTS.md#3-原生输入端口与服务端口)中的 `KeyboardActivityPort.start({grantId,policy},onActivity): Promise<CollectionSourceLease>`，系统句柄由 N081-00 冻结的受控 helper 持有。跨进程 callback **只能**给 `{bucketStart,bucketEnd,activityCount,foregroundAppId,afkBoundary}` 和 grant/revision；键码、扫描码、字符、composition 与逐键时间戳不得进入 TypeScript 公共端口、NDJSON、Event Hub 或日志。`CollectionService` 在回调内复核授权后调用 `CollectionStore.appendKeyboard`，幂等 key 为 grant/revision + 桶起点 + policyVersion。

范围包括无输入/鼠标-only 与来源不可用状态、锁屏释放和重新启用；不包括窗口标题默认读取、正文/语言识别、截图、管理 UI。`GetLastInputInfo` 只辅助综合 AFK，不能作为本接口的 keyboard 事件提供者。N081-06 负责将此 port 与正式产品组合根装配。

## 验收

- fake clock 测试 normal 10 秒桶/5 秒静默/5 分钟 AFK 与 smoke 1 秒/2 秒/15 秒；鼠标-only 不生成 keyboard 活动，锁屏/恢复、暂停及迟到回调不能补写。
- 在 adapter → IPC/事件 → 存储/Trace 的序列化边界检查无键码、字符、逐键序列；日志与崩溃诊断也不得输出正文。不同输入来源不可用状态如实区分。
- 实机至少在普通编辑器和一组快捷键/游戏输入场景验证“活动事实”；检查受管库不含实际输入文字。设备/权限不可用记 BLOCKED，fixture 通过不可代签。报告 `reports/N081-03.md` 记录真实 native 接入和资源释放证据。
