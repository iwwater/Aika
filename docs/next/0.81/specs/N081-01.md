# N081-01 · 来源授权与生命周期

状态：**AUTO_PASS（组件层）**；正式管理端授权与 G2/G4 实机 NOT_RUN（属 N081-06）。验收报告 [reports/N081-01.md](../reports/N081-01.md)。前置 [N081-00](N081-00.md)。接口基线 [Collection 契约](../CONTRACTS.md)。关联 RPD N081-R01/R07、81-A/E。

## 实施

增加与单帧 `CaptureGrant` 独立的持续 Collection 来源授权，分别覆盖 keyboard、指定截图目录、剪贴板图片。授权绑定当前用户×角色实例、来源及真实目录、本地留存用途、策略版本、修订和到期；默认无授权。设置草稿与实际启用分离，目录更换、配对切换、保留用途或本地目的地变化使旧授权失效。不得把 0.8 单次屏幕 grant 当作持续监听凭据。

由宿主/包资源生命周期统一启停 listener。暂停立即停止新事件并递增代次，恢复仅在同一仍有效的授权范围内；停止保留按 TTL 管理的旧样本，撤销清理未晋升样本及其投影。锁屏、睡眠、Windows 用户会话变化、退出、包停用或实例切换均停止并释放资源；解锁/重启不自动续采。迟到读取在**采集前、写库前、投影前**复验当前代次。限定回补只能覆盖同一有效授权期间的指定目录，不能抓启用前/暂停期间的文件。

## 接口设计与责任范围

拟由 `core/collection-grants.ts` 提供 `CollectionGrantManager.issue({pairing,kind,directoryRoot?,expiresAt,policyVersion,expectedRevision,operationId})`、`transition({grantId,action,expectedRevision,operationId})`、`assertActive(grantId,revision,pairing,kind)`、`current(pairing,kind)` 和 `close()`；返回 `CollectionGrant`/明确冲突或失效错误。`action` 仅 `pause|resume|stop|revoke`，每次状态变更增加 revision，operationId 重放返回同一结果。`resume` 只在原范围仍有效时恢复，目录/配对变化需新 grant。具体持久记录由 N081-02 的 `collection_grants` owner 提供，不在 manager 里另造未落盘状态权威。

本步还定义包/桌面层的 `CollectionSourceLease.close()` 与 `HostResourceRegistrar` 资源 ID 绑定：一种来源最多一个当前 listener；暂停、撤销、锁屏或停包时 await close 后再报告已停止。N081-03～05 实现各来源 lease，N081-06 通过管理 port 调用。范围不包括目录解析、剪贴板 bytes、样本查询、管理页面、OCR/VLM。0.8 的 `CaptureGrantManager` 保持原权限和 API，不隐式复用。

## 验收

- fake clock/受控 adapter 测试默认关闭、各来源开关互不影响、授权过期、旧修订拒绝、跨用户/角色实例不能读取或写入、单帧授权不能升级、暂停后迟到写入为零。
- 资源测试核对每次暂停/撤销/锁屏/包停用后键盘、目录、剪贴板 listener 均释放；重复停用幂等。用户重新启用后只接收新事件。
- 正式管理端尚未交付时本步只记组件 AUTO_PASS；产品授权 G2/G4 等 N081-06 接线。报告 `reports/N081-01.md` 明确授权持久化位置、审计字段与真实/模拟事件区别。
