# 0.81 正常与快速测试配置

状态：**SPEC 预设，尚未实现**。日期：2026-09-25。[执行索引](SPEC.md) · [RPD 默认值](RPD.md#42-首版试运行默认值)。此表定义实施时必须提供的有效策略，不冒充当前已有环境变量或 UI 开关。所有数值以单一 policy 对象解析、校验、记录策略版本；测试覆盖配置装载和拒绝非法值。

| 策略 | 正常运行 `normal` | 快速验证 `smoke` | 理由 |
| --- | --- | --- | --- |
| 键盘活动桶 | 10 秒 | 1 秒 | 更快观察区间产生，不改变“无正文” |
| 键盘静默结束 | 5 秒 | 2 秒 | 快速检验片段边界 |
| 综合无输入 AFK | 5 分钟 | 15 秒 | 现场可观察 AFK 切换；仍不能把鼠标算 keyboard |
| 上下文 ring | 3 分钟、1,000 项 | 30 秒、100 项 | 验证清空和容量边界 |
| 样本元数据/受管图片 TTL | 7 天 | 10 分钟 | keyboard 片段和图片均有界；确定性自动测试使用 fake clock，无须等 10 分钟 |
| 单次来源授权最长有效期 | 7 天 | 30 分钟 | 授权过期停止新采集，不等于删除既有未过期样本；可选择更短期限 |
| 受管图片总容量 | 1 GiB | 64 MiB | 快速触发容量清理，不改变原图所有权 |
| 解析排队上限 | 32 项 / 64 MiB | 4 项 / 24 MiB | 可容纳一张上限内的 20 MiB 图片，同时较快触发满队列 |
| 文件与剪贴板关联窗口 | 5 秒 | 2 秒 | 缩短双通道现场复测等待；相同内容不同次出现仍保留事件 |
| 单图尺寸 | 20 MiB、40 MP | 同正常 | 解码安全边界不因测试放宽 |
| 文件稳定判定、路径范围、版本复检 | 两次 size/mtime 读取至少间隔 1 秒且可解码 | **同正常** | 快速配置不能把半写文件误收为有效样本 |
| 剪贴板占用重试 | 最多 3 次、总计不超过 1 秒，每次复检 sequence | **同正常** | 快速配置不摄取已经变化的旧图片 |
| 目的地和权限 | 本地；每来源显式启用，锁屏/暂停/撤销拦截 | **同正常** | 只缩短测试等待，不降低授权条件 |
| 云调用、自动邀请、自动长期晋升 | 全部关闭 | **同正常** | 采样与理解/发言/记忆分离 |

`smoke` 必须由开发/测试启动参数显式选择，使用独立的本地测试数据根和独立授权记录，控制台持续标明“快速测试配置”；产品启动默认固定为 `normal`。实施可选项目现有配置加载机制，但不把测试配置写入普通用户偏好，也不让运行中的服务无提示热切换。`smoke` 的来源目录只能是用户明确选定的测试目录；不自动指向真实 Pictures/Screenshots 或任意历史图库。退出 smoke 后由测试工具只清理**该测试数据根的受管副本**，原始截图不受影响。

为便于执行，N081-00 应落两个脚本入口：拟议 `npm run test:next081` 跑 fake-clock/契约/存储/正式组合根自动化；拟议 `npm run dev:next081:smoke` 由 `tools/run-next081-smoke.mjs` 创建独立临时数据根、启动正式 Windows 产品并在控制台显示 profile/目录/授权状态。两者目前**均不存在**；实际脚本名若遵循现有工具规范调整，须同步本表、SPEC 和报告。smoke 启动不自动签发来源 grant，测试者仍从 Settings 选择测试来源并启用。正常产品启动不继承 smoke 参数。

自动单元测试通过注入时钟推进 1 秒、2 秒、15 秒、TTL 和撤销竞态；时间相关断言不依赖实际 sleep。真实 Windows 现场 smoke 使用上述短阈值验证监听、锁屏、文件稳定和界面响应。N081-07 的 3 日/8 小时自然样本只能用 `normal` 统计，smoke 样本单列为受控测试数据，不计入自然使用覆盖率。

额外压力用例可在临时测试根中显式覆盖**更小**容量/队列上限，迫使拒绝和清理发生；覆盖值必须写在测试报告中，不得扩大采集范围、保留期、权限或默认行为。无论配置如何，测试失败时均释放监听资源、撤销测试授权并保留可定位的脱敏错误记录。
