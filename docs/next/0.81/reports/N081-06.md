## 4. 控制台入口与隐私边界
- 入口位于**配置 → 本地采集与留存**（`settings/section=collection`），与「隐私与授权感知」并列，**不放在 Developer 分区**——权限控制不能只给开发者。
- 页面首屏即声明：默认关闭、键盘只记活动区间不含按键内容、图片副本在本机受管目录、用户原图永不被本模块删除、当前配置档（normal / smoke）。
- 三来源各自独立卡片：状态、授权修订、授权截止、已授权目录（仅本机鉴权页可见）、最近采集时间、accepted/duplicate/rejected/dropped、最近错误码；操作按钮按状态给出（启用 / 暂停 / 继续 / 停止 / 撤销并删除）。
- 未接线来源显示**不可用**并说明原因，不提供无效开关。
- 缩略图经 `requestImage()` 带 Bearer 读取后转 object URL：`<img src>` 无法携带鉴权头，因此不走裸 URL。离开页面或重新加载时 `revokeObjectURL`，不留下悬挂引用。
- 删除与清空都经 `window.confirm` 二次确认；撤销单独提示会删除该来源样本。

## 5. 本步发现并修复的真实缺陷

**错误码在转换中丢失**：`CollectionGrantManager` 抛 `CollectionGrantError`，其机器码在 `code` 属性上、`message` 是人话。`safeCollectionError` 初版只读 `message`，导致所有类型化拒绝（含 `version_conflict`）都退化成笼统的 `unavailable`，管理端无法区分"需刷新"与"系统故障"。已改为优先读 `code`，并把 `CollectionStore.update` 的裸 `Error('revision conflict')` 统一为稳定 token `version_conflict`。

同类假阳性也一并修正：测试原先用子串扫描断言"响应不含 `character`"，会被合法的 `characterId` 命中，已改为按字段名断言。

### 8.3 实机运行中发现并修复的三个真实缺陷

实机测试的意义在于暴露自动单元测试无法察觉的跨组件缺陷。本步在真实产品中测出并修复了以下三项：

1. **helper 产物路径解析错误**：
   `collectionHelperPaths(configuration.projectRoot)` 收到的 `projectRoot` 是工作区根（`windows/`），而 helper 构建在 desktop-pet 包的 `dist/` 下，导致真实启动时报 `unavailable`。已修复为 `resolveHelperPackageRoot()` 从模块自身位置解析包根。
2. **`HWND_MESSAGE` 无法接收 `WM_CLIPBOARDUPDATE`**：
   剪贴板监听器使用消息窗口时，`AddClipboardFormatListener` 返回 1（成功），但 Windows 系统广播从不投递到消息窗口，导致实际永远收不到剪贴板变化通知。已修复为使用顶级隐藏无激活窗口（`WS_POPUP | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | SW_HIDE`），实机复测成功收到通知。
3. **剪贴板 BMP 格式契约错配**：
   Windows 剪贴板通过 DIB 交付图片，helper 将其暂存为自描述的 `.bmp` 文件，但 `CollectionStore` 早期契约只接受 PNG/JPEG/WebP，导致所有真实剪贴板图片被判定为 `unsupported_image_format`。已在 `contracts/collection.ts` 补充 `SupportedImageMime`，在 `CollectionStore.detectImageMime`、`extensionFor`、`normalizeMime` 及 `probeImageDimensions` 完整支持 BMP，实机复测成功入库并提供资产下载。
