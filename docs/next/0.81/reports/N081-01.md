## 4. 状态机与代次语义

```text
(无) --issue--> active --pause--> paused --resume--> active
                 |                  |                 |
                 |                  +--(到期)--> expired
                 +--stop--> stopped
                 +--revoke--> revoked   (终态：只能重新 issue)

active/paused + 时钟越过 expiresAt  => expired（停止新采集；既有样本按各自 expiresAt 清理）
```

- 每次状态变更 `revision+1`；`assertActive` 要求调用方给出的 `grantRevision` 与当前一致，因此**采集前、写库前、投影前**任一处复检都能拦下被取代的通知。
- `expiresAt` 受 `policy.grantMaxDurationMs` 硬上限约束：normal 7 天、smoke 30 分钟；用户可选更短。配置档切换不能沿用旧 grant（smoke 上限更短，必然拒绝 normal 长度）。
- `pause` 立即停新事件并递增代次；`resume` 仅在原范围仍有效时恢复，且到期后拒绝；目录/配对变化必须走 `issue`。
- `revoke` 是终态，语义上对应“撤销该来源并失效其来源证据”，具体样本清理由 N081-02 执行。`stop` 与 `revoke` 是**不同动作**，符合契约第 4 节。

## 5. 资源生命周期接线

`attachLease(binding, registrar)` 把来源 lease 绑定到：
- manager 内的单一 live lease（每 kind 至多一个）；
- 宿主 `HostResourceRegistrar.register('listener', 'collection:<kind>:<grantId>', release)`（`contracts/plugin.ts:390` 既有接口）。

释放路径统一为 `release()`：先摘除内部记录，再 `await binding.release()`，最后若仍在 `outstanding` 中则 `registrar.release(id)`。`close()` 幂等。锁屏/睡眠/会话变化/包停用/实例切换通过 `suspendAll(reason, pairing)` 一次释放全部 lease 并把 `active` 授权转 `paused`——**解锁/重启不自动续采**，用户必须显式 resume 或重新 issue。

`CollectionSourceLease.close()`（`contracts/collection.ts`）是 adapter 侧形状；N081-03～05 实现具体 lease，N081-06 通过管理 port 调用。
