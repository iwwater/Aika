## 4. 脚本的读取边界

`tools/next081-trial-report.mjs` **只**调用两个只读接口：

- `GET /api/collection/status` → 来源状态、计数、受管字节、队列深度、profile、策略版本；
- `GET /api/collection/samples?from=&to=&limit=&cursor=` → 时间窗内分页的有效样本**元数据**（不含图片字节）。

它**不**：扫用户截图目录、打开 SQLite、读 helper staging、绕过授权、写任何采集状态。人工标注与漏采由操作者通过控制台走 `feedback` / `feedback/missing`，脚本只汇总计数。这与 SPEC 的"日报只引用聚合计数、脱敏 sampleId 和来源状态，不附用户图片或键盘正文"一致。

报告字段中配对标识只保留首 8 字符（`instanceId`、`characterInstanceId`），授权目录**只记 `hasAuthorizedDirectory` 布尔值**而不落盘实际路径。
