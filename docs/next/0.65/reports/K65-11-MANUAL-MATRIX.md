> **验收范围与 0.75 边界说明**：
> 1. **排除项（留待 0.75）**：根据 [0.75 RPD](../../0.75/RPD.md)，主控制台、独立配置页及多级 Web 后台已明确列入“0.75 逐界面索取参考后全面重写”。因此**本轮 0.7 验收不考核临时 Web 控制台的视觉和布局**，只验证后端接口、数据存取与桌宠交互。
> 2. **本轮考核重点**：
>    - **桌宠本体前端与表现侧**：Live2D 渲染、基础动效（待机/眨眼/呼吸）、手势路由（左键轻抚/右键面板/拖拽）、鼠标穿透与尺寸滑块。

## 建议验收执行流程

1. **第一步（桌面表现）**：启动桌宠，肉眼观察 **PET-02（眨眼/呼吸动效）** 是否自然，测试 **PET-03（右键本体呼出面板、左键轻抚）** 与 **PET-04（穿透与快捷键恢复）**。
2. **第二步（语音链路）**：测试 **VOICE-01（边说边出字）**、**VOICE-03（TTS 听感与快速连发气泡同步）**。
3. **第三步（0.7 角色与灵魂）**：提炼/激活一个角色包，测试 **SOUL-01（说话风格与口吻）** 和 **SOUL-02（原作知情边界）**。
4. **第四步（连续性与遗忘）**：告诉桌宠称呼与秘密（**SOUL-03、SOUL-04**），多轮对话后验证其是否记住；随后执行纠正与遗忘（**SOUL-05、SOUL-06**），验证是否彻底忘干净。
