# K65-02A 自动验收报告

日期：2026-09-22；状态：AUTO_PASS；前置：K65-02 AUTO_PASS。

## 交付

实现 `windows/code/desktop-pet/plugins/provider-runtime.ts` 与 `plugins/legacy-slot.ts`：

- 注册并校验 `AdapterDescriptor`、`SourceInstance`、`ModelProfile`、`Binding`，同 capability 的多个 adapter、同 adapter 的多个来源和同来源的多个模型可以并存。
- 解析时固定 `sourceId/configRevision/modelProfileId/revision/binding revision`，生成不可变 `ResolvedBinding`；未知参数、能力不支持、禁用来源和缺少云端凭据明确拒绝，不做隐式 fallback。
- 支持 `remote-api`、用户所有的 `local-service` 和宿主管理的 `managed-local`；本地来源允许 `auth.kind: none`，云端只保存 credential reference。
- managed-local 按实例 single-flight 启动，租约归零时释放；local-service 只释放宿主自己的调用租约，不执行外部进程停止。
- 增加按来源并发/队列上限、排队取消、活动调用超时和迟到结果抑制；绑定修订固定在一次调用内，不跨来源重试。
- 增加旧七槽 `SlotBinding` 到五层 Provider 结构的纯迁移函数，ID 由旧记录稳定内容派生，重复迁移幂等，原 credential、模型、音色和预算字段可追溯。

没有把真实 LLM/TTS/STT 接入提前并入本步；真实来源回放分别由 K65-03/K65-05/K65-06 完成。

## 测试证据

新增 `tests/next65/providerRuntime.test.ts`，覆盖：

1. 同 capability 多 adapter、同 adapter 多来源、同来源多模型的解析和实例键隔离。
