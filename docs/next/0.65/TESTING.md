## 必需组合

| 场景 | 证据 |
| --- | --- |
| 只有宿主 | 可列包、返回缺普通包提示；无业务模型初始化 |
| 宿主 + 普通包 | 桌宠文字链路，无可选代码及专用依赖，不只是开关关闭 |
| + TTS / + STT / + 两者 | 四种组合独立走生产链，未选包缺席、无隐式设备调用 |
| 升级兼容组合 | 已验收文本/语音/Memory/Timeline/知识库/快照用例保留 |
| 第三个测试插件 | 只依赖公开 SDK、独立打包，宿主及普通包 hash 不变 |
| 故障与撤销 | 导入失败、初始化失败、超时、取消、更新/停用中在途回调、来源撤销不污染新轮 |

干净验证在工作区/临时目录创建独立安装目录，复制且仅复制声明的产物；启动进程 cwd 在该目录，清除指向开发树的解析路径，禁止借用工作区 node_modules。记录解析文件/进程/设备/初始化计数及产物清单；不删除开发环境依赖来模拟最小安装。目录重解析逃逸、依赖冲突和异常清理应覆盖 Windows 行为。

## 独立模块任务的验证范围

根 [AGENTS.md](../../../AGENTS.md) 是模块责任与影响范围规则。本版首次迁移仍按 SPEC 前置；基线已交付后的单模块/adapter 修复不重跑整个迁移序列。默认验证本模块、所改公共契约、直接消费者和一条必要接入链；更远影响必须有依赖或失败证据再扩展。
