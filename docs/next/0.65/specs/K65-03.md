## 1. 本步实现边界

从 trial-backend/DesktopRuntime/TurnController 抽取通用宿主入口，唯一轮次权威保留；PetPresentation、默认角色、桌宠 renderer/设置、LLM 适配与近期历史落普通包。不得以空 TTS/Memory 假实现满足旧强制端口；改成明确能力需求，文字路径不解析音频或长期维护模块。

普通包通过 01/02 公共入口注册，保持已支持文本 Provider 协议和配置迁移基础。提供默认串行文字流程，尚不做通用 DAG。缺 LLM 配置仍可显示桌宠和设置，不能声称对话成功。最近历史提供真实最小实现，持久化若需要轻量共享基础可复用，但不启动长期抽取。

生成内核与普通包独立便携目录产物、各自清单及新构建目标；剥离原 build 强制 WeChat/wake 和顶层 sherpa/silk 等可选依赖。Windows 宿主可依赖 Electron 执行平台，桌宠业务资产/代码归普通包，不能将整个 renderer 业务塞回 Kernel。

在离开开发树的临时安装目录，只复制宿主+普通包验证；旧组合作为迁移参考保留至 04 接续，不以旧入口跑通替代新宿主成功。
