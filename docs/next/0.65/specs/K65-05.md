## 1. 本步实现边界

把现有 TTS Provider、语音配置适配、音频交付/播放接入和专用依赖拆为 TTS 包；保持实际已支持协议，不新增音色克隆。普通包提供通用展示订阅，TTS 包承担语音输出，不能要求 STT 或麦克风。

通过默认文字/语音输出能力选择触发 TTS 惰性加载；配置页面和元数据发现不初始化。播放事件、停止、迟到回调及音频文件清理沿用 Scope 保障，失败不重发已交付文字或重写消息。

提供单包构建产物，桌面播放所需 renderer 适配随 TTS 包加载，通过受控 IPC/公开接口注册，不静态夹带在普通包。共享运行资源登记所有者。


### 多源 Provider 补充

TTS 按“公共输出接线 + 所选合成 adapter”交付，多个云端/本地 adapter 可共存。本版至少一个既有云端与一个本地实现真实生成音频；SAPI 可作已存在本地候选，但不是唯一可扩展 local 类型。voice/model/format 按来源校验，公共播放接收规范化音频描述，不混用音色或采样率。仅用云端不携带其他本地引擎依赖。 统一契约见 [PROVIDERS](../PROVIDERS.md)。
