## 1. 本步实现边界

实现本地包目录导入→staging 校验→原子安装登记、发现、启用意图和首次请求激活。已安装、启用、就绪、实际加载分开记录；元数据发现无执行。依赖先加载，同包并发请求 single-flight；依赖冲突/循环拒绝，缺资源提示而不联网安装。

实现公开 host capability 注册/选择、资源登记与退出清理。首次请求按依赖闭包加载，失败清理本次部分资源、保留他人使用的依赖；迟到初始化不得覆盖取消或新状态。宿主无普通包也可运行管理命令，但不假装能聊天。

本步提供最小导入/列出/启用/请求/关闭的程序或 CLI 入口，供后续自动使用。先实现整宿主关闭与失败释放；运行中停用/更新事务由 08 完成。用真实 ESM fixture 插件验证，不把生产业务迁入本步。


### 多源 Provider 补充

插件包激活只注册 Provider factory，不初始化所有来源/模型；把来源实例创建交给 02A。同 capability 多 factory 不能互相覆盖；重复身份才冲突。取消或失败时只清理本次取得的租约。 统一契约见 [PROVIDERS](../PROVIDERS.md)。
