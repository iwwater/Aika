## 1. 源码与实现边界

providers/slot-registry.ts 当前 SlotBinding 直接携端点/模型/凭据，protocol 只有有限内置值，校验强制 credentialRef 及部分计费参数；不能把它当作已具备本地无 Key、多实例管理。先核对 00 基线，再通过薄迁移适配保留已验收协议与设置。

实现 AdapterDescriptor、SourceInstance、ModelProfile、Binding 和不可变 ResolvedBinding。adapter 来自 01/02 插件注册；同能力多 adapter 合法，重名身份冲突拒绝。来源/模型/绑定各有稳定 ID 和修订，同一 adapter 多端点、同来源多模型、不同阶段多来源并存。迁移现有 SlotBinding，重复迁移不复制配置，不丢 credentialRef 与预算策略。

管理 API 先提供保存/读取/显式校验/解析和状态入口，图形操作由 09 接入。保存草稿不加载引擎；活动引用要求能力与资源匹配，列表成功不等于可推理。能力协商按 adapter 与模型特性交集，不按模型名称猜测，不静默忽略未知参数。

实现 remote-api、用户所有 local-service 和宿主管理 managed-local 的生命周期策略。测试使用真实生产 registry/loader 和可控本地服务/worker。local-service 停用只关闭自有连接；managed-local 延迟启动、租约、排空/取消、超时和关闭释放。不得构建通用模型安装器或修改用户已有服务进程。

按完整来源/模型/资源修订隔离实例缓存，连接与模型资源分别复用。固定来源策略，暂无自动 fallback 或并发竞速；切配置下一轮生效，权限撤销即时生效。健康状态按来源和模型/配置修订记录，不按 adapter 整包标绿。
