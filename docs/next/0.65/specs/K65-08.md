## 1. 本步实现边界

基于 02 导入登记和 07 活动依赖实现停用、卸载、替换更新、恢复。展示依赖者，活动流程引用时拒绝操作或由用户显式切回有效流程；不自动修改配置。先阻止新调用，再排空/取消在途，按依赖逆序释放。

首版代码更新/完全卸载采用重启生效：在途版本固定，新版本目录 staging 校验后登记 pending，关闭后切换并验证启动。失败恢复旧活动指针和兼容数据备份，不能混用两版。更新前记录变更和回退资源；不删除尚在用的版本目录。

停用采集与撤销权限立即停止设备，代码仍缓存则标待重启。默认保留包数据和撤销记录，单独清除不扩大范围。共享资源只在最后使用者离开释放。

验证单独兼容更新 TTS 包，普通包、STT、内核产物 hash 保持；不要求运行中热替换。


### 多源 Provider 补充

包更新/停用需要枚举该 adapter 的所有来源实例、模型租约及流程绑定；普通来源配置切换不重打包。用户所有 local-service 只能断开自有连接，不能 kill；宿主管理进程按租约释放，更新待重启状态仍准确。 统一契约见 [PROVIDERS](../PROVIDERS.md)。
