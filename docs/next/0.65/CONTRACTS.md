# 0.65 最小插件与包契约 v0.2

状态：执行设计，未实现。K65-00 核对实际符号，K65-01 落地公共类型与校验。以下逻辑名字不是现有源码导出，实际路径由 00 记录。优先薄适配；不复制另一套 Runtime。

## 1. 包产物与身份

首版采用本地目录包：根 manifest.json、编译后的 ESM 入口、静态资产及包内运行依赖。导入复制到宿主管理目录，校验后原子登记；不直接执行用户任意目录。压缩包/在线商店不是本版门槛。目录导入和单包打包命令必须可自动运行，不要求公开发布。

Manifest 必需信息：schemaVersion、packageId、version、hostApiRange、platform/arch/runtime 要求、plugins 清单（pluginId、entry、能力声明）、必需/可选 package 依赖及版本范围、资源与权限声明、文件清单/hash。能力声明包含 capabilityId、adapterId（若提供 Provider）、契约版本、输入输出描述与副作用类别。模型权重只作资源引用和就绪检查，不默认打包下载。

包身份与版本不可变；相同 ID/版本同内容重复导入幂等，不同内容冲突拒绝。单个安装配置中同 packageId 仅一个活动版本；不兼容依赖拒绝而非自动选任意版本。可选依赖不自动安装、启用或加载。发现只读元数据，不 import 入口。路径不得越过包根；首版拒绝符号链接/junction 等重解析项。导入阶段不执行 install 脚本。

内核、普通包、TTS、STT、兼容能力包各有产物与内容/依赖清单。允许同仓库开发，共享轻量 SDK 通过公共版本边界；宿主和普通包不静态/传递导入可选包私有实现。ESM/native 依赖在单包构建阶段准备，终端用户导入不需要编译整应用。hash 证明内容一致性，不冒充签名或不可信代码沙箱。

## 2. 插件宿主接口

逻辑入口 activate(hostContext) → pluginHandle，逻辑释放 deactivate(reason)；名称由 01 映射，语义必须一致。HostContext 提供有版本的能力注册/解析、既有轮次与 AbortSignal、受作用域限制的事件、配置/凭据引用、包数据命名空间、日志与资源登记接口。模型协议、业务 Prompt、桌宠动作不写入宿主。

内置与导入插件走同一路径。普通包插件不得因内置身份获得直接访问宿主私有对象的捷径。同一 capabilityId 允许多个 adapter/provider 提供；禁止重复 adapterId/pluginId 的冲突注册及隐式覆盖。通过 binding→modelProfile→sourceInstance→adapter 显式选源，不按导入先后选 Provider。服务定位不接受未声明依赖。

本版运行受信任本地插件，不承诺进程内代码的安全隔离；权限声明用于产品启用/设备及外部动作控制，不赋予配置文本执行脚本的能力。

## 3. 状态与生命周期

分别记录安装版本、启用意图、就绪条件、实际加载状态；不把它们压成一个布尔值。对用户至少能表达未安装、已安装未启用、启用待加载、已加载、失败、停用/更新待重启。

激活 Profile 时仅检查元数据、配置和资源可用性，不启动推理引擎；满足条件不等于运行已验证。首次实际请求加载已启用的依赖闭包，依赖先于消费者。并发首次请求只初始化一次；初始化失败清理本次部分资源，不破坏已加载共享依赖。动态故障仍须在实际调用时报告。

停用先阻止新调用，再等待在途结束或用户显式取消；按消费者先于依赖逆序释放。活动 Profile/其他插件依赖未解除时拒绝停用并列出影响，不静默改流程。共享资源到最后使用者释放。停止采集/撤销权限立即生效，不等重启。

代码卸载和升级采用重启边界：活动轮固定 package/version、Profile/config revision；更新只登记待生效版本，重启校验后切换。资源可先释放，但 ESM 模块仍缓存时状态不得声称代码已完全卸载。失败恢复最后有效版本；数据模式不兼容时必须恢复配套备份，禁止只回退代码直接打开新模式库。

超时默认值在 00 按实际关闭行为登记并在 01 固定为有上限策略；超时不给副作用操作自动重试。释放失败标明未完成并允许可诊断恢复，不虚报成功。

## 4. 轮次、事件与数据

沿用既有 Scope/session/turn/generation、取消和迟到过滤权威。从 TurnController 提取通用部分可以改变目录，不得并存两个分配轮次的控制器。展示层订阅事件；硬编码角色、PetPresentation、播放细节属于普通/输出包适配。

终态恰好一次，终态后无有效输出；持久化和输出副作用使用原稳定标识。长期记忆包缺席时普通包仍有最小近期历史及身份，不提供伪 Memory 成功返回。升级兼容组合复用原持久化权威和撤销记录，不创建竞争队列。

包卸载默认保留数据；清除为独立操作。长期来源包停用后，已注入的来源片段和快照须失效，不能靠保留旧快照继续使用该包知识。来源撤销先于缓存与后台写回，重装/回退不能恢复被忘记事实。

## 5. Flow Profile 与阶段

首版 Profile 为版本化 JSON：id/revision、节点与能力绑定、依赖边、条件、必需/可选结果、汇合顺序、失败策略。每个节点固定声明输入/输出及副作用；条件只用受限比较/存在性规则，不 eval 脚本。无环；写入/播放/动作默认串行且不自动重试。

默认串行流程先在普通包成立，再由 07 引入通用 DAG 执行。并行仅用于无写冲突只读节点；汇合按声明顺序与规则而非完成顺序。安全/隔离/撤销守卫由宿主或必需能力契约保障，不能通过删节点绕过。

Context 来源经过作用域、有效性、预算和去重后组合。稳定前缀与动态后缀沿用 0.61 实际语义；包版本/启停改变可用来源时失效旧快照。当前轮配置固定，但撤销即时检查。基本事件诊断从 02/03 产生，09 只做管理与展示，不另建事实源。

## 6. 多源 Provider

[PROVIDERS.md](PROVIDERS.md) 是本契约的规范补充。能力、adapter、来源实例、模型/音色配置与槽位/阶段 binding 分层；同能力多个云端/本地实现可共存。部署方式 remote-api/local-service/managed-local 不与协议绑定；本地来源允许无凭据和无云计费字段。只有所选来源初始化，不加载一个功能的全部引擎。

K65-01 冻结多源 schema，K65-02A 在业务包拆分前实现解析与实例生命周期，03/05/06 验证 LLM/TTS/STT 实际来源。旧 SlotBinding 迁移为稳定来源与模型引用，保留单一配置权威；不是新增另一套七槽设置。默认不自动 fallback。
