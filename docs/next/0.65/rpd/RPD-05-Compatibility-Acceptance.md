# 0.65 RPD-05 · 兼容迁移与版本验收

日期：2026-09-21；状态：需求草案，已拆执行 SPEC，开发与测试 NOT RUN。本文受[总 RPD](../RPD.md)范围约束；编号用于需求追踪，不是 worker 执行任务。

## 定位与用户价值

内核化后默认体验持续可用，配置可恢复，已有知识和记忆不丢失；为 0.7 提供有证据的接入基线。

需求归属：K65-R01、K65-R09；汇总 K65-A～T 的跨模块验收。依赖：RPD-01～04 与 RPD-06 的集成结果。本稿是产品完成条件，不是测试执行脚本。
