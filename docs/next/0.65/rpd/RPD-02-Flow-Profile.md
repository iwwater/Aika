# 0.65 RPD-02 · 流程配置与校验

日期：2026-09-21；状态：需求草案，已拆执行 SPEC，开发与测试 NOT RUN。本文受[总 RPD](../RPD.md)范围约束；编号用于需求追踪，不是 worker 执行任务。

## 定位与用户价值

用户通过配置改变流程，无需修改中央流水线代码。首版支持串行、条件分支、有限只读并行及汇合；提供配置入口，不要求拖拽画布。

需求归属：K65-R02、K65-R03（配置与版本）、K65-R06。依赖：RPD-01 的生命周期约束和 RPD-03 的能力声明。管理操作见 RPD-04。

## 用户流程

复制默认 Profile → 修改阶段、依赖、绑定和输出策略 → 校验并预览执行关系 → 保存草稿 → 激活 → 下一轮生效。保存草稿与激活分别表达，校验失败不替换活动配置。

## 产品需求

| 编号 | 必须满足的结果 |
| --- | --- |
| FP-01 | Profile 描述阶段选择、依赖、条件及 Provider 绑定，具有可追踪的身份与版本 |
| FP-02 | 允许满足依赖的顺序调整；不能把需要回复结果的阶段移到回复之前 |
| FP-03 | 并行限于无共享写入冲突的独立只读阶段；汇合区分必需和可选结果，合并顺序稳定 |
| FP-04 | 激活前检查未知能力、缺失依赖、输入输出不兼容、循环和必需保障缺失，错误定位到相关节点/关系 |
| FP-05 | 可保存、导入导出与回退；配置不包含密钥，导入不执行脚本或自动安装代码 |
| FP-06 | 校验与预览不调用模型或外部动作；预览展示可能的分支与条件，不把未运行的分支伪称为实际路径 |
| FP-07 | 回退只改变流程选择，不恢复已遗忘事实，不回滚已发生的外部动作 |

条件可用信息、表达方式和序列化格式留到 SPEC。首版不支持任意脚本、循环 Agent、动态代码热替换或任意副作用并行。

## 关键场景与验收

| 场景 | 预期结果 | 总 AC |
| --- | --- | --- |
| 语音输入配置为文字输出 | 可正常回复且不调用 TTS/播放 | K65-B |
| 两来源完成先后互换 | 汇合结果遵循稳定组合规则 | K65-D |
| 可选来源超时 | 有降级标记，依赖满足时继续 | K65-D |
| 依赖循环或未知 VLM | 拒绝激活并解释原因 | K65-E |
| 修改后回退 | 下一轮恢复选定流程策略，用户数据不被回退 | K65-I |

## 待定

配置格式、条件表达、输入输出兼容校验方式、汇合算法和版本兼容策略在实施前确定；不在 RPD 冻结 schema。

## 与能力包的关系

Profile 仅编排已启用且就绪的包所提供的能力，不能通过引用节点自动安装或授权包。校验分别提示未安装、未启用、缺模型/凭据、版本不兼容和流程依赖错误；包生命周期见 [RPD-06](RPD-06-Capability-Packages.md)。

新增 FP-08：激活前核对包依赖与能力就绪；运行时加载失败按真实失败策略处理。禁用/卸载被活动流程依赖的包时，先展示影响并选择有效流程或阻止操作，不能静默修改用户流程。最小默认 Profile 只使用普通包；语音组合分别引用 STT 或 TTS，不要求二者成对存在。

## 插件化与包体化主目标

Flow Profile 消费插件公开声明的能力，不承担包安装器职责。内核插件化与独立包交付是前提，完成流程重排不能代替插件化完成；Profile 不引用插件内部文件。

实施入口：[0.65 SPEC 索引](../SPEC.md)。产品中的待定项按对应步骤冻结，不要求 worker 自行扩大范围。

## 多来源部署补充

新增 FP-09：每个需要模型能力的阶段引用显式 binding，可分别选择云端/本地来源与模型配置；同一 Profile 无全局唯一模型限制。未知能力参数拒绝，未选来源不加载。首版不自动 fallback，流式失败不拼接不同来源；K65-Q/S 由 02A、07 联合验证。
