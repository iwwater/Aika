# 0.65 RPD-04 · 流程管理与运行诊断

日期：2026-09-21；状态：需求草案，已拆执行 SPEC，开发与测试 NOT RUN。本文受[总 RPD](../RPD.md)范围约束；编号用于需求追踪，不是 worker 执行任务。

## 定位与用户价值

用户知道当前使用哪个流程、修改何时生效、这一轮为什么失败，并能恢复到有效配置。

需求归属：K65-R03（用户操作）、K65-R07。依赖：RPD-01 的真实生命周期、RPD-02 的配置校验与版本、RPD-03 的能力信息。

## 产品需求

| 编号 | 必须满足的结果 |
| --- | --- |
| MD-01 | 最小管理入口支持查看、复制、编辑、保存、校验、导入导出、激活与回退 Profile |
| MD-02 | 明确区分草稿、活动版本和当前轮版本；激活成功提示下一轮生效，失败保持原配置 |
| MD-03 | 提供默认示例和可操作的校验反馈，包括问题节点、原因和可修改位置 |
| MD-04 | 按轮关联 Profile 版本与阶段执行记录，显示开始、结束、耗时、跳过、失败、取消和降级 |
| MD-05 | 区分未执行、条件未选中、失败与成功，不把预览结果作为执行证据 |
| MD-06 | 诊断默认仅记录必要标识和状态，不包含密钥或私密全文；错误信息可用于定位而不泄露输入内容 |
| MD-07 | 用户能够回到有效 Profile；恢复配置不自动重放原轮或其外部副作用 |

首版编辑形式可以是文本配置或轻量表单，实施前确定。运行诊断只覆盖本版执行路径，不扩展为全应用遥测平台。

## 关键场景与验收

| 场景 | 预期结果 | 总 AC |
| --- | --- | --- |
| 激活新流程时旧轮仍运行 | 同时看清活动版本与旧轮实际版本 | K65-F、K65-H |
| 可选 Context 来源失败 | 可见降级原因，最终回复状态与来源失败分别表达 | K65-D、K65-H |
| 导入错误 Profile | 显示具体校验失败，原有效配置继续可用 | K65-E、K65-I |
| 排查慢轮次 | 可定位阶段耗时与实际路径，默认不读取聊天正文 | K65-H |
| 回退并发起新轮 | 新轮使用回退版本，不重放旧轮 | K65-I |

## 能力包管理

按 [RPD-06](RPD-06-Capability-Packages.md) 增加 MD-08：提供本地能力包导入、依赖/资源检查、启用、停用、更新与卸载入口。操作前展示受影响的流程、依赖者与设备需求。默认普通包文字交互完整可用，不通过启动报错强迫用户安装语音或视觉模块。

新增 MD-09：分别显示安装、启用、待加载、已加载、失败、待重启状态及实际包版本。可选包未安装/未启用属于正常配置；对引用它的流程才提示阻塞。安装成功但缺少模型或服务配置时明确显示未就绪，不能显示可用。

新增 MD-10：停用/卸载提示保留的数据和是否需要重启；删除用户数据单独表达。显示加载、失败和释放证据，未运行能力不显示虚构的健康成功。管理入口不自动采集麦克风/屏幕，也不因导入包静默联网安装资源。

## 插件化与包体化主目标

新增 MD-11：管理页面分别显示内核版本、产品组合、已安装插件包版本和实际加载的插件；资产皮肤包、角色数据包与可执行插件包不可混同。导入或更新单个兼容插件包无需重新安装普通包，重启生效边界必须可见。

相关入口：[总 RPD 与依赖关系](../RPD.md)。

实施入口：[0.65 SPEC 索引](../SPEC.md)。产品中的待定项按对应步骤冻结，不要求 worker 自行扩大范围。

## 多来源部署补充

新增 MD-12：来源管理可同时保存云端 API、外部本地服务与托管本地引擎实例，分别配置模型/音色与阶段绑定。展示所选 sourceId/模型/部署方式及加载/健康修订；无 Key 本地不强制凭据。发现列表不等于推理就绪，刷新不启动所有引擎。来源故障不把同能力其他实例一起标红；K65-Q/S 覆盖管理操作。
