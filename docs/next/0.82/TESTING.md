## 配置与边界

| 参数 | normal | smoke |
| --- | --- | --- |
| 屏幕 OCR 周期 | 5 分钟；可设 1～60 分钟 | 5 秒，仅隔离测试策略 |
| 每日批次 | 本地 20:00，可配置时区/时间 | 仍为每日规则，以注入时钟测试；实机手动触发，不把每分钟伪装每日 |
| 陪伴配额 | 共享每日 2 次、间隔 3 小时 | 仅隔离数据根可短冷却；每日规则由假时钟测试 |
| 暂存/样本/派生 TTL | 7 天；派生不长于父来源 | 10 分钟 |
| 受管内容总容量 | 1 GiB，含文本暂存/派生与图片副本 | 64 MiB |
| 来源队列 | 32 项 / 64 MiB | 4 项 / 24 MiB |
| 单图 | 20 MiB / 40 MP；抓屏路径独立预算由 00 冻结 | 不放宽 |
| 文档 | 20 MiB、PDF 最多 200 页；DOCX 解压有界 | 不放宽 |
| 文本 | 每提交片段 64 KiB、每剪贴板/手动文本 1 MiB、每文档提取 1 MiB UTF-8；超限明确标部分/拒绝 | 不放宽 |
| 任务并发 | 每配对一个批次、一个观察任务；共享 OCR 执行并发 1；候选生成队列 1 | 相同 |
| 重试 | 单处理自动重试最多一次；同 job/processingKey | 相同 |

文本限额为执行预算初值，由 00 核对后冻结；DOCX 最大解压字节/条目、解析超时、持续帧像素与字节预算、OCR p95/CER、CPU/私有内存/磁盘/聊天延迟阈值必须在实现相应测量前记录于 00 报告，不能留 null 并判 PASS。不同类型阈值不能互相替代。normal 不读取 smoke 授权/数据；升级旧授权默认无正文目的。所有验证用公开/合成内容，不记录私人输入。

## 证据层级

1. 单元/组件：假时钟、故障和迟到回调可注入；被测 owner/grant/parser/调度/仲裁必须是生产实现。
2. 真实设备：固定像素截图 OCR、真实剪贴板、支持应用/输入法的提交、目录 watcher 和实际文档解析；截图不得藏文字元数据充当 OCR。
3. 正式产品：Electron → trial-backend → 鉴权 API → 同一 owner/adapter/投影。脚本手工拼装 service 的通过不能替代。
4. 人工体验：集中 N082-09 操作，不代签。自动锁屏事件模拟只能证明分发，真实 Win+L/睡眠仍人工完成。

报告逐项 PASS/FAIL/BLOCKED/NOT_RUN，包含版本/哈希、配置、命令/退出码、用例数、错误与延迟计数；native 用例 try/finally 及有界超时，故意制造失败后验证进程/句柄/staging 均释放。不可用来源明确拒绝，不用 skip/删断言获得完整通过。
