# N082-05 · 真实持续目标捕获与本地 OCR

状态：**NOT_STARTED**。前置：00 引擎/捕获验证、01；保存接口依赖 02。权威：[RPD](../RPD.md)、[SPEC](../SPEC.md)、[共用契约](../CONTRACTS.md)、[测试规则](../TESTING.md)。源码路径以下均相对 Windows 工程根，标“新增”的是目标文件，不声称已存在。

## 范围与修改路径

交付可信目标选择、窗口/区域/屏幕单次捕获端口和真正的像素 OCR；供周期 scheduler 调用，不在 adapter 内另建定时循环。原始帧默认处理后释放，Observation 保持短期；明确保存才进 Collection。不将图像元数据或尺寸描述当识别结果，不要求 VLM。

现有：`core/local-ocr-engine.ts`、`core/screen-perception.ts`、`core/observation-context.ts`、`management/perception-runtime.ts`、`contracts/perception.ts`、桌面捕获接入；目标新增 `core/screen-capture-source.ts` 及 00 选定的 native/OCR adapter 与构建部署。

## 本步接口、消费者与生命周期

提供 ScreenCapturePort.selectTarget/validateTarget/capture 和 OcrPort.recognize，消费 01 持续 grant/取消与 00 图像预算；06 是主要调用方、07 消费 Observation，08 提供用户入口。一次捕获前/处理后/发布前复验 grant、generation、目标版本；句柄被重用、DPI/屏幕范围变化或目标丢失先失效，不静默扩大到整个桌面。

持续目标来源必须由可信桌面选择，不能以 selected-random-id 当作真实目标证明。固定范围缩放/色彩/坐标转换按 00 冻结规则，超限显式拒绝或有据缩放；旧单帧 1.5 MB 路径保持独立兼容。真实 OCR 空白可返回空文本，失败状态不生成情境；engine/language/readingOrder/bounds 真实，无引擎置信时不编数字。

同一授权范围的未变化帧/文本可复用短期结果，但缓存 key 含配对/目标/授权/引擎版本；撤销清除。保存观察独立确认后调用 02，失败不把临时帧变永久档案；帧/staging 在取消、失败、退出均释放。缺模型/语言包或引擎启动失败为 unavailable，不能本地失败后自动上传云。
