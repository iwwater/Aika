## 本步接口、消费者与生命周期

实现 CONTRACTS §5 的 mode/status/set/pause/resume、manual batch/job、text submit、continuous/context grants、save observation 和扩展来源/样本接口。所有写入 operationId/revision、token/Origin，pairing 从 runtime 固定；不能把浏览器 body 当原生目标授权或任意文件读取指令。

Settings 展示 active/passive、全局暂停、真实来源状态与能力覆盖、正文独立授权、屏幕预览目标、周期/每日时间/目的地、近期接收/待处理/失败；提供立即整理、主动立即观察、暂停/恢复、回看/删除。Dashboard 为轻量摘要，Developer 为无正文诊断；正文详情明确读取，不将其塞 status/日志。旧 image-only 组件兼容新 text/file 类型，时间显示本地并以 UTC 查询。

组合根只实例化一次 mode/grant/store/scheduler/Invitation owner，共享取消和 lease；卸载/退出 await 关闭，缺引擎/目录/正文 adapter 如实 unavailable，基础文字链继续。启动不自动恢复活跃采集；pin 包含实际 helper/OCR/源码构建产物，构建变化合法重新签发基线并记录，不能关闭 pin 校验。normal 与 smoke 启动完全隔离。
