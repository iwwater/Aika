# N082-03 · 剪贴板及 keyboard/IME 正文来源

状态：**NOT_STARTED**。前置：00 正文可行性通过、01、02。权威：[RPD](../RPD.md)、[SPEC](../SPEC.md)、[共用契约](../CONTRACTS.md)、[测试规则](../TESTING.md)。源码路径以下均相对 Windows 工程根，标“新增”的是目标文件，不声称已存在。

## 范围与修改路径

交付 clipboard_text、input_text、manual_text 和 history_reference。input_text 至少一个真实可用的提交路线，不将 keyboard/IME 两种技术路线强制实现成两套监听。实际已验证范围之外返回 unavailable，不声称全局覆盖。不接入抓屏 fallback，不实现逐键永久日志或每日解析调度。

现有：`desktop/collection/collection-helper.cpp`、`core/collection-helper-client.ts`、`core/collection-service.ts`、对应 helper 构建与契约；目标新增 `core/clipboard-text-source.ts`、`core/input-text-source.ts`、`core/history-source-reference.ts` 及 00 选定的应用/IME adapter。若须独立安装组件，版本和卸载/关闭路径同时交付。

## 本步接口、消费者与生命周期

提供 TextSourcePort.start(grant,signal,onCandidate)/Lease.close；输出 CONTRACTS 的 SourceCandidate/InputTextCandidate，消费者为 Collection service/store 与 06 批次。manual_text 验证长度/授权后 append，history_reference 只接当前合法 History 引用并在查询/处理时复验。

剪贴板 sequence 读取前后复检，图片与文字开关独立，纯文本/HTML格式不误当图片；无法确定来源应用记 unknown。input_text 按实际 commitId、应用/输入法和语义提交片段输出，中文 composition 中间值与取消不入库；编辑/撤销不推断为整个文档最终状态，可靠更正事件可标替代。重复键盘/IME 路线去重。应用范围/保护控件在源端校验，不可靠时禁用该范围。

helper 新能力独立 schema/kind/staging 引用并协商版本；不放开 keyboard v1 的逐键/正文字段拒绝规则。正文长度受限，不打日志；暂停/撤销/退出取消读任务、await 停止后清 staging，迟到回复由代次拒绝。

## 验收与交接

- AC-08203-1：真实剪贴板文本、空/长文本、快速变化与占用；同 sequence 幂等，旧 sequence 不落库，图片/文字开关互不授权。
- AC-08203-2：选定真实应用内中英文输入、composition 取消、选词、粘贴/更正、密码控件与未支持应用；结果是可验证提交文本，非活动计数或键码映射。列明实际覆盖矩阵。
- AC-08203-3：撤销/锁屏/切应用时在途读取拒绝，退出与故障无正文暂存残留；旧 keyboard 无正文测试继续通过。
- AC-08203-4：主动提交与 History 引用有真实 owner 证据；重复幂等、超限有状态，原 History 删除后引用/派生失效。
