# N082-04 · 截图与下载文件增量接收及解析

状态：**NOT_STARTED**。前置：00、01、02；图片 OCR 交付依赖 05。权威：[RPD](../RPD.md)、[SPEC](../SPEC.md)、[共用契约](../CONTRACTS.md)、[测试规则](../TESTING.md)。源码路径以下均相对 Windows 工程根，标“新增”的是目标文件，不声称已存在。

## 范围与修改路径

复用已有截图/剪贴板图片接收，增加下载目录新稳定文件候选和 TXT/MD、文本 PDF、DOCX 的有界本地 parser。监听阶段只登记/暂存，不因事件自动开口。无 OCR 时可测试文件 parser，但图片解析完整验收待 05。不联网下载、不执行文件、宏或扫描整盘。

现有：`core/screenshot-directory-source.ts`、`core/collection-service.ts`、`memory/collection-store.ts`；目标新增 `core/download-directory-source.ts`、`core/document-parser.ts` 与必要 parser adapter。依赖选择/许可证由 00 核定，解析 worker/子进程归宿主管理。

## 本步接口、消费者与生命周期

提供 FileSourcePort.start/resolveStable 和 DocumentParser.parse(sourceRef,version,bytesRef,mimeType,limits,signal)；消费者 06 批次与 02 owner。source scope 使用真实根及显式递归范围；首次/恢复建立接收边界，历史导入必须另选范围与明确动作。文件只能按后端 opaqueRef 读取，不能由网页提交任意路径。

稳定判定复用 size/mtime 间隔与可解析校验，读取前后版本重验；临时下载/半写、rename、替换、符号链接越界、目录失效有明确状态。离线期间未接收的文件不自动混入当日增量；用户可显式导入。每来源版本一份候选，剪贴板瞬时图片已有有界副本，文件原件消失时返回 missing。

parser 做类型/签名检测、字节/页数/解压字节和条目数/超时预算，在大分配之前限制；DOCX 禁宏与外部关系获取，PDF 无文本层返回 unsupported/scanned 而非空成功，TXT/MD 编码异常为 partial/failed。结果 DerivedText 保留父版本/处理器、限制原因和期限。截图双通道同次关联折叠，撤销其中一源后剩余证据重算。
