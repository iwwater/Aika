## 范围与修改路径

扩展唯一 Collection owner 以支持有界文本暂存、文件候选、处理结果与作业记录，保留 0.81 图片/活动与 tombstone。提供新消费者所需索引/分页。范围不含实际 adapter、文件 parser、模型生成、第二套 Wiki。

现有：`memory/collection-store.ts`、`contracts/collection.ts`、`memory/unified-timeline.ts` 的直接兼容层；目标新增 owner 内 migration 及 `tests/next082/store-migration.test.ts`、派生删除/容量测试。分文件仅为组织，仍用同一数据库生命周期。

## 本步接口、消费者与生命周期

提供 appendCandidate/listPending/commitDerived/queryEffective/invalidate 与 claimJob/finishJob；入出参及处理幂等 key 见 CONTRACTS。03～08 直接消费；History 适配只保存原引用。正文不出 status/event/通用 Trace，detail 读取重新鉴权/配对/有效性检查。

数据库事务同时核验源版本/代次并提交派生与作业进度；删除发生在解析过程中也不能写回。来源删除/到期/撤销清除派生、全文索引、staging和投影，通知候选/缓存失效；共享父来源保留有效部分。受管内容统一预算，只有最后引用释放才扣除实际资产容量。原文件只读，程序管理的副本可清理。

升级事务保持旧样本、反馈和 tombstone，不给旧 grant 增加目的；migration 中断可恢复，旧二进制遇高 schema 明确拒绝而非破坏库。来源事件身份与资产 hash 分开；跨配对不共享资产。派生处理器更新不能绕过删除记录，查询 cursor 固定配对/过滤/排序。文件物理删除失败记录待清理与真实占用，不能只删 DB 行宣称磁盘已释放。

## 验收与交接

- AC-08202-1：真实旧 SQLite 升级/重启/中断恢复，旧图与活动可查、原文件不变；旧 grants 无正文授权。
- AC-08202-2：文本/图片/文件重复事件、异时同内容、乱序和处理重试幂等；跨配对/旧 cursor 不可读。
