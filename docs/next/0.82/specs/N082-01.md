## 本步接口、消费者与生命周期

提供 `ModeRuntime.setMode/pauseAll/resume/status`、扩展 SourceGrant activate/transition、持续屏幕授权与 ContextUseGrant 校验，字段按 CONTRACTS。02～08 消费同一 grant/generation/signal，不另建状态机。

控制写入使用 operationId+expectedRevision，持久幂等；模式变化只改策略不扩大来源范围。active→passive 取消屏幕/未展示情境候选，仍保留被动已授权接收；全局暂停撤销本代在途提交权、await lease.close。来源独立 pause/stop/revoke 不操作其他来源，不能调用 suspendAll 模拟单来源操作。resume 成功须有新实际 lease，启动失败显示 unavailable/error。

Windows 会话事件在目录单独启用时仍可达；监听系统状态不能隐式启用文本/剪贴板。锁屏、挂起、会话/配对切换、正常退出/崩溃恢复都拒绝旧代次；重启先将旧 running/active 变为待手动恢复，不自动开监听。恢复重新验证目标与授权；旧失效/停止/撤销源不复活。撤销后允许新授权及目录变更，旧授权身份/修订拒绝迟到事件。释放失败不能被 catch 后回报成功。
