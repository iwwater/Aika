## 2. 核心机制落实证据链

1. **统一鉴权管理路由与动作覆盖（AC-08208-1）**：
   - 模式查询 (`GET`)、策略更新 (`PUT`)、全局暂停 (`pause`)、恢复运行 (`resume`)、增量批处理触发 (`batches`) 全部按契约响应并返回标准状态；
   - 路由层统一捕获错误并安全脱敏映射为 `ManagementError`，不向上泄露本地敏感文件路径或原始图像字节。
2. **严格版本防冲突与操作幂等（AC-08208-2）**：
   - 策略变更严格比对 `expectedRevision`，一旦检测到过时版本号立即抛出 409 `version_conflict`，防止多客户端并发踩踏；
   - 写入操作强制校验 `operationId`，空白无效 ID 强拒绝。
3. **未装配安全降级与高可用防御（AC-08208-3）**：
   - 若某子模块由于环境原因未装配，路由精准抛出 `unavailable` 提示，绝不影响基础对话、工作协议或控制台其它核心能力。
4. **单实例生命周期与优雅释放（AC-08208-4）**：
   - 生产组合根 `trial-backend.ts` 内统一管理单实例，停机或退出时逐一关闭观察任务与文件租约，零游离进程遗留。
