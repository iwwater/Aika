## 2. 核心机制落实证据链

1. **被动模式严格抑制主动情境问候（AC-08207-1）**：
   - 处于 `passive` 模式时，`offer()` 立即返回 `null`，屏幕观察无论检测到何种内容均绝对不发起主动生成，也不弹出气泡。
2. **ContextUseGrant 强依赖闭环（AC-08207-2）**：
   - 本地 OCR 的文本若要进入模型生成上下文，必须显式持有 `active` 状态的 `ContextUseGrant`；
   - 未授权时本地 OCR 可照常执行，但生成 Hook 被完全阻断（零模型调用请求）。
3. **配额与冷却总账共享（AC-08207-3）**：
   - 冷却时间严格限制为 3 小时（10,800,000 ms），未过冷却期的新观察直接丢弃；
   - 每日最多主动陪伴 2 次，达到上限后当日禁止再次主动触发，直至下一自然日自动刷新。
4. **短期生命周期与防幽灵残留（AC-08207-4）**：
   - 候选有效时间设定为 5 分钟（300,000 ms），未被用户采纳的候选超期自动失效清除，不在内存中长期累积。
