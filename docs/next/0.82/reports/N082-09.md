## 3. 后续人工测试（HUMAN_VERIFICATION）操作指引

Agent 自动化已全面验收封板，后续人工可集中按以下 7 项真实场景进行实机体验与抽检：

1. **设置面板与初始零采集**：
   - 打开管理控制台，核对默认处于 `passive` 且全局暂停状态，无任何来源被私自开启。
2. **剪贴板文本与图片独立采集**：
   - 在已授权 `clipboard_text` 下复制一段纯文本，核对生成文本候选；
   - 复制纯图片，核对图片走受管图片通道，两通道互不干扰。
3. **输入法中英文输入与密码框安全**：
   - 在记事本等应用中打字并按空格 commit，核对获得提交文本段；打拼音时中途按 ESC 放弃，核对无多余拼音碎片存入；
   - 在浏览器或登录界面的密码输入框中输入，核对被 100% 阻断，无任何记录。
4. **下载文件与本地解析**：
   - 将测试 `.txt`、`.md`、`.pdf` 或 `.docx` 放入授权下载目录；
   - 待浏览器下载完成后（无 `.crdownload`），点击“立即整理”触发批处理，检查解析出的 DerivedText。
5. **周期屏幕观察与主动气泡**：
   - 切换为 `active` 模式并授权持续屏幕感知；
   - 屏幕上显示有明显文字的应用时，触发“立即观察”，核对生成轻量气泡，且每日最多 2 次、冷却 3 小时。
6. **锁屏停采与睡眠恢复**：
   - 按 `Win + L` 锁定 Windows 桌面，核对后台立即转入 `paused` 并释放监听句柄；解锁后需手动点击“继续”才恢复监听。
7. **删除与撤销**：
   - 点击“撤销并删除该来源样本”，核对候选与派生文本被级联清理，原文件与原对话历史不受影响。
