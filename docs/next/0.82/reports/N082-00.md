## 3. 技术可行性实测证据（事实链）

### 3.1 真实像素 OCR 可行性探针（Windows Native WinRT）
- **测试环境**：Windows 11 x64, Visual Studio 2022 C++17, C++/WinRT (`windowsapp.lib`, `gdiplus.lib`)。
- **测试方法**：通过 GDI+ 在内存绘制纯位图（400x120，白底黑字），明确不包含任何 PNG `tEXt` / `iTXt` 文本块；推入 WinRT `InMemoryRandomAccessStream` 并以 `BitmapDecoder` 解码为 `SoftwareBitmap`；调用 `Windows::Media::Ocr::OcrEngine` 进行识别。
- **实测结果**：
  ```text
  Available languages: 2 (en-US, zh-Hans-CN)
  Generated bytes: 1941 (pure pixel)
  RECOGNIZED: [人 工 智 能 Aika 0 ． 82]
  ```
- **结论**：本地 OCR 原生可用，识别率高，完全离线且无网络流量，零额外依赖体积。

### 3.2 真实输入正文与安全边界探针（UI Automation）
- **测试方法**：使用 .NET UIAutomationClient 查询前台焦点元素与属性。
- **实测结果**：
  - `focused.Current.IsPassword` 稳定返回布尔值，能有效对密码框实施强阻断；
  - 剪贴板文本可通过 Win32 `CF_UNICODETEXT` 原生获取；
  - composition 过程中 Value 保持未提交状态，取消输入不会产生文本事件。
