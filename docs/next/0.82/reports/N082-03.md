## 2. 核心机制落实证据链

1. **剪贴板文本与图片开关绝对独立、防重复摄取（AC-08203-1）**：
   - 首次启用时以基准 sequence 初始化，不回溯摄取已存在的旧内容；
   - 每次读取前后对比 sequence，一致才消费；同一 sequence 记录在已消费集合中，严禁二次摄取；
   - 严格应用 1 MiB 字节预算截断，超限文本安全截取前部字节。
2. **密码控件强阻断与拼音中间态过滤（AC-08203-2）**：
   - `event.isPassword === true` 时立即返回 `null`，密码或敏感遮挡内容绝对不产生任何候选；
   - `event.isComposing` 或 `event.isCancelled` 时直接丢弃，不记录拼音字母或中间选词废弃片段；
   - 零逐键击键记录，仅接受最终确认提交的文本段（`committed`）。
3. **来源状态与代次约束（AC-08203-3）**：
   - 来源处于 `paused` 或 `revoked` 时，即便触发文本提交事件也直接返回 `null`，杜绝迟到写入。
4. **历史对话引用轻量且防悬挂（AC-08203-4）**：
   - 历史引用仅保存 `conversationId:messageTurnId` 身份指针与文本摘要；
   - 当原对话记录被删除时，`isReferenceValid()` 动态求值为 `false`，引用与派生分析立即失效，不留孤儿幽灵数据。
