## 2. 核心机制落实证据链

1. **持久化每日计划账本与防重复执行（AC-08206-1）**：
   - 依赖 `companion_batch_ledger` 表持久记录每日成功批次；
   - 同一配对在同一自然日（如 `2026-09-26`）再次请求 daily 批次时，自动返回 `already_completed_today` 终态并标记 `skipped`，绝不重复解析；
   - 手动触发批次（`manual`）具有独立触发源标识，不侵占也不消耗每日定时计划账本。
2. **候选到派生文本的完整闭环（AC-08206-2）**：
   - 调度器按 `cutoff` 时间截取待处理的 `pending` 候选列表，确保批次处理拥有确定性边界；
   - 调用解析器抽取文本后，通过 `commitDerived` 原子提交并关联父来源版本，自动将原候选状态推进为 `processed`。
3. **周期观察有界并发（AC-08206-3）**：
   - 调度器内部维持 `isBusy` 互斥保护，最大并发度严格为 1；
   - 在上一次观察（捕获 + 像素 OCR）仍在执行时，任何新收到的定时 `tick()` 直接静默忽略并返回 `null`，绝不积压排队，彻底消除追跑历史帧的雪崩隐患。
4. **无文字画面的零干扰原则（AC-08206-4）**：
   - 当画面空白或 OCR 识别出的文字为空时，调度器自动静默丢弃，绝不生成无意义的 Observation 事件或气泡。
