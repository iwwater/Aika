## 2. 核心机制落实证据链

1. **真实像素 OCR 与占位符彻底淘汰（AC-08205-1）**：
   - 彻底废止原实现中当无 PNG 元数据时输出 `[本地屏幕图像 ${width}x${height}]` 的造假缺陷；
   - 纯白色/单色无字图片在通过 OCR 后，输出 `blocks: []` 与 `readingOrderText: ''`，真实如实反映画面无文本事实。
2. **可信目标校验与持续授权约束（AC-08205-2）**：
   - 单帧 CaptureGrant 绝对不能启动周期捕获，只有持有合法 `destination: 'local'` 的 `ContinuousPerceptionGrant` 才可调用 `capture`；
   - 窗口被关闭 (`isValid: false`) 或多屏分辨率超标（如测试中超过像素阈值）时，立即抛出 `target_invalid` 强阻断，绝不静默扩大全屏。
3. **空间几何排版阅读顺序与有界缓存（AC-08205-3）**：
   - 提取的各文本块强制按 `(y, x)` 双轴自上而下、自左至右稳定排序，拼接得到自然的段落级阅读流；
   - 基于图片 SHA-256 摘要进行受控缓存（默认容量 64），对于周期捕获中画面静止未变的场景直接复用已有结果，避免 CPU 浪费。
4. **取消与异常格式防御（AC-08205-4）**：
   - 引擎支持 `AbortSignal`，调用方取消时抛出 `AbortError` 并及时终止运算；
   - 0 字节损坏数据安全返回 `status: 'failed'`，零未捕获异常。
