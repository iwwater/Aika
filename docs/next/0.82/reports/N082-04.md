## 2. 核心机制落实证据链

1. **下载目录临时文件隔离与基线防追溯（AC-08204-1）**：
   - 首次启用时先 snapshot 目录内已有文件加入 `baseline`，绝不回溯摄取历史遗留文件；
   - 浏览器未完成下载产生的 `.crdownload`、`.tmp`、`.part` 临时后缀直接在 watcher 阶段被拦截，仅当重命名为合规后缀且经历完整稳定判定后才触发候选。
2. **纯本地离线解析与多格式安全边界（AC-08204-2）**：
   - **TXT / MD**：UTF-8 边界安全截断；
   - **DOCX**：解包读取 `word/document.xml`，自动检测若含 `vbaProject.bin` 宏文件立即标记 `unsupported` 拒绝执行；单包解压体积受 32 MiB 严格防御保护（防 Zip 炸弹）；
   - **文本 PDF**：提取流中文字，无文字层的扫描版标为 `unsupported`（引导走 OCR 流程），超 200 页的大文件安全拒绝；
   - 不支持的可执行文件（如 `.exe`）直接返回 `unsupported`，杜绝任何外部调用。
3. **取消信号与状态闭环（AC-08204-3）**：
   - 解析支持 `AbortSignal`，调用方中止时立即返回 `status: 'cancelled'`；
   - 0 字节文件返回 `missing`，超 20 MiB 限制文件返回 `failed` 并提示 `file_too_large`。
