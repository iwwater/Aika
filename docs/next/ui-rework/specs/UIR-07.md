## 2. 实施步骤

1. 实现最多六类卡片：当前角色、今日概览、最近经历、最近知识、系统状态、快捷入口。当前角色和经历优先，使用自行设计样式。
2. 每项数值来自真实查询，注明时区、日期区间和 pairing；统计定义固定为成功完成对话轮次/有效陪伴事件/当日激活知识等，不以消息数冒充轮次数，不能仅第一页长度作总数。
3. 最近经历限制 3～5 条，摘要来源有效且不暴露原始 Trace；普通用户可看简明来源，开发详情遵守 Developer 开关。最近知识排除未晋升候选。
4. 当前模型/音色取 effective，保存未生效另提示；未配置/未检测/失败与零分别显示。缺真实关系阶段时省略，不生成百分比。
5. 快捷入口打开对应角色、Knowledge、Playground、Plugins、Settings，继承真实配对；刷新取消过时查询，避免聚合一个失败导致整页空白。
