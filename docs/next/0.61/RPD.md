## 3. 完成标准

- 模型设置必须经过真实生产启动组合根；页面保存成功或独立 adapter 测试通过不足以证明接通。
- “模型可自定义”指模型名称、端点与已实现协议可独立配置，不承诺所有未知协议都自动兼容。
- 状态灯区分已配置、可达与实际可用；未知、检查中、过期不能误标绿。
- 换肤更换外观，不切换角色人格和记忆；知识库是独立参考资料集合。
- 冻结内容按真实 Provider 请求前缀验证。缓存命中/TTFT/费用记录实际测量，不承诺 100% KV Cache 或固定降本比例。
- 明确纠正、遗忘、知识删除和切库立即撤销旧上下文；普通记忆增长可延迟进入冻结快照。
- 真流式 ASR 在用户停止录音前产生真实 partial；batch fallback 不能替代此 AC。
- FIX61-01～10 必需自动 AC 全通过、受影响回归和 Windows 构建/冒烟通过，才标开发完成；用户确认后才标 ACCEPTED。
