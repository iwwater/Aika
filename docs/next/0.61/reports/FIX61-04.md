## 1. 问题与修复

用户实测：桌面端**左键与右键都只打开聊天抽屉**，且工程中**没有任何换肤/切换角色入口与独立功能面板**。

根因是 `desktop/main.mjs` 里的一行：

```js
$('character').onpointerup = () => { if (pointer && !pointer.moved) panel(!panelOpen); pointer = null; };
```

它不区分按钮，把「抚摸 / 拖动 / 面板」三种意图压成同一个动作，且无法单测。本轮把**路由决策**提取成独立生产模块 `desktop/pointer-router.ts`，由真实渲染器调用、由测试驱动同一个对象。

### RED 证据

实现前 `npm run check` 失败原文：

```
tests/next61/fix61-04.pointer.test.ts(8,67): error TS2307: Cannot find module '../../desktop/pointer-router.mjs' or its corresponding type declarations.
```
