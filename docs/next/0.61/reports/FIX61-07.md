## 1. 解决的两个用户诉求

**R-TODO-08 状态灯**：用户要的是「绿=已连接可用」，不是「端点能访问」。核心修正是把三种不同强度的断言分开：

| 证据 | 含义 | 能否点亮绿灯 |
| --- | --- | --- |
| `configured` | 该槽位有凭据/地址/模型绑定 | 否 |
| `reachable` | 端点应答了非计费请求（如模型列表） | 否 |
| `operational` | **本次配置下真实调用成功** | **是** |
| `selfCheck` | 本地能力自检通过（如 SQLite 完整性） | **是** |

这正是 SOURCE_AUDIT 指出的缺陷：「模型列表可达就可以绿灯」——只能证明 API 可访问，不证明模型权限、语音能力、推理成功。

**R-TODO-11 麦克风诊断**：用户当前语音不可用且原因不明。关键设计是**试麦与后端 ready 解耦**——后端失败时用户仍必须能检查设备。
