## 1. 源码定位

BrowserCaptureDriver 已有 onLevel/onDiagnostic 和 getSettings 部分读取，但 getUserMedia 未指定 deviceId；Electron mediaAllowed 由 voiceRequested/wakeRequested 控制，后端未 ready 时 start_voice 不会授权。不能直接在管理浏览器页加 getUserMedia 就假称桌宠试麦可用。

## 2. 修复与接口边界

HealthSnapshot 按模块返回 state=unknown/checking/ready/degraded/failed/disabled，evidence=configured/reachable/operational、checkedAt、configRevision、reasonCode、repairAction。绿色限当前配置下有实际运行或等价能力自检证据；红色失败；灰/黄色表示未配置、未测、过期或部分可达。凭据存在和 /models 成功不能冒充 ASR/TTS/LLM 实际可用。

集中订阅启动状态、Provider 最近调用结果、本地引擎加载及 SQLite 打开/schema/读写回滚自检。非计费探测可手动刷新且限流；不为定时点灯生成付费请求。切配置后旧健康结果无效，30 秒后标明过期，不凭历史成功永远绿。

试麦放桌宠可信 renderer：单独的显式 mic_test_start/stop 权限租约，仅允许音频，与后端 ready 解耦；关闭/超时/失焦取消、异常退出释放 tracks，不能同时打开会话采集。测试不启动 camera/ASR/LLM，不写 Timeline。

枚举输入设备，选择 default 或 deviceId，偏好只存本机 app userData；设备变更/拔出显示原因，可明确选择回默认，不静默换麦。展示 track.getSettings 实测采样率/声道，设备标签、默认选择和权限状态；无法取得标 unknown。

复用 PCM 电平。按键录音最长 5 秒、仅内存本地回放，结束销毁 buffer/object URL；通过同一 deviceId 配置接入正式 BrowserCaptureDriver。权限拒绝/设备占用/无 PCM 分别定位。

以上新接口名是设计建议，不声称已经存在；复用上游 Scope、取消、存储与鉴权边界。只修改本 SPEC 所需代码，共享接口变动同步记录消费者。
