## 1. 源码定位

已核实：management/settings.ts 的 validateManagedSettings 校验 adapter.models、endpoints、固定 pricing/thinking；app/trial-config.ts 的 validateTrialConfiguration 限制供应商、URL 和 memory_turn；providers/text-protocol.ts 还有 DeepSeek 型号检查。providers/qwen-asr.ts 构造器锁定具体型号。app/trial-authorizer.ts 即使 unlimited 也读取预算文件并 reserve。

management/aika-profile.ts 仅存 providers 数组，未分槽；management/aika-routes.ts 的 GET 不返回 providers，UI 刷新可能丢配置；management/server.ts 调用异步 aikaRoute 时缺 await。

app/trial-backend.ts 仍构造 JsonDialogueProvider、StrictTrialMemoryProvider、JsonSummaryProvider、Qwen ASR/感知；Aika adapter 的独立契约测试不能证明生产已接通。

## 2. 修复与接口边界

建立唯一版本化 SlotBinding（七槽：dialogue/memory_turn/summary/perception/asr/tts/admission），记录 adapterId、protocol、endpoint、model、credentialRef、能力参数、输入输出上限、可选计费信息。catalog 只给预设与协议能力，不以模型名称/价格白名单拒绝自定义模型。旧配置迁移保留原值，备份并可回退。

逻辑 ProviderRegistry.resolve(slot, binding) 负责能力匹配与实际实例化。文本四槽必须接通 OpenAI-compatible 与 Gemini；记忆保留现有严格计划解析、来源校验和提交语义，只替换模型调用适配，不退回旧维护器。perception/asr/tts 也可独立填写模型/地址/凭据及选择已实现的相应协议，不能把“任意配置”伪装成支持任意厂商协议。至少保留当前生产多模态/语音协议，加接 FIX61-08 的本地流式 ASR。思考参数按协议 capability 映射，不将 Qwen 字段发到其他协议。

Profile/SlotBinding 只保存引用；Key 通过既有凭据入口写入受保护存储，支持新增/替换，读回只给 configured 状态。允许 HTTPS 和显式 loopback HTTP 本地端点；禁止把 Key 交给重定向后的其他主机。

配置保存带 expectedRevision；“已保存”和“已应用”分开。新轮使用同一配置修订；在途轮保留原修订，切换不能使 authorizer 与 adapter 不一致。需要重启的本地资源明确提示。

unlimited 下跳过价格/额度预扣门槛及预算文件依赖，但保留取消、启停、端点/配置一致性、请求尺寸与输入输出上限；未知价格标 unknown，不造零费用。bounded 模式仍执行合法的用户预算与预扣，缺价格只阻塞 bounded，不能为了开放配置删除所有授权保护。

修复 Aika GET/PUT 序列化和生产 management 注册；所有配置必须在真实 trial-backend 组合根可达。

以上新接口名是设计建议，不声称已经存在；复用上游 Scope、取消、存储与鉴权边界。只修改本 SPEC 所需代码，共享接口变动同步记录消费者。

每个 AC 先建立生产路径失败测试，保存 RED 证据，再最小实现、GREEN 和重构；现有已通过行为保留回归，不要求用户中途操作。状态均为 NOT RUN。
