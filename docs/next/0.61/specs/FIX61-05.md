## 1. 源码定位

cubism-renderer.mjs 虽有 options.assetBase，但 presetCatalog 和 parameterMap 为静态 import，缓存 Map 也在模块级；只改目录不能完整换肤。loadRig 固定 pet.model3.json 并依赖特定 FileReferences。tools/configure-model.mjs 生成单目录绑定；desktop/electron/assets.mjs 只服务受限 root。

## 2. 修复与接口边界

在 Next 数据目录建立模型包注册表；已有 local-model 作为内建包兼容。最小支持用户导入本地已授权 Cubism 3/4/5 model3 包，选择入口文件、校验引用/纹理/预设/参数映射，不要求下载商店，不支持 Cubism 2。

逻辑 SkinStore.list/import/activate(expectedRevision,skinId)；包含 model entry、独立 preset/map、fingerprint 与支持能力。无 preset 的包可生成禁用自动动作的安全目录，触摸只对已确认参数生效；不把原模型预设套到新 rig。

渲染器的 maps 与 catalog 改为实例级加载。先验证并加载候选，成功后切 active revision，再释放旧 WebGL/纹理/监听器；失败保留旧皮肤。跨进程保存/渲染回执失败需回退并报告，启动恢复最近有效选择。

资源通过 pet 协议按 registry ID 解析，禁止任意磁盘路径、..、符号链接逃逸；受管理模型资产单独做版本/hash，不使换肤等同修改程序 runtime hash。

换肤只改变外观，不改变 characterId、身份、语音、知识库或记忆；UI 明示“外观/皮肤”，0.7 Character Pack 另行绑定。

以上新接口名是设计建议，不声称已经存在；复用上游 Scope、取消、存储与鉴权边界。只修改本 SPEC 所需代码，共享接口变动同步记录消费者。
