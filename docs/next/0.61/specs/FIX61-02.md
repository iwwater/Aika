## 2. 修复与接口边界

逻辑 ModelDiscovery.list({protocol, endpoint, credentialRef, cursor?, signal}) 返回 items[{id,label,capabilities?}]、nextCursor、checkedAt。在管理 API 的现有鉴权边界增加发现路由；输入为已保存配置引用或验证后的草稿，不记录密钥。

OpenAI-compatible 使用明确 apiBase 的 models 资源；Gemini 使用 models.list 分页，按 supportedGenerationMethods 辅助选择。不要对任意完整推理 URL 粗暴追加 /v1/models；配置区分 apiBase 与推理路径，迁移已知旧 URL，无歧义之外允许单独配置 modelsEndpoint。

UI 提供端点、Key、协议、获取列表、搜索下拉、手工模型名和各槽绑定。发现失败/404/不支持不得清空已选模型，也不得禁止手填。发现成功只证明列表可访问，不证明指定模型能完成推理。

请求超时 10 秒、单页/总量有界（最多 1000 条/20 页）；取消、重复页 token、旧请求迟到和配置切换隔离。未知能力展示 unknown，不据模型名称编造能力。

以上新接口名是设计建议，不声称已经存在；复用上游 Scope、取消、存储与鉴权边界。只修改本 SPEC 所需代码，共享接口变动同步记录消费者。
