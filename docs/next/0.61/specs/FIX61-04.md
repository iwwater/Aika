## 1. 源码定位

desktop/main.mjs 的 character.onpointerup 未区分按钮，直接 panel(!panelOpen)；Electron main 主要负责 IPC/布局，并非唯一点击入口。interaction-motion.mjs 已有 tap 曲线；cubism-renderer.mjs 已有 attention 触发和政策校验，可复用。

## 2. 修复与接口边界

在 renderer 分发 pointerdown/move/up/cancel/contextmenu：左键短点击触发本地抚摸反馈，左键拖动仍移动桌宠；右键只开功能面板，防止 pointerup 与 contextmenu 双触发。抚摸不发 LLM 请求、不写 Memory；尊重动作开关、reduced-motion 与模型参数边界。

功能面板有独立 view/state，与聊天抽屉区分，可同窗口切视图，不强制新 BrowserWindow。入口含聊天、换肤、知识库、配置、记忆、Timeline、日志/诊断、麦克风和状态；不存在的目标不能是死链接。日志仅已有脱敏诊断，不提前做 R-TODO-14 全轮 Trace。

扩展既有 layout/shell IPC，保持来源、主 frame 校验；Esc 关闭、键盘可达、缩放与屏幕边缘不裁切。后端失败时仍能打开面板看错误与试麦。

以上新接口名是设计建议，不声称已经存在；复用上游 Scope、取消、存储与鉴权边界。只修改本 SPEC 所需代码，共享接口变动同步记录消费者。
