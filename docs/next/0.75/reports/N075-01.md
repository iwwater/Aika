## 1. 目标与执行边界

N075-01 目标为**彻底收口运行时真相（Runtime Truth Repair）**，确保前端 0.75 各页面改造前，后端具备唯一的生产运行时、真实消费 0.7 连续性、合规的异步记忆提炼生命周期、端到端阶段级 Trace、真实上下文快照检视与平滑 Provider 适配。

- **范围聚焦**：LLM、Memory、Continuity、Provider、Trace、Runtime wiring；
- **严格越界防御**：STT / TTS 核心声学逻辑不做非必要改动；
- **单模型单对话调用（Single Dialogue LLM Call Invariant）**：一轮对话仅有一份完整的 `DialogueContext`，由单次对话 LLM 调用消费，禁止建立第二条对话推理管线；
- **时序不变式（Timing Invariants）**：
  1. 用户发言（Raw Transcript）：优先立即持久化落库；
  2. 连续性与前台 Context：仅消费已提交状态；
  3. 普通事实提炼（Memory Distillation）：后台异步执行，绝不阻塞前台回复；
  4. 纠正/遗忘/不确定请求：立即触发 Pending 隐私保护屏障；
  5. 长期记忆写入：严格走 `MemoryTurnPlan` → CAS/版本校验 → `commitTurn()`，彻底禁止 direct SQL 写表。
