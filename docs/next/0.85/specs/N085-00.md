## 责任与接口

核实 Windows 正式链的 `BackendSession → History/Memory lifecycle → ContinuityMemoryPort → ProductionContinuityContext → DialoguePipeline`，以及 `CharacterPackStore`、`CharacterDistiller`、`continuity-routes` 和 Knowledge Library 的真实消费者。区分 `IMPLEMENTED/WIRED/EXPOSED`，逐项记录 0.79 候选生产链、派生遗忘、0.8 Event/Observation、可选包与管理入口的实际状态。源码位置和 DTO 以当时基线为准；本稿引用的 `contracts/continuity-memory.ts`、`contracts/character-pack.ts`、`contracts/continuity-context.ts` 是核对入口，不是预设新增 API。

冻结来源矩阵：`history:<messageId>`、Character SourceBlock、明确保存且可撤销的 Observation、Knowledge Library 文档分别由谁拥有正文、有效性、配对/角色/作品约束与删除权。定义编纂输入的逻辑字段（sourceType、sourceId、sourceRevision、locator、pairing 或 character/pack scope、origin、occurredAt、validity、authorization），并映射到已有字段；缺字段才提出最薄兼容扩展。临时 Observation、Work 回执、助手生成文字一律没有用户事实写入权限。
