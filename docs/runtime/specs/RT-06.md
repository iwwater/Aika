# RT-06 · 跨渠道主动投递策略

状态：READY（仅授权本地实现与自动验证；真实服务/人工 AC 未执行）。
需求来源：[v0.5 与增量需求](../../PRD_V0.5.md)；执行规则：[安全执行计划](../../GOAL_EXECUTION_PLAN.md)。

## 前置与范围

- 前置：RT-05、GW-01、AGT-05。
- 修改范围：delivery policy/outbox adapter、既有proactive闸门。源码根为 aika-crossplatform；优先复用现有端口，不为文档目录迁移源码。
- 非目标：本份范围外功能、发布、公网部署、真实账号操作。前置自动契约通过可开发；需要真实安全属性的集成不可由 fake 放行。

## 行为与接口

quietHours/cooldown/urgency/目标授权与去重，默认一个指定渠道，无回复不跨平台追发。群组永不接私人提醒；通知不可执行任务。

所有新增公共字段需在 CONTRACTS 登记版本、兼容 adapter 与消费者；持久化使用临时数据库验证升级与失败回退，不触碰用户库。

## 验证与交付

先读当前生产实现与既有测试，列出定向命令；测试必须走本模块生产实现，fake 只替代外部依赖。记录命令、退出码、逐 AC 证据、影响消费者、未执行的真实/人工项。逻辑测试不证明 UI 可用、真机或真实服务通过。
报告路径：../reports/RT-06_ACCEPTANCE.md。仅所有可自动 AC 通过才能写 AUTO_PASS / 待人工验收；FAIL 不可改为 NOT RUN 来推进依赖。完整验收维持待人工；不自动提交或推送。


## 全文审阅：复用投递出口

唯一outbox来自GW-01，AGT-05的完成通知也转入同一端口，不另造重试队列。提醒/主动消息必须用户曾授权目标；审批请求不可按urgency绕过quietHours并误算批准。quietHours结束前暂缓，过期时丢弃并可见，不追发到其他渠道。持久冷却key含主体+事件类型+目标，重启不清零频控。
