## 行为与接口

请求绑定 principal、conversation、agentSession、规范化 workspace、action 参数摘要/哈希、policy版本、过期时刻、单次 nonce。unknown 默认拒绝；群聊不能批准高权限动作。记录 pending/approved/rejected/expired/cancelled，审批消费原子化，执行前再次校验。

所有新增公共字段需在 CONTRACTS 登记版本、兼容 adapter 与消费者；持久化使用临时数据库验证升级与失败回退，不触碰用户库。

## 全文审阅：审批与执行不是同一终态

Permission请求状态pending→approved/rejected/expired/cancelled；approved是决定终态，执行单独以executionId/consumedAt原子认领一次。批准后、尚未认领前撤销需重新检查；已经发生的副作用不能靠取消追回，报告consumed/executing/cancelRequested。动作摘要不足以确认范围时拒绝或请求补全，不把自然语言“只改3文件”当文件白名单。

不持数据库事务跨整个外部进程；在宿主执行前做最后授权检查并审计认领。路径必须规范化并防Windows大小写、UNC、junction/reparse、相邻前缀和TOCTOU；无法保证时拒绝越界，不因只读字样开放任意用户目录。支付/账户/危险动作默认拒绝，无永久approve-all。桌面也需明确策略，不因origin=desktop自动全权限。
