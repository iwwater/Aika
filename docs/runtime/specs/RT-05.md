## 行为与接口

提醒/定时/延时/事件触发分别建模；时区、错过时机默认不补跑副作用、幂等触发key、重试上限、用户暂停。完成事件不转成频繁轮询Cron。

所有新增公共字段需在 CONTRACTS 登记版本、兼容 adapter 与消费者；持久化使用临时数据库验证升级与失败回退，不触碰用户库。

## 全文审阅：持久触发语义

任务字段包括id/owner/scope、trigger(time|cron|event)、IANA timeZone、nextRunAt、misfirePolicy、enabled、attempts、executionKey及状态。默认错过的提醒标missed不补发，重复小时只执行一次，不存在时刻记录skip；这属于本版产品策略，以fake clock覆盖DST与时钟回拨。

到期认领、事件去重与入outbox使用同一持久提交边界；不能先标done再产生结果。非幂等外部副作用若崩溃后是否完成未知，标unknown待处理，不自动重放。默认最多3次可重试、指数退避、有容量上限。单宿主调度不承诺PC关闭仍可执行；无时区数据/无调度解析能力返回unsupported，不硬编码本地时区。
