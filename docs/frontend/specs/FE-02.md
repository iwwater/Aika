# FE-02 · 模式、场景与设置

## 架构与接口依据

本 SPEC 必须实现 [模块架构与接口](../ARCHITECTURE.md) 中对应阶段的端口、事件、状态与错误语义；通过 adapter 兼容现有实现。下方 AC 同时验证这些契约，无需启动其他真实模块。

需求与边界见 [模块 PRD](../PRD.md)，依赖遵循 [共享契约](../../modules/CONTRACTS.md)。

交付 companion/oral_practice/scenario_practice 选择、练习语言/纠正偏好/场景参数、退出场景与设置保存反馈；角色始终相同。

| AC | 模块内验收 |
| --- | --- |
| FE-02-A | 切换三模式向接口发送正确参数，退出场景清除 UI 临时身份，不重置角色显示 |
| FE-02-B | fake 存储成功/失败/重载：设置正确恢复，失败可见，不假装已保存 |
| FE-02-C | 键盘可完成选择/发送/取消，控件有可访问名称；窄屏和桌面无主要控件遮挡 |

只执行当前 SPEC 的本模块测试；其他模块使用 fake/mock。验收报告放 `../reports/FE-02_ACCEPTANCE.md`。全流程测试仅在必须联调或大任务完成时按 [集成 SPEC](../../integration/SPEC.md) 执行；真人设备后置项不自动恢复。

## 全文审阅结论

A/B可由生产Presenter+fake端口验证；C需真实DOM/浏览器键盘与窄屏验证，不能由函数调用记录认定可访问性通过。切模式只影响下一轮快照，在途轮保持原参数；保存失败保留先前设置并可见，退出场景不改Character Soul。
