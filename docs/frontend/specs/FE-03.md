# FE-03 · 语音状态与字幕显示

## 架构与接口依据

本 SPEC 必须实现 [模块架构与接口](../ARCHITECTURE.md) 中对应阶段的端口、事件、状态与错误语义；通过 adapter 兼容现有实现。下方 AC 同时验证这些契约，无需启动其他真实模块。

需求与边界见 [模块 PRD](../PRD.md)，依赖遵循 [共享契约](../../modules/CONTRACTS.md)。

交付监听/转写/等待/回复/播放状态、临时字幕、立即发送/清空、逐句高亮和降级提示。只消费模拟状态，不新增音频算法。

| AC | 模块内验收 |
| --- | --- |
| FE-03-A | fake STT 临时/最终事件正确更新字幕，立即发送/清空只调用对应接口一次 |
| FE-03-B | fake TTS 句子进度高亮正确，缺少匹配范围不猜位置；取消后高亮清理 |
| FE-03-C | 无麦克风/输入降级/音频错误均可见且仍可文字聊天；关闭面板解除自身订阅 |

证据：组件测试、浏览器使用 fake 数据的操作记录和必要截图。整套真实桌面/手机链路留 INT-01/03。Live2D/桌宠/素材创作仍后置，环境采集不开启。

只执行当前 SPEC 的本模块测试；其他模块使用 fake/mock。验收报告放 `../reports/FE-03_ACCEPTANCE.md`。全流程测试仅在必须联调或大任务完成时按 [集成 SPEC](../../integration/SPEC.md) 执行；真人设备后置项不自动恢复。
