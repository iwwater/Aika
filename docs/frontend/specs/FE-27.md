1. 执行时核实当前官方 SDK / 候选 WebGL 运行时的兼容与使用条款，记录确切版本及来源；本文件不预称某版本兼容或可免费分发。不引入购买、新凭证或未核实可分发素材。
2. 选一个许可覆盖目标使用方式的现成包，登记下载来源、文件哈希、作者、许可证、署名要求、本地使用与安装包分发是否允许。运行时和角色素材分开审查；仅有本地使用权时不把素材提交进仓库或分发包。
3. manifest v1 含 id/version、入口相对路径、资源清单、默认表情、expression/motion 白名单映射、mouth 参数映射、待机配置与授权元数据。拒绝绝对路径、目录穿越、网络 URL、可执行脚本、不在资源清单的引用；规范化后的最终路径必须在角色根目录内，检查链接逃逸。
4. 首版仅受信任的本地配置包，不做任意 ZIP 导入和模型返回路径加载。拟冻结总资源上限 100MiB、单纹理边长 4096、资源文件数 256；超限显示 invalid_asset，不半加载。解码后按实际尺寸复检。

## 表现端口 v1

`load(manifest, signal): Promise<void>`、`setExpression(id, turnId)`、`playMotion(id, turnId)`、`setMouthOpen(value, playbackSessionId)`、`reset()`、`dispose(): Promise<void>`。runtimeTurnId 可空；口型会话另由 FE-29 定义，不能伪造 Runtime ID。上游明确切换活动轮次 / 播放会话，旧 ID 不改变当前状态。

状态为 idle/loading/ready/fallback/disposed；错误只含 unsupported/invalid_asset/load_timeout/render_failed 等代码。未知表达回退默认，mouth value 有限且 clamp 到0～1；非法数值回零。load 默认超时10000ms，abort/替换 load 后迟到资源必须销毁。dispose 幂等，禁止再创建动画循环。
