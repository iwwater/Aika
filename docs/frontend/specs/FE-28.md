## 行为

1. 使用本地包加载 Canvas/WebGL；执行10秒加载超时与 abort。成功启动一个动画循环，待机呼吸 / 眨眼与包内白名单表情动作映射，未知项回默认。
2. 主窗只发送正式 ReplyEnvelope 投影的受控 ID。mood 不能推导任意资源路径；新轮使旧轮动作失效；取消时 reset，仍允许当前角色待机。
3. 无包、坏包、WebGL 不可用、上下文丢失或渲染错误进入 fallback：停止循环、释放部分资源、展示 AvatarPlaceholder。重试先清理旧实例；聊天和主窗播放不受影响。
4. FE-29 尚无能量时，默认口型闭合；若采用 speaking 简化动画须显示“简化口型”，不能以此验完整音频同步。
5. pet 销毁必须 await adapter 清理或记录失败；清除纹理、监听、计时器。窗口重新打开只存在一个当前 renderer。无渲染需求时不留隐藏循环。
