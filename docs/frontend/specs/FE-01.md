# FE-01 · Runtime 桥接与消息状态

## 架构与接口依据

本 SPEC 必须实现 [模块架构与接口](../ARCHITECTURE.md) 中对应阶段的端口、事件、状态与错误语义；通过 adapter 兼容现有实现。下方 AC 同时验证这些契约，无需启动其他真实模块。

需求与边界见 [模块 PRD](../PRD.md)，依赖遵循 [共享契约](../../modules/CONTRACTS.md)。

交付文本发送、流式展示、取消/重试、complete/interrupted/cancelled 呈现；Hook 只订阅状态与派发命令，保留旧消息兼容。

| AC | 模块内验收 |
| --- | --- |
| FE-01-A | fake Runtime 流式/完成/失败/取消序列正确展示，旧 turn 事件不覆盖新消息，不重复显示片段 |
| FE-01-B | 无 TTS/mic 时文本发送和完成正常；错误后能再发，disabled/busy 状态不残留 |
| FE-01-C | 中断消息明确状态，不当完整成功回复；组件卸载/重开无重复订阅 |

只执行当前 SPEC 的本模块测试；其他模块使用 fake/mock。验收报告放 `../reports/FE-01_ACCEPTANCE.md`。全流程测试仅在必须联调或大任务完成时按 [集成 SPEC](../../integration/SPEC.md) 执行；真人设备后置项不自动恢复。
