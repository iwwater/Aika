## 接口设计（拟定，以本 SPEC 冻结为准）

事件信封沿用总 PRD §18 的四字段，schemaVersion 仿 `TraceEventV1`：

```ts
// src/domain/environment.ts（新文件）
export const ENVIRONMENT_SCHEMA_VERSION = "environment.v1";

export interface EnvironmentEvent {
  schemaVersion: typeof ENVIRONMENT_SCHEMA_VERSION;
  sourceId: string;
  eventId: string;
  hostEpoch: string;
  timestamp: number;   // 宿主墙钟，仅展示；排序/频控用单调时钟
  receivedMonotonicMs: number;
  timingPrecision: "measured" | "estimated" | "unknown";
  confidence: number;  // 0..1；进程/空闲类确定事件为 1
  payload:
    | { kind: "foreground_changed"; process: string; title: string }
    | { kind: "screen_keyword"; keyword: string; text: string }
    | { kind: "game_event"; event: string }   // victory/defeat/pentakill/…由词表映射
    | { kind: "notification"; app: string; title: string }
    | { kind: "idle_changed"; idleSeconds: number };
}
```

端口与 token（token 分散所有权，定义在接口旁）：

```ts
// src/services/environment/contracts.ts（新文件）
export interface EnvironmentSource {
  readonly kind: string;  // "foreground" | "screen" | …
  start(emit: (event: EnvironmentEvent) => void, signal: AbortSignal): Promise<() => Promise<void>>; // ready后返回幂等异步停止函数
}

export interface EnvironmentSnapshot {
  foreground: { process: string; title: string; since: number } | null;
}

export interface EnvironmentMonitor {
  readonly snapshot: EnvironmentSnapshot;
  subscribe(listener: (event: EnvironmentEvent) => void): () => void;
  dispose(): Promise<void>;
}

export const EnvironmentSourcesToken = token<readonly EnvironmentSource[]>("environment.sources");
export const EnvironmentMonitorToken = token<EnvironmentMonitor>("environment.monitor");

export interface ProactivePolicyInput {
  event: EnvironmentEvent;
  now: number;
  lastSentAt: number | null;      // SETTING_KEYS.proactiveLastSentAt
  proactiveToday: number | null;  // countProactiveSince(startOfToday)，拿不到为 null
  userBusy: boolean | null; // null为无法判定，不从进程名伪推全屏
  sustainedMs: number;
  occurrencesInWindow: number;
}
export type ProactiveDecision =
  | { action: "ignore"; reason: string }
  | { action: "remember"; reason: string }
  | { action: "trigger"; reason: string };

export interface ProactivePolicy {
  evaluate(input: ProactivePolicyInput): ProactiveDecision;
}
export const ProactivePolicyToken = token<ProactivePolicy>("environment.proactivePolicy");
```

## 取舍

**信封 + payload，不是平铺联合**：总 PRD §18 定义的就是 `{type, timestamp, confidence, payload}` 信封。后续加传感器只是 payload 加 `kind` 成员；按 `kind` 穷举的消费方补分支即可，漏不掉。

**policy 是纯函数**：`evaluate` 不写存储、不发请求、不起定时器。「现在能不能说」由既有 `canSend` 闸门终审（FE-22 接线）；policy 只回答「这个事件值不值得说」。职责分开，conformance 才有确定性输入。

**trigger 的执行接线不在本 SPEC**：从决策到 `CompanionRuntime.submit` 要动 presenter 与 `domain/proactive.ts`，归 FE-22。本 SPEC 交付的 policy/monitor 允许暂时没有生产调用方（同 `prefetch?` 先例：先冻结契约）。

**内核 eventBus 不动**：环境事件是传感器业务事件，走 monitor 自己的订阅；eventBus 的封闭联合不含它们。

## 生命周期与默认阈值

start失败必须清理已注册listener；abort发生在ready前时，迟到返回的stop也必须执行，monitor.dispose等待全部stop完成后不再广播。默认dedupeWindowMs=2000、maxPerMinute=60，按sourceId+规范化payload去重；时长和频控用宿主单调时钟，不用可回拨墙钟。snapshot可追加recent事件计数，但窗口标题不得进入计数key日志。纯policy不知道是否用户忙时返回ignore。

## 2026-09-14 · 生命周期、撤销与摘要契约

需求映射：SET-04/05、ENV-05/08、PRO-07、PRD AC-01/05。本 SPEC 只做生产 monitor 与契约，不做设置页、真实采集或发送接线。

- `foreground_changed` 的 `title` 改为可选；首版真实 source 不读标题，也不产生该字段。monitor 兼容旧 fixture 的该字段时在规范化入口剥离，snapshot 只保留 process/since。同步本文件原示例及 conformance，不把未实现草案误称已发布版本迁移。
- 为每个 source 定义 `off | starting | running | stopping | denied | error` 状态、当前 generation 和只含代码的错误。unsupported 由宿主不注册能力表达。注册 monitor 不等于启动 source；source 开关由 FE-19 的控制端口接入。
- 增加 `setSourceEnabled(sourceId, enabled): Promise<void>` 与 `stopAll(): Promise<void>`，source 的 start/stop 串行化；stopAll 先撤销全部 generation、清空 snapshot/recent，再等待全部 stop。停止失败显示 error，不伪称 off；一源失败仍尝试停止其余源，dispose 可幂等重试清理。
- recent 至多 20 条，只存规范化事件摘要，TTL 60000ms，以宿主可信单调接收时间计算；不得从 OCR 文本提取任意摘要字段。当前应用是单独状态，只在该 source 正运行且 epoch 有效时可用，不因用户停留超过 60 秒失效。
- 模型出口 DTO 只含受控 process 名、持续时间、event kind / 词表 ID、置信度和年龄；禁止 title、OCR text、图像。摘要授权检查由 FE-19/22 消费时执行，DTO 存在不代表可外发。
- 同一 source 关闭只清除其状态与 recent；stopAll 清空全部。跨进程时钟不得直接相减，统一映射到 monitor 时钟；未知 / 未来时间拒绝或记无正文诊断，不延长 TTL。
