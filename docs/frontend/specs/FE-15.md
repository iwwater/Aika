# FE-15 · Tauri HTTP传输与手机页迁移

状态：已全文审阅，READY（本地实现）。前置：FE-14、FE-17-pre；FE-17-host在本份后验收，不循环依赖。依据：[PRD](../PRD.md)、[共享契约](../../modules/CONTRACTS.md)。

## 范围与设计

修改src-tauri/src/remote.rs或其复用路由模块gateway.rs、lib.rs、TS tauriTransport/宿主装配、src-tauri/mobile/index.html及定向测试。复用现有监听器与鉴权端口，不无故开第二端口；允许最小改remote.rs，不能声称保留旧路由就零风险。

- GET /api/v1/events：请求带epoch/cursor，返回events、oldest/latest cursor、gap、runtimeStatus。每主体/会话缓存最多500帧并设总字节上限，超限明确截断；过期cursor/epoch变化触发重同步，不从0盲目执行旧命令。
- POST /api/v1/commands：认证/Origin/尺寸检查后生成可信带外主体，转发TS网关校验业务。202只代表accepted，requestId/messageId关联终态；Runtime不在线明确503，不能伪称完成。只允许主窗口发布Runtime帧与回应命令，其他WebView不能伪造。
- FE-17-pre提供配对/会话凭证逻辑。首页可作为不含数据的配对壳公开，任何历史/事件/命令必须认证；配对码以请求体单次兑换，不把长期凭证放URL。cookie认证需CSRF；Bearer或其他方案同样严格校验Origin白名单，不开放任意CORS。
- 旧手机路由仅兼容业务载荷，必须接统一鉴权、身份范围和曝光开关；旧?t=不继续授予长期权限。迁移后提示重新配对，不删除聊天。旧路由不得绕过新权限。
- 默认loopback，LAN按用户设置启用；公网由FE-17门禁管理。每个长轮询超时≤25s，有界并发与取消；等待不占用全局锁，不能阻塞POST或服务停止。Runtime心跳失联标offline，Rust只缓存已有帧。
