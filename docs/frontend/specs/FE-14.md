## 契约

以下是待实现逻辑契约；先与RT-01/02已定型类型对齐，不复制身份模型。

```ts
interface OutboundCursor { gatewayEpoch: string; seq: number }
interface RemoteReplyV1 {
  replyText: string; translation: string | null; mood: string;
  actions: readonly RemoteDisplayAction[]; // 仅受控展示动作，无路径/脚本
}
type OutboundCommandV1 =
  | { schemaVersion: 1; type: "submit"; messageId: string; text: string }
  | { schemaVersion: 1; type: "ping"; requestId: string };
interface AuthenticatedCommand {
  raw: unknown;
  principal: AuthenticatedPrincipal; // transport认证后带外注入
  conversationId: string;          // 从服务端会话映射，不信任body声明
  connectionId: string;
}
interface OutboundTransport {
  publish(target: AuthorizedTarget, frame: OutboundFrameV1): void;
  onCommand(handler: (input: AuthenticatedCommand) => void): () => void;
}
```

OutboundFrameV1按channel判别为reply/status/trace，包含schemaVersion=1、cursor与可选turnId。status仅白名单code/状态/requestId，不原样输出error.message。reply由generated投影，禁止memoryCandidates及内部数据。Trace经统一脱敏函数生成适于远程的投影，需本地采集开+外发开+主体授权+显式订阅四门；默认远程正文关闭，不得被本地includeText开启连带授权。

command的messageId按主体+conversation去重，校验版本/type/空串及4000 Unicode码点文本上限，拒绝原因发送到原连接。消息只进入统一facade；source=text保留旧语义，可信来源另带，mode取请求所属会话的已保存配置而非全局可变值。网关需有turnId到授权目标映射，不能把所有Runtime事件广播给所有设备。未映射轮次不外发；桌面轮只能发给明确绑定该桌面conversation的设备。

cursor按订阅流单调递增，重启变gatewayEpoch；过滤其他会话产生的序号空洞不是丢帧。gap由传输分页元信息表达。订阅映射、去重表、缓冲有数量/字节/TTL上限；若消费确认不确定，不自动重投submit。没有transport时插件skipped；安全授权端口缺失时不接入命令。
