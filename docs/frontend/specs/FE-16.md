# FE-16 · 浏览器dev传输与Node WS中继

状态：已全文审阅，READY（本地实现）。前置FE-14、FE-17-pre；与FE-15无强依赖。依据：[PRD](../PRD.md)。

## 范围与设计

scripts/outboundDevRelay.mjs、services/outbound/wsTransport.ts、app/hosts/plugins.ts、package与锁文件，项目devDependency按核实版本增加ws。浏览器页面是客户端；Node进程监听loopback。生产构建+URL参数不得启动relay连接；必须开发构建和显式本地配置同时开启，地址只允许已配置本地relay。

producer与consumer会话角色分开认证，consumer不能publish Runtime数据，producer不能替任何主体创建审批。配对/撤权复用FE-17-pre；websocket握手用短期单次ticket或已认证同源会话，长期凭证不进URL/log。校验Origin、订阅conversation与频道、消息大小/速率/连接数量，慢消费者断开并保留可重连状态。relay不持LLM凭证、不调用Provider。

复用FE-14 cursor/epoch/gap及授权投影，按连接过滤。断线后只恢复事件游标；不得自动重发状态未知的submit。旧epoch重连需要重新同步，撤权关闭当前连接并使ticket失效。中继停止释放socket、timer、订阅，测试失败也必须finally清理。
