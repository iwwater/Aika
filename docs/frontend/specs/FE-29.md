# FE-29 · 实际播放能量与 Live2D 口型同步

状态：DRAFT，2026-09-14 文档拆分，未启动实现。需求：[PRD](../PRD_ENVIRONMENT_AND_LIVE2D.md) L2D-04～06/08、AC-10。前置 [FE-27](FE-27.md) 表现契约；真实桌宠口型需 [FE-20](FE-20.md)、[FE-28](FE-28.md)。规范遵循[共享契约](../../modules/CONTRACTS.md)。

## 目标与文件边界

口型来自实际播放信号。主窗采样并中继参数，pet 只渲染；不复制播放、不录制麦克风、不将预生成文本长度当作音频能量。

| 范围（相对 aika-crossplatform/） | 工作 / 所有者 |
| --- | --- |
| `src/services/voice/contracts.ts` | TTS 公共端口可选追加播放能量订阅，保留旧消费者兼容 |
| `src/services/voice/cloudTtsOutput.ts`、`outputEngine.ts` | 仅对实际可取得 PCM / 媒体播放节点的后端接入能量；不重写队列 |
| `src/services/voice/webSpeechOutput.ts` | 系统语音后端如无法取得能量则明确 unsupported，不录系统回环凑信号 |
| `src/services/voice/playbackEnergy.ts` 及测试 | 生产 RMS 计算、平滑、限流与清理 |
| `src/presentation/voicePresenter.ts`、`src/pet/relay.ts` | 关联实际播放会话及轮次，转发白名单参数 |
| `src/pet/` 的表现消费处 | 过滤旧会话与序号、丢流闭嘴，调用 character 端口 |

执行先审查当前播放后端，报告支持矩阵。FE 主责展示接线，TTS 主责可选能量端口；共享契约登记追加版本与队列 / Presenter / pet 消费者，受影响 conformance 必须跑，不借此修改 STT 或模型协议。

## 契约与算法

拟追加 `subscribePlaybackEnergy?(listener): () => void`，事件为 `{ playbackSessionId, runtimeTurnId?: string, seq, phase: started|sample|ended|stopped|error, rms?: number, precision: measured|unavailable }`。播放会话由真实输出端分配，不把语音旧 turnId number 伪装成 Runtime string。点朗读没有 Runtime ID 时留空。

支持后端复用实际播放链的音频节点，RMS=sqrt(mean(sample²))，非有限数回零；默认嘴形值 clamp((rms-0.01)/0.19,0,1)，拟定起落平滑常数40/80ms，最多30次/秒中继。这些是初版配置，执行时记录版本，若需调参使用开发音频，冻结后再验收。

started 建立当前会话，ended/stopped/error 立即发 mouth=0 并停止采样；取消路径不等待下一次 sample。pet 连续250ms没收到当前会话有效样本自动归零；旧 seq / 旧会话丢弃。会话结束后迟到 sample 不重新开嘴。关闭窗口释放展示订阅，但不停止主窗播放；输出后端停止后释放其分析器。

无端口或 precision=unavailable 时可显示 speaking 简化动画，并持续标注“简化口型”；完整同步项 BLOCKED。禁止仅凭 started/ended 标为 measured。主窗与 pet 不直接相减各自单调时钟；端到端延迟用共同外部录制测量，内部日志只辅助定位。

## AC

| ID | 方法与通过条件 |
| --- | --- |
| FE-29-A | 生产 RMS + 固定 PCM：静音、已知振幅正弦、NaN、截断片段；RMS 数值误差≤1e-6，归一值合法，零信号闭嘴 |
| FE-29-B | 生产中继 + 假时钟：30Hz上限、250ms丢流、旧会话/seq、取消后迟到样本，均不持续张嘴；窗口关闭不调用TTS stop |
| FE-29-C | 未实现可选端口的旧后端仍播放；系统语音不可测时展示简化标记，unsupported 不伪称 measured；受影响队列和输出 conformance 通过 |
| FE-29-D | 10句真实播放（长短句各5句）与5次真实打断，记录各句开始 / 结束偏差；每句各≤150ms，每次打断≤300ms复位；无重复音频 |
| FE-29-E | 启停 / 朗读切换 / 新轮替换10次：分析器和订阅释放；普通朗读保留独立session，无伪造runtimeTurnId |
