# FE-32 · 中英文屏幕文本上下文与按需读屏

状态：待实现/验收；2026-09-14 用户明确要求的日常读屏互动补充。依据[PRD](../PRD_ENVIRONMENT_AND_LIVE2D.md)桌宠陪伴补充。FE-21保留固定英文关键词基线，本SPEC扩展通用文本，不能用五个关键词通过替代。

## 前置与范围

依赖FE-18生命周期、FE-19权限与请求出口、FE-21生产capture/OCR资源。FE-31消费本端口，算法测试不依赖桌宠、Live2D或真实LLM。首版识别主显示器上获授权前台窗口客户区的可见中英文文本；不识别最小化/被遮挡内容、不滚动页面、不读取其他显示器，不声称理解图表、图片、视频动作或任意微小文字。

前台为pet/主窗时使用点击前保存的最后有效外部窗口标识，重新验证其可见性/范围；不能把点击后的桌宠文字读给自己。显示器捕获须排除pet与主窗覆盖区域；无法可靠排除时拒绝该区域并提示调整窗口，不能把自身气泡当新屏幕话题反复触发。

## 端口与数据

新增 `ScreenContextSource.readOnce({ reason: manual|change, sessionGeneration, signal }): Promise<ScreenContextResult>`；change须已授权且通过diff，manual可绕过diff但仍受授权、并发和资源上限。

result含id/sourceId、sourceTrust=environment、captureGeneration、窗口身份（不含标题）、采集区域、单调采集时间、expiresAt、language、confidence、readStatus及`excerpts`。最多20段、总计2000字符，保留阅读顺序和段置信度；多余截断并标记truncated。空白/低置信度/超时/不可捕获有明确状态，不返回虚构描述。

截图和完整OCR原文仅本地内存，禁止日志、Trace、数据库、远程或图像模型出口。**本次新增允许的出口**：用户已授权“屏幕文本用于对话”时，经长度限制与来源标注的可见文字摘录可送当前Provider；原“只允许固定词表摘要、禁止任何OCR文字进入模型”对本SPEC被替代。没有该出口，无法对任意屏幕文字互动。授权页明确说明文字摘录可能包含私人信息、发送目标及范围，提供预览/暂停，不宣称脱敏能保证消除全部敏感信息。

摘录仅作为带来源和时间的不可信上下文，不能作为system/user指令，不写User Soul；screen_talk的用户请求与摘录分开构造。生成回复是否落为正常会话消息沿既有规则，授权页说明回复可能引用页面内容；不另存原文证据，避免承诺“任何相关文字永不落库”。模型可能复述摘录，不能承诺绝对无回显；远程展示仍受既有回复授权。

TTL60秒从capture计时；用户点击强制刷新，不拿旧画面冒充当前；请求发送前重查session/授权/窗口身份/TTL，任何失效移除证据。暂停/关闭清空全文及摘录，迟到结果无效。上次文本去重只在内存存有界指纹，不记入日志。

## 识别与调度

- 离线打包eng与chi_sim资源；引擎可沿FE-21或替换为经过真实质量验证的本地实现，版本、许可证和资源哈希需记录，不凭名称保证识别效果。
- 自动路径仍先diff；对有效窗口区域读取布局文本，不局限中央80%×20%。前台窗口改变或首次进入陪伴可进行一次基线OCR，随后仅变化且稳定≥3秒才OCR。
- 统一capture/OCR调度器，并发1、pending1、滚动每分钟最多10次；用户请求优先替换未开始自动任务，不增加第二worker，手动也计总额。达到额度显示下一次可用时间，允许取消，不能静默挂起或偷偷突破上限。
- 自动挑选置信度≥0.8的文字段作为主动候选；手动低置信度段明确标记“不确定”，无有效文本则提示未读到，不生成肯定的屏幕断言。检测不到文字不等于画面没有内容。
- 单次OCR超时5000ms、初始化15000ms；热读屏目标P95≤3000ms（扩展文本区域预算，FE-21关键词仍2000ms）；原图不跨出本地主窗受控路径。

## 文件范围
