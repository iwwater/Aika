## 2. FE-33-A · 冷启动零采集

**操作**

1. 双击 `aika-crossplatform.exe` 启动。
2. 打开**设置**（右上角设置入口）。
3. 找到 **Awareness / 环境感知** 分组。
4. 在启动前，先打开任务管理器，记下进程数与句柄数（仅 Aika 进程）。

**通过条件**

- [ ] 环境感知分组**出现**（`available = true`）。
- [ ] 里面两个 source 初始都是 **「已关闭」**（不是「运行中」「启动中」）。
- [ ] **启动本身零采集**：任务管理器里 Aika 进程**没有新增持续 CPU 占用**，无 WGC/捕获相关线程活动。
- [ ] 开关状态与你上次退出时一致（持久化读回）。
- [ ] 若宿主不支持，应显示 **「权限被拒」/「错误」**，而不是假装「运行中」。

## 3. FE-33-B · 前台应用感知

**操作**

1. 打开设置页环境感知分组，开启 **「前台应用感知」**（标签为 `前台应用 · …`）。
2. 在 **VSCode → 浏览器 → 游戏**（或三个不同程序）之间来回切换，每次切换后观察应用里的前台应用显示。
3. **连续开关 20 次**「前台应用感知」开关。
4. 做一次**锁屏**（Win+L）再解锁；再切到 150% DPI 显示器各观察一次。

**通过条件**

- [ ] 切换应用后，识别到的**进程名正确**，延迟 **< 1 秒**。
- [ ] 20 次开关后**无线程/句柄泄漏**（对比开关前后的句柄计数，不持续增长）。
- [ ] 锁屏 / 最小化时，busy 观测为 **`unknown`**，**不是 `false`**（不能谎称"用户不在忙"）。

**观测值填写**

```
切换延迟（目测/秒表）：
进程名是否正确：
20次开关前句柄数 / 后句柄数：
锁屏时 busy 显示：
```

## 4. FE-33-C · 屏幕抓取（窗口归属）

**操作**

1. 开启 **「屏幕感知」**（标签为 `屏幕 · …`）。
2. 用**非私人画面**（例如空白记事本、开源文档页）触发画面变化。
3. 分别让前台是：**普通窗口** / **pet 桌宠** / **主窗** / **被 pet 遮挡**，各观察一次。

**通过条件**

- [ ] 普通窗口时，抓取返回 `ok` 且携带**正确进程名与客户区矩形**；**返回体无窗口标题**。
- [ ] 前台是 pet / 主窗时，**回退到「最后一个有效外部窗口」**并重新验证（而不是抓到 pet 自己）。
- [ ] 被自身窗口遮挡时返回 **`obscured`**，界面提示「请调整窗口」，**不硬读**。

**观测值填写**

```

前台=pet 时读到的是：
前台=主窗时读到的是：

## 5. FE-33-D · 双语读屏与性能

**操作**

1. 确认 `dist/tessdata/` 里有 `chi_sim.traineddata` 与 `eng.traineddata`（已随包）。
2. 准备三类**非私人**画面：中文文章、英文文档、中英混排 IDE。
3. 对每类，分别走两条路径：
   - **手动**：点桌宠 → 「看屏幕聊聊」
   - **自动**：让画面自然变化（active 模式下）
4. 记录每次读屏耗时。

**通过条件**

- [ ] **双语资源离线加载成功**（可断网测试，仍可用）。

- [ ] 限流到上限时显示**下一次可用时间**，不静默挂起。

## 6. FE-33-E · 环境摘要出口（需真实 Provider）

> 会产生真实调用费用（DeepSeek，量很小）。

**操作**（四轮对话）

1. 两个开关都**关**（「将环境摘要用于对话」+「允许屏幕文字用于对话」）→ 发一轮。
2. 只开「将环境摘要用于对话」→ 发一轮。
3. 再开「允许屏幕文字用于对话」→ 发一轮。
4. 关掉「允许屏幕文字用于对话」→ 立刻再发一轮。

**通过条件**

- [ ] 两个都关时，请求里 **零环境内容、零摘录**。
- [ ] 只开摘要时，**只有应用名 + 时长**。
- [ ] 开摘录后，摘录带来源与时间出现在**「参考资料」区块**且标 **「（未确认）」**。
- [ ] 关掉开关后的下一轮**立刻为空**。
- [ ] **原图与完整 OCR 原文不出现在日志、Trace、数据库任何一处**（逐处检查并留证）。

## 7. FE-33-F · 陪伴会话逐项演示

**操作**

1. 先点 **「显示桌宠」** 让 pet 出现。
2. 关闭主窗（最小化）。
3. 依次演示：**开启陪伴（active，一次确认）** → **quiet** → 点 pet **「看屏幕聊聊」** →
   pet **直接输入**（「聊两句」） → **暂停读屏** → **结束陪伴**。
4. 期间做：**拖动** pet、**双击**、**连续点击**。

**通过条件**

- [ ] 每项行为与 FE-31 状态机一致，状态显示**真实**。
- [ ] **拖动结束不算点击**（不展开快捷菜单）。
- [ ] **双击不发两轮**。
- [ ] quiet 模式下**自动发送为 0**。
- [ ] 暂停后**普通聊天仍可用**。
- [ ] 结束陪伴**不中断**主窗已有的用户轮与 TTS。

**观测值填写**

```
