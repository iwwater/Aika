# Character Contract

## 组成

- **Character Pack**：角色、作品版本、来源、知识截止点和可追溯修订。
- **Character Soul/Style**：稳定性格、价值取向和互动偏好。
- **Character Wiki**：有来源的角色知识。
- **Canon Timeline**：作品/角色的原作经历，不混入当前陪伴事件。
- **Relationship State**：当前用户与当前角色实例的有证据互动适应。

## 边界

Character Pack 与 Continuity 分开存储和失效。角色切换、来源撤销、遗忘和纠正必须使受影响的 Context 失效；动态关系不能自动重写原作事实；未知截止点不能放宽为“允许全部内容”。
