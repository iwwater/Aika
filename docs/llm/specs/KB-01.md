# KB-01 · 知识库文件批量导入（DRAFT）

依据：[0.5 RPD](../../RPD_MVP_0.5.md)、[MVP-06](MVP-06.md)、[派发审阅](../../REVIEW_DISPATCH_2026-09-15.md)。独立于 0.6 和研究型 RAG；本次仅拆文档，未派发，AC 全部 NOT RUN。

现状：KnowledgeIndex 已有 `importDocuments`，需要注入 `KnowledgeFileReader`；KnowledgeWikiPort 尚无批量导入。不是只接一个文件选择器。复用既有整批事务、内容去重、版本和 FTS 更新，不另造索引器。

范围：Aika `aika-crossplatform/src/services/knowledge/` 管理端口/索引适配，设置页知识库入口、文件选择与宿主读取端口、必要 Tauri 权限及定向测试。实施前登记实际文件路径。浏览器宿主无读取能力时禁用入口并说明；不为本份另建 Web 上传链路。

首版仅 UTF-8 `.md`/`.txt` 本地文件；复用 `KNOWLEDGE_IMPORT_LIMITS` 的现有限额并在 UI 显示。读取前检查数量与文件大小，读取后再做内容限制校验；总批次内存有界。暂不含 PDF/DOCX、目录递归、文件监听、向量检索或云端上传。

| AC | 验收与证据 |
| --- | --- |
| A | 设置页可选择多个文件、取消、确认导入；只读取明确选入且验证过的文件，非法路径/非支持格式/超限/解码失败在提交前有明确反馈 |
| B | 导入前显示文件清单、角色归属、文档类型与解锁阶段；复用现有元数据约束。切角色不把在途结果写入另一角色；无后台自动选取文件 |
| C | 管理端口连接生产 KnowledgeIndex 与宿主 reader；同内容重复导入 skipped，变更内容遵循既有版本规则，正确更新 FTS；导入后列表与检索能使用新条目 |
| D | 沿用整批原子事务：任何文件失败整批回滚，不报告其余文件成功；显示失败原因与重试入口。成功显示 updated/skipped 数，不误称支持逐文件部分成功 |
| E | 取消选择不读文件；读取/校验期间取消不提交。进入事务后按既有提交/回滚语义完成，不用隐藏界面伪装回滚；重复点击不创建并行重复批次 |
| F | 用生产索引与测试 reader 验证重复/变更/跨角色/超限/失败回滚及检索；Windows 真机另验选择器→宿主读取→列表。fixture 不替代真机，未跑项写 NOT RUN |
