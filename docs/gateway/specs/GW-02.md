## 行为与接口

首期仅已绑定用户私聊；群聊默认拒绝。选择官方 Bot API 传输并记录版本依据；token 仅宿主保存。长消息切分与平台速率限制有界重试。未获外发授权用传输 fixture。

所有新增公共字段需在 CONTRACTS 登记版本、兼容 adapter 与消费者；持久化使用临时数据库验证升级与失败回退，不触碰用户库。

## 全文审阅：轮询与账户配置

第一版选官方getUpdates长轮询，offset只在GW-01持久接收后推进；如账号已有webhook返回配置冲突，不自动deleteWebhook影响其他机器人部署。进程停止abort轮询；只有一个poller拥有同一bot租约。新增设置入口通过可信主窗配置/启停，默认关；先验证身份绑定再接消息。

Telegram官方API在URL路径使用bot token，不能套用只删query的redactEndpoint；日志仅记录方法名/状态码，下载URL同样屏蔽整个token段。429按retry_after，有上限；长文本按平台上限和Unicode安全切分，切片ID稳定且局部送达状态可见，不重发已成功片段。

协议依据：[Bot API](https://core.telegram.org/bots/api)、[官方FAQ](https://core.telegram.org/bots/faq)。实现时冻结实际版本/能力；真实账号仍条件执行。
