## 行为与接口

语音识别经既有 STT，能力缺失明确不支持；文件仅提取受支持文本为资料，拒绝脚本执行。仅平台受控下载地址，禁止任意 URL 抓取。

所有新增公共字段需在 CONTRACTS 登记版本、兼容 adapter 与消费者；持久化使用临时数据库验证升级与失败回退，不触碰用户库。

## 全文审阅：音频文件端口不是麦克风

生产SpeechInputEngine只接start(language,events)，WhisperClient.transcribe接16kHz单声道Float32Array；不能把Telegram OGG/Opus直接塞给麦克风端口。范围补一个STT拥有的AudioTranscriptionPort{transcribe(blob,signal)}及注入的decode/resample边界，复用Whisper请求；能力缺失明确unsupported，不偷偷开麦克风或降级WebSpeech文件识别。TTS输出不是接收语音文件的硬前置。

支持附件先限制纯文本/Markdown/已定义JSON和受支持音频格式；image/PDF/office/压缩包暂不解析。校验实际字节/解码后时长上限，下载需受控平台fileId、重定向再次白名单验证，禁止任意URL。AC增加固定压缩音频→生产解码→单声道16kHz→fakeASR的实值验证，取消中止解码/请求并清理，绝不加载私人音频。
