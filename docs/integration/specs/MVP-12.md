## 1. 通道与身份（AC-A）

| 项 | 冻结值 |
| --- | --- |
| 方向 | pet-shell → Aiki（反向），**loopback only** |
| 协议 | HTTP `POST`，`Content-Type: application/json`，路径见 Aiki 侧 SPEC |
| 契约版本 | 请求体带 `schemaVersion: 1`；Aiki 侧不认识该版本即拒收，不回退猜测 |
| 身份 | Aiki 派生 shell 时注入**点击回调凭据**（环境变量，与 `PET_SHELL_EXIT_TOKEN` 同构、方向相反）；shell 只在 owned 期间持有 |
| 凭据边界 | attach 实例**不持有**凭据 → 零请求；凭据不进日志、不进 `/api/status`、不进诊断快照 |
| 作用域 | shell 实例级；Aiki 侧按注入时登记的实例身份校验，不按「来源 IP 是 127.0.0.1」放行 |
| 可追溯 | 事件带实例身份与产生时间；消费者（Aiki 侧接收方）在契约文档中登记 |

## 2. 事件语义与可靠性（AC-B）

| 项 | 冻结值 |
| --- | --- |
| 事件形状 | `{schemaVersion, type:"click", eventId, atMs, payload:{button}}`；`eventId` 为 shell 侧生成的唯一 id（uuid） |
| 去重窗口 | Aiki 侧按 `eventId` 去重；**重复投递不产生第二次效果**。窗口至少覆盖一次重试的最大跨度 |
| 重试 | 只对**连接失败/超时**重试一次；重试沿用同一 `eventId`。不得为新事件复用旧 id |
| 背压 | 单在途 + 有界队列；队列满时**丢最旧并计数**，不阻塞点击判定线程、不影响窗口交互与四端点 |
| 不自动重放 | 进程重启、重连、实例转交后**不回放**历史点击 |
| 断连 | shell 侧失败只记账，不重试到成功为止、不弹窗；Aiki 不在线时点击等于丢弃 |
| 错误响应 | Aiki 侧返回明确状态码（未授权 / 版本不符 / 负载非法 / 队列满）；shell 侧一律只记账 |
| 超时 | 单请求上限沿用 1500ms；不回退到更长超时 |

## 3. 点击判定（AC-C）

| 项 | 冻结值 |
| --- | --- |
| hit area | 渲染器注册的命中元素（与窗口 click-through 判定同一份，见 `RendererHost` 的 `onHitTargetChange`）；**不在命中区域内不产生事件** |
| 与拖动的区分 | 按下到抬起的位移 **< 4 px** 且未进入拖动状态 → 判为点击；超过阈值一律判为拖动，**不产生点击事件** |
| 与双击的区分 | 冷却窗口 **400 ms**：窗口内的第二次抬起**折叠为同一次点击**，不产生第二个事件 |
| 按钮 | 仅左键；右键保留给上下文菜单，不上报 |
| 不派发业务轮 | **shell 只上报事实，不生成对话轮、不直接播动作、不推进任何 Agent 状态**。是否回应、如何回应由 Aiki 侧策略决定（SPEC 原文：不默认点击生成一轮对话） |
| 失败反馈 | 上报失败对用户不可见（不阻塞、不抖动、不弹窗）；仅诊断计数可见 |

## 4. 不预定项（留给 Aiki 侧消费者 SPEC）

点击到达 Aiki 之后做什么——打招呼、播放 `waving`、还是生成一轮对话——**不在本 SPEC 决定**。Aiki 侧只承诺：收到已授权的点击事实、按 `eventId` 去重、由明确登记的消费者处理；消费者的产品语义另立 SPEC。

→ 该 SPEC 已起草：[MVP-15 点击的 Aika 侧语义](MVP-15_CLICK_CONSUMER.md)（草案，未派发；v1 只作为可观测事实已落地并冻结，v2 待拍板）。

## 5. 撤销与关闭（AC-E）

| 场景 | 期望 |
| --- | --- |
| 能力关闭（未注入凭据 / 开关关闭） | 零请求；四端点输出不受影响 |
| 退出 / 换实例 | 撤销迟到输入：已在队列中的点击不再投递；凭据随所有权释放一起丢弃 |
| 单实例转交 | 转交后原实例不再上报 |
| 验证据分列 | fixture 层（假传输、计数与边界）与**真实 UI 操作**（真人点击）**分开记录**，不得互相代替 |
