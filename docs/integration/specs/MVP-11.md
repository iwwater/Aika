# MVP-11 · Live2D 与首版换装（DRAFT）

依据：[RPD](../../RPD_MVP_0.6.md) MVP-R11、[统一规则](../SPEC_MVP_0.6.md)。AC 全部 NOT RUN。前置：MVP-07 的 Live2D 技术与目标用途条件通过，MVP-09/10。

范围：shell Live2D renderer、模型/profile、菜单选择与资源清理。消费现成授权模型，不恢复 Aika 自研窗口，不启动 ComfyUI、素材生产、工坊或口型。

首版建议采用**整模型切换**作为换装，实施前按实际模型验证并冻结；若选同模型部件换装，则在报告明确部件/参数契约。两种方式不同时强制，不能把普通 renderer 切换当作换装已验。

| AC | 验收与证据 |
| --- | --- |
| A | 固定依赖版本、模型来源及使用/分发条件；真实 Windows 显示选定模型，并报告所支持 motion/表情与实际映射 |
| B | Aiki 的 say/action/event/emotion 经唯一表现出口可见；未知 motion/表情有确定降级，不假装播放，不新增 LLM 调用 |
| C | 至少两套已授权外观完成选定方式的本地换装演示；先加载验证再提交切换，失败保留旧外观；加载中有状态，不承诺零耗时 |
| D | sprite↔Live2D 与连续换装保持单一输出；释放旧纹理、模型、渲染循环与监听；旧 generation 加载成功也不得覆盖当前选择 |
| E | 缺文件、无效模型、未知换装项、载入失败及断连按可恢复策略处理；能力/profile 随最终成功选择更新，失败不污染当前配置 |
| F | fixture 验映射/异步竞争，device 验模型/动作/换装与资源变化；许可未解决的素材不入分发包 |
