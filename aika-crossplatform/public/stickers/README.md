# 表情包

把图片直接丢进这个目录（`png` / `gif` / `webp` / `jpg` 都行），然后在
`manifest.json` 里给每张写一条：

```json
{
  "stickers": [
    { "id": "wink", "file": "wink.png", "when": "开玩笑、逗对方的时候" }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 她在提示词里看到的名字，也是落库的值。改了 id 等于换了一张，历史消息会显示不出来 |
| `file` | 这个目录下的文件名 |
| `when` | **必填。** 什么时候该用它。写不出来她就选不准——没有这条的会被直接忽略 |

懒得手写就跑 `npm run stickers:scan`：它会把目录里还没登记的图片补进
`manifest.json`，`when` 留空给你填。**`when` 空着的条目不会进提示词**，
她看不见也就选不到。

## 规则

- 她只能从清单里挑，不生成图，也编不出清单以外的名字。
- 清单为空时整套机制隐身：提示词里一个字都不提，结构化输出也不多这个字段。
- 一次最多 24 张（`MAX_STICKERS`）。再多她挑不准，提示词也会被撑大。
- 图片建议 240×240 以内、单张 300 KB 以内：聊天气泡里只显示这么大。

图片文件走 `.gitignore`，不进仓库；`manifest.json` 和这份说明进。
