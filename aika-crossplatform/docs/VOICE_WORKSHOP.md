# 声音工坊方案

声音工坊是与 Aika 主程序分离的本地工具，用来把合法授权的录音制作成可导入的 Style-Bert-VITS2 语音包。

## 设计目标

- Windows 上尽量一键启动。
- 先检测显卡、Python、FFmpeg、磁盘和数据集，再允许训练。
- 自动完成格式统一、静音切分、转写初稿和训练目录生成。
- 用户必须检查文字标注后才能开始训练。
- 自动选择适合显存的批大小；8GB 显存默认从 batch size 2 开始。
- 训练完成后直接生成 `voice.json` 和模型目录。

## 操作流程

```text
选择授权录音
  → 环境与音频质量检查
  → 自动切分和转写
  → 人工校对日语文本
  → 一键训练
  → 多情绪试听
  → 导出 Aika 语音包
```

## 训练数据建议

- 建议准备 30～60 分钟干净的单人日语录音。
- 单段控制在约 2～12 秒。
- 避免背景音乐、混响、削波和多人重叠。
- 普通、开心、温柔、关心等风格分目录保存。
- 不使用未获得许可的配音演员、主播或他人私密录音。

## 工具包边界

首个工具包只负责环境诊断、数据准备、启动上游训练界面和导出。训练算法本身保持使用原版 Style-Bert-VITS2，避免维护一个私人分叉。

工具包目录见 `tools/voice-workshop/`。当前先提供配置示例与环境诊断脚本；模型下载、训练和导出将在 M2 完成。
