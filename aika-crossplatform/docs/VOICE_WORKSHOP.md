# 声音工坊方案

> 2026-09-03 修订：角色改说中日英三种语言后，**声线模型必须一个模型覆盖三种**。
> Style-Bert-VITS2 的 JP-Extra 是日语专用，不再可用；选型改为待定，倾向 GPT-SoVITS。
> 完整取舍见 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) 的 M5。

声音工坊是与 Aika 主程序分离的本地工具，用来把合法授权的录音制作成可导入的语音包。

## 设计目标

- Windows 上尽量一键启动。
- 先检测显卡、Python、FFmpeg、磁盘和数据集，再允许训练。
- 自动完成格式统一、静音切分、转写初稿和训练目录生成。
- 用户必须检查文字标注后才能开始训练。
- 自动选择适合显存的批大小；8GB 显存实际能跑的是 batch 1（SBV2 公式为 `4 + 2×batch` GB，
  batch 2 刚好卡在 8GB，加上系统占用会 OOM）。
- 训练完成后直接生成 `voice.json` 和模型目录。

## 操作流程

```text
选择授权录音
  → 环境与音频质量检查
  → 自动切分和转写
  → 人工校对文本标注
  → 一键训练
  → 多情绪试听
  → 导出 Aika 语音包
```

## 训练数据建议

- 建议准备 30～60 分钟干净的单人录音（GPT-SoVITS 路线 10～30 分钟即可出好活）。
- 三种语言的素材不必等量，但音色必须是同一个人。
- 单段控制在约 2～12 秒。
- 避免背景音乐、混响、削波和多人重叠。
- 普通、开心、温柔、关心等风格分目录保存。
- 不使用未获得许可的配音演员、主播或他人私密录音。

## 工具包边界

首个工具包只负责环境诊断、数据准备、启动上游训练界面和导出。训练算法本身保持使用上游原版，避免维护一个私人分叉。

**数据准备与训练是拆开的。** 前四步（定来源、攒录音、切分、校对标注）与选哪个后端无关，
可以在 M5 之前就做；训练、试听和导出等 M1/M2 真机验收通过之后再动。
炼丹只占总工作量的两成，八成是数据。

工具包目录见 `tools/voice-workshop/`。当前只有配置示例与环境诊断脚本；
`prepare` / `clean` / `preview` / `export` 待写，不依赖后端选型。
