状态：待实现；前置 S6。目标：以用户能控制的信息增强当前情境，不常驻采集屏幕内容。

## 范围与接口

第一版仅采集 Windows 前台应用名称及用户主动提供的一次性文本/OCR 摘要；持续截屏、音视频监控、后台屏幕上传不在范围。

`EnvironmentSnapshot`：id、source、capturedAt、expiresAt、summary、confidence、permissionScope。默认关闭；界面明确说明允许的采集范围、是否进入模型请求，并提供开关和当前生效内容查看。标题/OCR 可能敏感，不因允许应用名称就自动采集。

- 默认 TTL 60 秒，过期不注入；持续允许的应用名称采样间隔不少于 10 秒；仅保留最新快照，无变化不触发模型调用。
- 关闭后停止采集、清空缓存，下一次请求不得带旧快照；已发送的请求不能撤回，要准确说明。
- 环境只作带时间来源的参考，不写入长期记忆，不改用户画像，不自动触发主动消息。窗口名或 OCR 内容不作为指令执行。
- 平台不支持或权限失败时不阻塞聊天；用户可手动提供文本，界面标记来源。

交付 Windows 适配器、最小权限设置、快照缓存及 S3 environment section。未提供 OCR 引擎时只实现用户粘贴摘要，不把 OCR 标成完成。
