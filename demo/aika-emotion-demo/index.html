参考音频驱动的情绪迁移

同一句台词，模型与文本完全不变，只更换一段参考音频，输出语音的情绪随之改变。 这是 reference-audio-based 情感控制路线的直接验证。

Target line · 固定台词
声线

韵律起伏对比

F0 变异系数（pitch variation）＝基频标准差 ÷ 均值。数值越高的情绪，语调起伏越大。 同一句台词下该指标相差 2 倍以上，说明情绪确实由参考音频驱动，而非文本内容。

方法与数据

1 · 情感数据工程

  • 单一授权音源 → 静音切分 39 段（2~12 秒/段，共 2.9 分钟）
  • Fun-ASR 自动转写 → 人工复核（剔除转写幻觉、气息段、过短段）
  • 按文本情绪与声学指标（语速、低能量占比）筛出参考音频库

2 · 情绪 → 参考音频映射

  • 从素材中挑选情绪跨度大的片段作为「情绪原型」：温柔 / 安心 / 亲密 / 嘲讽 / 毒舌 / 恳求
  • 每一段既是训练数据，也是推理期的情绪控制接口

3 · Zero-shot 情绪迁移

  • 参考音频 → HuBERT 语义 token + 频谱 prompt，与目标文本一起送入 GPT + SoVITS 解码
  • 换参考音频即换情绪，无需重新训练，热切换零成本

4 · 一次量化发现

  • 最初的演示只用 2 段温柔系参考，主观听感偏「机械」
  • 做采样参数扫描（repetition_penalty 1.5→1.35、top_k 8→15 等）后，F0 变异系数仅从 0.115 变到 0.118（+2.6%）——参数不是原因
  • 换成情绪化的参考音频后，同一句台词的该指标达 0.20 以上（2.2 倍）——参考音频的情绪属性才是控制变量
